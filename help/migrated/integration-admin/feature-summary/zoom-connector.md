# Adobe Learning Managerのズームコネクター

## 概要

Adobe Learning ManagerのZoom コネクターを使用すると、ライブバーチャルクラスルームセッションの実施、学習者の登録の管理、出席と修了の追跡を行うことができます。 また、1つのアカウント内で複数のZoom接続をサポートし、統合管理者が役割やユーザーグループに基づいてアクセスを管理し、作成者がコースセッションで使用可能な接続を選択できます。 セッションが終わると、出席とパフォーマンスのデータがAdobe Learning Managerに同期され、レポートとトラッキングが行われます。

## ズームコネクターの設定

ズームコネクターを設定するには：

1. 統合管理者としてAdobe Learning Managerにログインします。
2. **ズーム**&#x200B;タイルにカーソルを合わせます。

   ![](assets/zoom-connector1.png)
   _Adobe Learning Managerでズームコネクターを構成する_

3. **Connect**&#x200B;を選択します。 ズームコネクター設定ページが開きます。
4. それぞれのフィールドに次のアカウント情報を入力します。 Zoomアカウントの管理者から、次の資格情報を取得できます。

   * 接続名
   * ZoomアカウントID
   * クライアント ID
   * クライアントシークレット
   * スーパー管理者のメールアドレス
   * このコネクターを使用できるロールまたはグループ（オプション）

   ![](assets/zoom-connector2.png)
   _構成の詳細を入力して、ズームコネクターを設定します_

5. **接続**&#x200B;を選択して統合を確立します。

>[!NOTE]
>
>ユーザーを有効にする場合、**学習者は、コネクターデータが正しく同期されるように、ZoomアカウントとAdobe Learning Managerアカウントの両方に同じメールアドレス**&#x200B;を使用する必要があります。

## 複数のズーム接続を追加する

Adobe Learning Managerには複数のZoom連携が可能で、連携する連携ごとに異なるZoomアカウントを設定できます。 例えば、パートナーやチームごとに個別の接続を作成し、各接続を使用できる役割やユーザーグループを指定できます。

追加できる接続数は、Adobe Learning Managerアカウント層によって異なります。

| **アカウントレベル** | **最大ズーム接続数** |
|---|---|
| Prime アプリケーションを使用する権限を承認するには、 | 6 |
| Ultimate | 50 |

## Zoomコースの作成

接続が確立されると、次のようになります。

1. **作成者**&#x200B;としてログインし、新しいバーチャルクラスルームコースを作成します。
2. 会議システムとして&#x200B;**Zoom**&#x200B;を選択し、使用するZoom接続を一覧から選択します。
   >[!NOTE]
   >
   >このリストには、ロールまたはユーザーグループで使用できる接続のみが表示され、セッションでは一度に1つの接続が使用されます。
3. 管理者、マネージャー、またはセルフ登録を通じて、学習者をコースに割り当てます。
4. 登録時に、学習者はコースの詳細を記載した電子メールを受け取ります。
5. 学習者は自分のAdobe Learning Managerアカウントにログインしてコースにアクセスし、Zoomセッションに参加できます。

## 作成者が使用できるZoom接続

コースセッションを作成または編集する場合、役割またはユーザーグループが使用できるズーム接続から選択できます。 統合管理者は、各Zoom接続にアクセスできる役割またはユーザーグループを定義します。

例えば、統合管理者が2つのZoom接続（**パートナーAズーム**&#x200B;と&#x200B;**パートナーBズーム**）を構成し、各接続を異なるユーザーグループに割り当てたとします。

* パートナーAとパートナーBの両方のグループに属している場合は、どちらの接続も選択できます。
* パートナーAグループのみに属している場合は、**パートナーAズーム**&#x200B;を選択できます。
* どちらのグループにも属していない場合、これらの接続を選択することはできません。

>[!NOTE]
>
>1つのセッションで使用できるズーム接続は1つだけです。 使用可能な接続が複数ある場合は、セッションに使用する接続を選択します。

## ズーム接続の管理

**接続の管理**&#x200B;ページには、アカウントに設定されているZoom接続が表示されます。 **表示可能**&#x200B;列は、各接続を使用できるロールまたはユーザーグループを示します。 このページから、既存のズーム接続を編集、有効化または無効化したり、削除したりできます。

![接続、資格情報、およびロールまたはグループの設定を有効にしたZoom接続の構成ページ](assets/zoom-connection-configure-page.png "接続、資格情報、およびロールまたはグループの設定を有効にしたZoom接続の構成ページ")

### ズーム接続を編集する

既存のズーム接続を編集するには：

1. **接続の管理**&#x200B;ページで、編集する接続を選択します。
1. [構成]タブで、次のいずれかを更新します。

   1. Zoomアカウントの資格情報を更新するには、**資格情報**&#x200B;の横にある「**編集**」を選択し、必要な詳細を更新します。
   1. コネクターを使用できるユーザーを変更するには、この接続を使用できる&#x200B;**ロールまたはグループ**&#x200B;を更新してください。

1. 「**保存**」を選択します。

### ズーム接続を有効または無効にする

新しいズーム接続はデフォルトで有効になっています。 接続を無効にすると、作成者は接続を削除せずにその接続を使用できなくなります。

接続を無効にするには：

1. **接続の管理**&#x200B;ページで、無効にする接続を選択します。
1. **接続を有効にする**&#x200B;を切り替えます。
1. 「**保存**」を選択します。

   無効にされた接続は、関連付けられたロールまたはグループのユーザーは使用できなくなります。

接続を再度有効にするには、[**接続を有効にする**]を選択し、[**保存**]を選択します。

### ズーム接続を削除する

Zoom接続を削除するには：

1. **接続の管理**&#x200B;ページで、削除する接続に移動します。
1. 接続の横にある&#x200B;**削除**&#x200B;アイコンを選択します。
1. 「**削除**」を選択します。

## 出席と完了の追跡

仮想セッションの終了後は、次の操作を行います。

* Adobe Learning Managerは、Zoomから自動的に完了ステータスを受け取ります。
* 管理者は、Adobe Learning Managerで出席とスコア付けのレポートを表示して、学習者の参加とパフォーマンスを追跡できます。

## Zoomサーバー間OAuthアプリの作成

Adobe Learning ManagerでZoom コネクターを使用するには、Zoomサーバー間OAuthアプリを作成し、必要なスコープを設定する必要があります。

### 必要なOAuth範囲

Zoomでアプリケーションを作成する場合は、次のスコープが選択されていることを確認してください。

| 必要な機能 | このキーワードを検索 | 次に選択 |
|---|---|---|
| すべてのユーザーミーティングを表示 | 会議 | `meeting:read:meeting:admin, meeting:read:list_meetings:admin` |
| すべてのユーザーミーティングを表示/管理 | 会議 | `meeting:update:meeting:admin, meeting:delete:meeting:admin, meeting:write:meeting:admin` |
| レポートデータを表示 | レポート | `report:read:meeting:admin, report:read:user:admin` （エンドポイントに一致するものを選択してください。） |
| すべてのユーザー情報を表示 | user | `user:read:user:admin, user:read:list_users:admin` |
| ユーザーの管理 | user | `user:update:user:admin, user:write:user:admin` |
| 会議登録者の追加 | 登録者 | `meeting:write:registrant:admin` |
| すべての会議登録者を一覧表示する | 登録者 | `meeting:read:list_registrants:admin` |
| サブアカウントミーティング | 会議+ :masterの検索 | `meeting:write:meeting:master` |
| ミーティング参加者レポート | 参加者 | `report:read:list_meeting_participants:admin` |
