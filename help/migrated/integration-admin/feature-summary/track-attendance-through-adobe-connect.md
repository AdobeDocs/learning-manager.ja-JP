# Adobe Connectのレコードビューを使用した出席の追跡

## 概要

Adobe Learning Managerでは、レコーディングビューを使用して、Adobe Connectバーチャルクラスルームセッションの出席を追跡できます。 学習者がライブセッションに出席していないが、Adobe Connectでレコーディングを長時間ウォッチすると、Learning Managerはその学習者がセッションに出席したとマークします。 その後、学習者はセッションモジュールを完了し、セッションが属する学習目標の完了に向かって進むことができます。

この機能が導入されるまで、Learning ManagerではConnectの録画を視聴した学習者の出席状況を記録する方法がありませんでした。 学習者がライブセッションを欠席してもセッションを完了できず、インストラクターが手動で参加して出席をマークする必要がありました。 この機能を使用すると、その手動手順が削除されます。 どのレコーディングをどの時間モニタリングしたかをAdobe Connectがレポートします。Learning Managerはモニタリング時間とアカウントに設定された完了条件を比較します。

学習者が記録されたセッションの完了条件を満たすと、管理者アプリで学習者がマークされます。

Adobe Learning Managerでは学習者が同じ電子メールIDを使用してAdobe Connectにリダイレクトされるため、学習者の電子メールIDはAdobe Learning ManagerとAdobe Connectで同じである必要があります。
デフォルトの同期頻度と、統合管理者が設定できる最短の間隔は1時間です。


## 誰が何をするのか

| 役割 | 彼らが何をしているか |
|----------------------------|-----------------------------------------------------------------------------------------------------------------------|
| 学習者 | セッションの記録を開き、ライブセッションが欠落した後に視聴します。 |
| 学習プログラム / 資格認定を | ライブセッション中に録音を開始するため、録音および文字起こしが存在します。 |
| 統合管理者 | 出席の同期で使用するAdobe Connectアカウントを設定し、同期スケジュールを設定するか、オンまたはオフにします。 |
| 作成者または配信マネージャー | バーチャルクラスルームセッションをスケジュールし、複数の日にわたるプログラムでは、永続的な部屋を数日間にわたって再利用します。 |
| Adobe Connect | 各学習者の電子メールと録画視聴時間をキャプチャし、APIを介して録画閲覧者のリストを表示します。 |

記録ベースの出席作業を行うには、役割ごとに個別の役割があります。

## ユースケース

### 学習者がライブセッションに失敗した場合

学習者は、ライブのバーチャルクラスルームセッションに参加できません。 その後、学習者はLearning Managerでセッションを開き、記録を確認します。 視聴時間が完了条件を満たすと、Learning Managerによって学習者に出席のマークが付けられます。学習者はインストラクターに質問することなくモジュールを完了できます。

### 部分的にしか見ない学習者

学習者はレコーディングを開きますが、視聴している視聴回数が必要なシェアを下回っています。 完了条件を満たしていないため、Learning Managerは学習者を出席としてマークしません。

### 1つの常設ルームでの複数の日にわたるセッション

作成者または配信マネージャーは、同じ永続的なConnectルームで1日目、2日目、3日目のセッションをスケジュールします。 Adobe Connectにログインしなくても、ルーム名を表示および再利用できます。

## 主な機能

| 機能 | 機能 |
|-------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| 自動出席 | 学習者が所定のしきい値を満たすまで録画を視聴した場合、Connectベースのバーチャルクラスルームセッションに出席したことを学習者にマークします。 |
| Connectから時間を見る | Adobe Connectがキャプチャする学習者の電子メールと録画視聴時間を使用します。 |
| 完了基準のしきい値 | ウォッチ時間が完了条件で設定されたパーセンテージに達すると、学習者がモジュールを完了したとマークします。 |
| 実際のウォッチ時間のみ | 学習者が実際に視聴した時間をカウントします。 シークバーをドラッグしても、ウォッチ時間が追加されません。 |
| スケジュールされた同期 | 統合管理者が制御するスケジュールでバックエンドパイプラインを実行し、オンとオフを切り替えることができます。 |
| 会議室の常時表示 | 作成者が永続的なルームを日間再利用できるように、接続ルーム名をインスタンスレベルで表示します。 |

## 出席管理の仕組み

*録画を開いた学習者から、Learning Managerがモジュールの完了をマークしました。*

### エンドツーエンドのフロー

1. インストラクターがAdobe Connectでバーチャルクラスルームのライブセッションを主催し、レコーディングを開始します。 録音と文字起こしは、セッション後に使用できるようになります。

1. セッションを逃した学習者は、記録を選択して表示します。 Adobe Connectは、ビューを自動的にトラッキングします。

1. Adobe Connectには、学習者のメールアドレスと、学習者が実際に視聴して費やした時間が表示されます。

1. 設定されたスケジュールで、バックエンドのSnapLogicパイプラインがAdobe Connect APIを呼び出し、指定されたフレームのレコーディングビューアのリストを取得します。 パイプラインでは、統合管理者で設定されたAdobe Connectアカウントが使用されます。

1. Learning Managerは、各ビューアを対応するコースやモジュールにマッピングします。

1. Learning Managerでは、学習者の合計視聴時間が完了条件と比較されます。

1. 視聴時間が基準を満たした場合、Learning Managerはそのモジュールについて学習者に完了のマークを付けます。 バックエンドでは、Learning ManagerはユーザーコースグレードのCSVを生成することで、この記録を行います。

>[!NOTE]
>
>Adobe ConnectはLearning Managerにデータをプッシュしません。 Learning ManagerはAdobe Connectインスタンスレベルでプルします。例えば、「この5人のユーザーは過去24時間にこれらの6つの録音を視聴しました」などと呼ばれます。 したがって、出席は、学習者が視聴を終了した瞬間ではなく、次のパイプライン実行後に更新されます。

### 修了基準及び視聴時間

学習者は、完了条件で定義されたパーセンテージ以上の録音を視聴する必要があります。 次の規則に注意してください。

* パーセンテージは、スケジュールされたセッション期間ではなく、記録期間に適用されます。 15分間のセッションを5分間だけ記録する場合、所要時間は5分間に基づきます。 Adobe Connectは記録時間を設定します。

* 割合はLearning Manager側で設定されます。 これは、アカウント全体で共通の設定であり、各インスタンスの設定ではありません。 ライブセッションに既に適用されている設定と同じ種類の設定（例えば、80%の参加が必要）。

* Adobe Connectは、学習者が実際に視聴した時間を記録します。 シークバーでジャンプしてもカウントされず、Connectが通過するウォッチタイムがLearning Managerによって処理されます。

| 完了条件 | 録画時間 | 所要時間を確認 | 結果 |
|-------------------------|------------------------------------|-----------------------|-------------------------------------------------------------|
| 50% | 5分 | 2.5分 | 2.5分ごとに完了とマークされたビデオが視聴されます。 |
| 50% | 5分（15分） | 2.5分 | 15分間のセッションではなく、5分間の録音に基づきます。 |
| 0% | 任意 | 開く以上の物はない | 録音を開くだけで十分です。 |

### 「適格性」ウィンドウ

Learning Managerでは、学習目標の完了日までの録画ベースの出席のみが適用されます。 学習目標に完了日がない場合、Learning Managerでは親学習目標の完了日が使用されます。

### 同期をスケジュール

統合管理者は、パイプラインの実行頻度を制御します。 スケジュールは時間ごと、週ごと、またはその他の間隔で設定できます。統合管理者は、スケジュールのオンとオフを切り替えることができます。 すべての実行に同じAdobe Connectアカウントが使用されます。

### 変更点

* 1日目に作成された常設会議室をユーザーが追加すると、Learning Managerはその会議室へのアクセス権をユーザーに付与します。 別の日に同じ会議室をセッションに追加できます。
* Learning Managerでは、**バーチャルクラスルームURL**&#x200B;の横のセッションの詳細に、インスタンスレベルの接続室名が表示されます。
* デフォルトインスタンスの場合、Learning Managerではコース作成時に設定された会議室が表示されます。

### 制限事項と考慮事項

* Learning Managerはスケジュールに従ってデータを取得するため、出席はリアルタイムではありません。
* この機能は、Connectベースのバーチャルクラスルームセッションのみを対象としています。
* 録音が存在する必要があります。そのため、インストラクターはライブセッション中に録音を開始する必要があります。
* 学習者は、Adobe Connectがキャプチャしたメールアドレスを使用して照合されます。
* シークバーをドラッグしても、ウォッチ時間が追加されません。
* 記録ベースの出席は、学習目標または親学習目標の完了日に停止します。

### 注意事項

* 視聴時間は、指定した割合（例えば、5分の50%は2.5分）以上である必要があります。 学習者がセッションを繰り返し視聴していても、所定の視聴時間に達していない場合は、視聴時間は増加しません。 ただし、学習者がセッションを部分的に異なる時点で視聴し、しきい値の基準を満たしている場合でも、視聴時間が加算されます。 例えば、学習者が1日目に1分間のセッションを視聴し、次の日目に退出した時点からさらに1.5分間のセッションを視聴した場合、視聴時間が合算されます。 これはAdobe Connect側で発生します。

* 完了条件は、コースレベルとアカウントレベルで設定できます。 このエフェクトは、ライブセッションへの参加と同じです。

* デフォルトの同期頻度と、統合管理者が設定できる最短の間隔は1時間です。

* Adobe Learning Managerでは学習者が同じ電子メールIDを使用してAdobe Connectにリダイレクトされるため、学習者の電子メールIDはAdobe Learning ManagerとAdobe Connectで同じである必要があります。

### FAQ

**Q.学習者はライブセッションに出席する必要がありますか？**
**A.**&#x200B;いいえ。 ライブセッションに参加しなかった学習者でも、録画を長時間にわたって視聴した場合に出席済みとしてマークできます。

**Q.学習者が視聴する必要がある録画の数を指定します。**
**A.**&#x200B;記録期間に適用される完了条件の割合。 例えば、5分間の録画が50%の場合、最低2.5分の視聴時間が必要です。

**Q.録音をスキップすることは重要ですか？**
**A.**&#x200B;いいえ。 Adobe Connectは、学習者が実際に視聴した時間を記録するため、シークバーのドラッグはカウントされません。

**Q.学習者が視聴を終了するとすぐに出席がマークされますか？**
**A.**&#x200B;いいえ。 Learning Managerはスケジュールに従ってAdobe Connectからビューアデータを取得するため、次回のパイプライン実行後に出席が更新されます。

**Q.Adobe ConnectからLearning Managerにデータが送信されますか？**
**A.**&#x200B;いいえ。 Learning Managerがプルします。 これは、Adobe Connectインスタンスレベルのプル方式で、プッシュ方式ではありません。

**Q.視聴している学習者をLearning Managerで確認する方法**
**A.** Adobe Connectは、学習者のメールアドレスと録画時間をキャプチャします。 Learning Managerはそれをコースとモジュールにマッピングします。

**Q.同期の実行頻度は誰が制御しますか？**
**A.**&#x200B;統合管理者はスケジュールを設定し、オンとオフを切り替えることができます。

**Q.完了率は各インスタンスに対して設定されていますか？**
**A.**&#x200B;いいえ。 これは、アカウント全体で一般的な設定です。

**Q.複数のセッションで1つのConnectルームを共有できますか？**
**A.**&#x200B;はい。 作成者は、1日目に作成された常設会議室を他の日にセッションで再利用でき、部屋名がLearning Managerのインスタンスレベルに表示されます。
