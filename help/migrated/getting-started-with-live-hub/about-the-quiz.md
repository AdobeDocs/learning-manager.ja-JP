# クイズについて

ライブハブのクイズ機能を使用すると、インストラクターはクイズを作成および実施して、ライブセッション中の学習者の理解度を評価できます。 セッション前またはセッション中にクイズを作成し、クイズを起動して回答をリアルタイムで収集できます。また、学習者がセッションダッシュボードで回答したときに結果を監視できます。

>[!NOTE]
>
> ライブハブセッションのクイズが、Adobe Learning Managerの&#x200B;**クイズ作成ツール**&#x200B;で作成されたクイズと異なります。

## 主な利点

クイズ機能には、次の利点があります。

* **学習結果の評価** ：学習者が指導後に主要な概念をどの程度理解し、保持しているかを評価します。

* **構造化された評価の実施** ：複数の質問で構成されるクイズを作成し、単一の質問のチェックだけでなく、トピックまたはモジュール全体で学習者を評価します。

* **個々のパフォーマンスを追跡** :ライブクイズの結果は、インストラクターがグループ全体のパフォーマンスをすばやく把握し、さらに詳しく説明する必要がある領域を特定するのに役立ちます。

* **エンゲージメントの向上** ：インタラクティブな評価を通じて積極的な参加を促します。
