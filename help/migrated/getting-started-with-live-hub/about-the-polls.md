# 投票について

投票機能を使用すると、インストラクターはライブセッション中に投票を作成して起動し、学習者から回答をリアルタイムで収集できます。 複数の選択肢、複数回答、短い回答など、質問の種類を選択して投票を手動で作成したり、Icebreaker投票やナレッジチェック投票などのAIが支援するオプションを使用して投票をすばやく生成したりできます。

学習者は、アクティブな投票に返信し、回答を更新して、共有された結果を表示できます。 すべての投票アクティビティは、**投票とクイズ**&#x200B;パネルから管理します。

## 主な利点

* **学習者のエンゲージメントを高める** ：学習者がリスニングを超えてセッション中の質問に対応できるようにすることで、積極的な参加を促します。

* **理解していることをリアルタイムで確認する** ：学習者がトピックをどの程度理解しているかを評価し、さらに説明が必要な領域を特定します。

* **アイスブレーカーを使ってセッションを開始する**:セッションの初めに世論調査を行って参加者を励まし、早めの交流を促し、より魅力的な学習環境を構築します。

* **簡単なフィードバックの収集** ：進行中の指示やコンテンツの共有を中断することなく、セッションを続けながら、学習者の意見、好み、フィードバックをリアルタイムで収集します。

## ロールと権限

**投票**&#x200B;機能は、ライブハブセッションのインストラクターと学習者の両方が利用できます。 実行できるアクションは、ユーザーの役割によって異なります。
