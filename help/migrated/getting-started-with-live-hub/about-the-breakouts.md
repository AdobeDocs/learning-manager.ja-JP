# ブレークアウトについて

ブレイクアウトルームを使用すると、インストラクターはライブハブセッションを小さなグループに分割できます。 学習者はこれらの会議室に参加してディスカッション、アクティビティ、共同作業を行い、アクティビティが終了すると自動的にメインセッションに戻ります。 ブレイクアウトルームは、ブレーンストーミング、グループアクティビティ、集中した学習に役立ちます。

インストラクターは、手順に従ってブレークアウトルームの作成と管理、学習者の割り当て、アクティビティのガイドを行うことができます。 セッション中、インストラクターは会議室のアクティビティを監視し、リアルタイムのディスカッションの概要を表示して、必要に応じてサポートを提供することができます。

学習者は、割り当てられたルーム内で共同作業を行い、ディスカッションに参加し、共有の指示と概要を使用してアクティビティに合わせることができます。

セッション終了後、インストラクターはセッションレポートとセッションダッシュボードを通じてブレイクアウトディスカッションと成果をレビューでき、より良い分析とフォローアップが可能になります。

## ブレークアウトセッションの利点

* **共同作業を推奨**:Participants&#x200B;すると、小さなグループで共同作業を行い、焦点を絞ったディスカッションや活動を行うことができます。

* **リアルタイムの部屋表示** ：インストラクターは、参加者の作業を中断することなく、部屋全体のエンゲージメント、参加、およびヘルプの要求を監視できます。

* **AIを活用したディスカッションのインサイト** :リアルタイムの概要は、インストラクターが複数の部屋にわたるディスカッションをすばやく理解し、アクティビティを効果的にガイドするのに役立ちます。

* **構造化されたアクティビティのガイダンス** ：ブレイクアウトアクティビティ中に学習者をガイドするための手順を提供します。

* **柔軟な参加者管理** ：参加者は、様々な学習形式に対応するように簡単に割り当てたり調整したりできます。

* **セッション後のインサイトとレポート** ：インストラクターは、セッションダッシュボードで概要、レポート、セッションデータを確認して、結果を分析し、今後のセッションを向上させることができます。

## ブレークアウトセッションの用語

これらの用語は、分科会がどのように機能するか、また参加者がアクティビティ中にどのように交流するかを説明するものです。

| **用語** | **説明** |
|----|----|
| **ブレークアウトセッション** | バーチャルクラスルームの一時的なセッション。参加者は小さなグループに分けられ、焦点を合わせたディスカッションやアクティビティが行われます。 |
| **小会議室** | これは、ブレイクアウトセッション内の小さなグループで、学習者は分割されて特定のアクティビティに参加します。 |
| **説明** | インストラクターが、ブレイクアウトルームの参加者にタスクまたはディスカッションを割り当てます。 |
| **ブレイクアウトレポート** | ブレイクアウトセッション中の学習者のエンゲージメントの指標。インストラクターが参加レベルを監視および評価するために使用します。 |

## ブレイクアウトセッションのワークフロー

ブレイクアウトセッションは、セットアップ、ライブコラボレーション、およびセッションの完了を含む構造化されたフローに従います。

### ブレイクアウトセッションの設定

教員は、ブレイクアウトセッションを開始する前に、セッションの要件に従ってブレイクアウトルームを作成および設定します。

* 部分断面図の部屋の数を定義します。

* 参加者をドラッグ&amp;ドロップして、学習者をルームに自動または手動で割り当てます。

* 学習者をガイドするアクティビティ指示を追加します。

この設定により、セッション開始前に学習者が整理され、アクティビティに沿って整列します。

### ブレイクアウトセッション中

ブレイクアウトセッションが開始されると、学習者は割り当てられた部屋に移動され、特定のアクティビティで共同作業を行うことができます。

* 学習者はブレークアウトルーム内でやり取りしたり、参加したりできます。

* インストラクターは、会議室のアクティビティの監視、参加の追跡、ヘルプリクエストへの対応を行うことができます。

* インストラクターは、リアルタイムでディスカッションの概要を確認し、必要に応じて受講者をガイドする会議室に参加できます。

このフェーズでは、コラボレーションと積極的な参加に重点を置きます。

### ブレークアウトセッションの後

ブレイクアウトセッションが終了すると、すべての参加者が自動的にメインルームに戻ります。

* 学習者がメインセッションビューに戻ります。

* インストラクターは、レポートを通じてアクティビティ全体、結果、セッションの概要をレビューできます。

* インストラクターは、セッションを複製して、同じ設定を今後のアクティビティで再利用することができます。

これにより、ブレイクアウトアクティビティが完了したことを示し、セッション後のレビューが可能になります。
