# ライブハブセッションでのインストラクターの役割

Adobe Learning Managerのインストラクターとして、ライブハブの効果的なセッションを実現し、魅力的なラーニングエクスペリエンスを提供する上で重要な役割を果たします。

この記事では、セッション前の準備、セッション中のインタラクションの管理、セッション後の結果のレビューなど、ALMでのライブハブセッションを管理するためのインストラクターのワークフローとベストプラクティスについて説明します。

## ライブハブセッションのインストラクターのワークフロー

### セッション前の準備

学習者が参加する前にセッションURLを使用して設定し、予定されている開始時間より前にライブハブルームに参加します。 詳細については、[セッションに参加](./join-live-hub-session-as-an-instructor.md)してください。

ルームでは、次の操作を実行できます。

* 画面の共有やホワイトボードアクセスの有効化など、学習者の権限を設定します。 詳しくは、[インストラクターとして会議室の設定を管理する](./manage-settings.md)を参照してください。

* AIが生成したアイスブレーカーや独自の質問を使用して、事前に投票を作成します。 詳細については、[投票を作成して開始する](./create-and-launch-a-poll.md#create-a-poll-using-ai)を参照してください。

* エンゲージメントと評価のためのクイズ（多岐選択または多岐回答）を作成します。 詳細については、[クイズを作成および管理](./create-and-manage-a-quiz.md#create-a-quiz)を参照してください。

* Miroを設定して、リアルタイムの共同作業とブレーンストーミングを可能にします。 詳細については、[ホワイトボードの共有](./share-a-whiteboard.md#share-miro-and-other-external-whiteboards)を参照してください。

* ブレイクアウトルームをデザインし、学習者を割り当て、ルームごとにインストラクションを追加します。 詳細については、[ブレークアウトルームを作成および管理する](./create-and-manage-breakout-rooms.md#design-a-breakout-session)を参照してください。

* 参照資料をアップロードすると、セッション中にAIが学習者の質問に対して、コンテキストに応じた正確な回答を生成できます。 詳細については、[インストラクターとしてチャットパネルを使用](./use-the-chat-panel-as-an-instructor.md#upload-files-for-better-responses)してください。

### セッションの管理

セッション中は、学習者のエンゲージメントを維持しながら、コンテンツを効果的に提供することに重点を置きます。 次のことができます。

* ライブセッションを開始および管理します。

* セッションを記録して再生できるようにし、後でレビューできるようにします。 詳細については、[セッションの記録](./record-a-session.md)を参照してください。

* 共有、チャット、Q&amp;Aなどの利用可能なエンゲージメントツールを使用して、コンテンツを提示します。

* 画面を共有し、注釈を付けて情報をハイライト表示し、スナップショットを書き出します。 詳細については、[画面の共有](./share-your-screen-as-an-instructor.md)を参照してください。

* 準備した投票とクイズを起動し、学習者に結果を表示するかどうかを選択します。 詳細については、[クイズを作成および管理](./create-and-manage-a-quiz.md)を参照してください。

* チャット、投票、ディスカッションを通じて、学習者との対話を可能にします。

* エンゲージメントインジケーター（「高」、「中」、「低」）を使用して参加者のエンゲージメントをモニターし、出席を追跡します。 詳細については、[参加者のエンゲージメントを追跡](./track-the-participant-engagement.md)してください。

* オーディオおよびビデオのアクセス許可を管理します。

### 学習者のインタラクションの管理

セッション全体で円滑なコミュニケーションと共同作業を確保します。 次のことができます。

* チャットパネルとQ&amp;Aを使用して質問に回答します。質問タブでのAIを活用した返信も含まれます。 詳細については、[インストラクターとしてチャットパネルを使用](./use-the-chat-panel-as-an-instructor.md#draft-replies-to-participant-questions-with-ai)してください。

* 「全員」タブですべての参加者と対話するか、「プライベート」タブで直接対話します。

* 必要に応じて、学習者の権限を有効または制限します。

* 出席者パネルビューから出席または欠席している学習者を管理し、挙手とリアクションを監視し、プライベートメッセージを送信し、マイクをミュートし、挙手の数を減らします。 詳細については、[出席者パネルを管理する](./manage-the-attendees-panel.md)を参照してください。

* ブレークアウトルームの開始や学習者からの問い合わせがあった場合のルームへの参加など、ディスカッションおよびグループアクティビティを容易にします。

* セッション中の中断や技術的な問題に対応します。 詳細については、[Live Hubのトラブルシューティングガイド](../kb/troubleshooting-guide-for-live-hub.md#connection-issues)を参照してください。

### セッションを終了する

トレーニングが完了したら、すべての参加者のセッションを終了します。 セッションが終了したら、セッション概要ページで結果を確認します。

* セッションの録音と文字起こしにアクセスし、必要に応じて録音を編集します。 詳細については、[セッションの記録](./record-a-session.md#view-topics-in-recording)を参照してください。

* セッションの概要、投票、クイズ、ブレイクアウト、Q&amp;A、リアクションなどのインタラクション、参加者のアクティビティ、ダウンロード可能なレポートなどのセッション分析をレビューします。 詳細については、[セッションダッシュボード](./view-the-session-dashboard.md)を参照してください。
