# 参加者のエンゲージメントの追跡

Live Hubの参加者のエンゲージメントにより、ライブセッション中の学習者または参加者のエンゲージメントをインストラクターがリアルタイムで確認できます。 ブラウザーのフォーカス、チャットアクティビティ、およびポーリングへの参加が1つのエンゲージメントレベルにまとめられ、緑色、黄色、または赤色のインジケーターとして表示されます。 これを使用して注意の低下を見つけ、リアルタイムで配信を調整します。

参加者のエンゲージメントには、特定の時点での、メインルームのすべての学習者の平均エンゲージメントレベルが表示されます。 学習者がセッションに参加するとすぐに、レベルが更新されます。

参加者の参加度は、ライブセッション中にのみ計算されて表示されます。

>[!NOTE]
>
> 参加者のエンゲージメントは、インストラクターのみが表示できます。 学習者はアクセスできません。

## エンゲージメントレベルの計算

参加者のエンゲージメントスコアは、ライブセッション中に学習者の注意力をリアルタイムで監視するのに役立ちます。 画面の上部にあるこのエンゲージメントバッジには、全体的なエンゲージメントレベルが&#x200B;**低**、**中**、または&#x200B;**高**&#x200B;と表示されます。これにより、セッションの配信を調整し、必要に応じて参加を促すことができます。

インジケーターは、メインルームのインストラクターにのみ表示されます。

![エンゲージメントレベル指標](assets/engagement-level-indicator.png)
*参加者のエンゲージメントが右上隅に表示されているライブハブインターフェイス。*

## エンゲージメントスコアの計算方法

各学習者または参加者は、次の要因に基づいて0 ～ 100のエンゲージメントスコアを獲得します。

- **セッションへの注意**：学習者または参加者がセッションウィンドウをアクティブにしたままにすると、デフォルトでエンゲージメントレベルが「高」になります。 別のウィンドウまたはブラウザータブに切り替えると、セッション活動に引き続き参加しない限り、エンゲージメントレベルは「低」に下がります。
- **セッションへの参加**：講演、スクリーンの共有、チャットメッセージの送信、世論調査やクイズへの対応、ホワイトボードの描画、手を挙げる、リアクションの送信、セッション内のクリックなどの活動を行うと、エンゲージメントスコアが高くなります。

### エンゲージメントスコアの変化

学習者のエンゲージメントスコアは、ライブセッション全体で、注意と参加に基づいて変化します。 エンゲージメントスコアの計算方法には、次の条件が影響します。

- **アクティビティの期間** ：ほとんどの参加アクティビティはエンゲージメントスコアを一時的に上げますが、その貢献度は約5分かけて徐々に下がります。 例えば、学習者がセッション中に話した後で別のウィンドウに切り替えた場合、エンゲージメントスコアは即座ではなく徐々に低下します
- **画面の共有**：学習者または参加者が画面を共有している間、エンゲージメントスコアは100のままです。
- **同時アクティビティ**：学習者または参加者が複数のアクティビティを同時に実行する場合は、エンゲージメントの値が最も高いアクティビティのみが考慮されます。 個々のアクティビティのスコアは組み合わせられず、エンゲージメントスコアが100を超えないようにします。
- **複数のデバイス**：学習者または参加者が複数のデバイスからセッションに参加した場合、これらのデバイス全体で最大のエンゲージメントスコアが考慮されます。

## エンゲージメントスコア

参加者参加度バッジには、メインルームのすべての学習者の平均参加度スコア（最も近い整数に丸めたもの）に基づいて、全体的な参加度が表示されます。

エンゲージメントスコア全体を計算する場合は、次の条件が適用されます。
- **インストラクターと録音ボット** ：インストラクターと録音ボットは、エンゲージメント全体のスコア計算から除外されます。 録音ボットは出席者リストに表示されません。
- **ブレイクアウトルーム**:ブレイクアウトルームの学習者または参加者は、エンゲージメントスコア全体には含まれません。 学習者がメインルームとブレイクアウトルームの間を移動すると、個々のエンゲージメントスコアがリセットされ、1 ～ 2分以内に再計算されます。
- **新しい学習者** ：参加者のエンゲージメントスコアは、セッションに参加してから約1分後に確認できるようになります。 スコアが利用可能になるまで、学習者または参加者はエンゲージメントスコア全体の計算から除外されます。
- **空の会議室**：学習者または参加者が会議室に存在しない場合、バッジにエンゲージメントレベルのない参加者のエンゲージメントが表示されます。

## エンゲージメントレベルと指標の特定

参加者のエンゲージメントバッジには、エンゲージメントスコア全体に基づいて、次のいずれかのエンゲージメントレベルが表示されます。 これらのレベルを使用して、学習者の注意力を監視し、必要に応じてセッションの配信を調整できます。  各レベルの意味は次のとおりです。

| **エンゲージメントレベル** | **スコア** | **説明** |
|----|----|----|
| 高 | 61～100 | 学習者は積極的にセッションに参加します。 |
| 中 | 31～60 | 学習者は、中度の参加で時折行われる対話を表示します。 |
| 低 | 0～30 | 学習者は、セッション中にほとんどインタラクションがないか、フォーカスが低下している。 |

>[!NOTE]
>
> - エンゲージメントスコアは、セッション中の参加者の注意を示します。 学習成果やパフォーマンスは測定しません。
> 
> - エンゲージメントスコアは1分ごとに計算されます。 変更がエンゲージメントバッジに表示されるまでに最大2分かかる場合があります。

## よくある質問

+++ エンゲージメントスコアは、参加者がセッションをアクティブに視聴しているかどうかを検出しますか？

掲示板で エンゲージメントスコアは、セッションウィンドウがアクティブかどうか、および参加者のアクティビティ（会話、チャットメッセージの送信、投票への応答など）に基づいて計算されます。 エンゲージメントの評価に、カメラビデオ、アイトラッキング、マイクのミュートステータスは使用されません。

+++

+++ 参加者がセッションウィンドウから切り替わったらどうなりますか？

参加者が別のブラウザータブ、ウィンドウ、またはアプリケーションに切り替えると、セッションウィンドウはアクティブとは見なされません。 セッション・ウィンドウが表示されたままの場合でも、別のウィンドウにフォーカスがある場合は非アクティブと見なされます。

+++

+++ すべての参加アクティビティは、エンゲージメントスコアに等しく貢献しますか？

会話、画面共有、チャットメッセージの送信、世論調査やクイズへの対応、ホワイトボードへの描画、挙手、反応の送信は、エンゲージメントスコアに等しく貢献します。 セッション内をクリックすると、全体の表示量がわずかに減少します。

+++

+++ 参加アクティビティ後にエンゲージメントスコアはどのように変化しますか？

ほとんどの参加活動の貢献度は、約5分で徐々に低下します。 例えば、参加者が別のウィンドウに切り替わって話した場合、次回の更新でエンゲージメントスコアが100に上がります。 その後の数分で、スコアは徐々に80、60、40、20まで下がり、参加者がセッションウィンドウに戻るか、再び参加するまで残ります。

セッションウィンドウをアクティブに保つ参加者は、高エンゲージメントレベルを維持します。

+++

+++ ブレイクアウトルームの参加者はエンゲージメントスコア全体に含まれますか？

掲示板で メインルームの参加者のみがエンゲージメントスコアの全体的な計算に含まれます。 インストラクターがブレイクアウトルームにいる場合、エンゲージメントバッジは表示されません。

+++

+++ ブレイクアウトルーム終了後にエンゲージメントスコアが全体的に低下するのはなぜですか？

参加者がブレイクアウトルームからメインルームに移動すると、個々のエンゲージメントスコアがリセットされ、1 ～ 2分以内に再計算されます。 これにより、エンゲージメントスコア全体が一時的に低下する可能性があります。

+++

+++ 参加者が複数のデバイスから参加した場合、エンゲージメントスコアはどのように計算されますか？

参加者が複数のデバイスからセッションに参加した場合、それらのデバイス全体で最大のエンゲージメントスコアが考慮されます。 あるデバイスで非アクティブセッションが発生しても、別のアクティブデバイスで記録されたエンゲージメントスコアは減少しません。

+++

+++ エンゲージメントバッジの更新に最大2分かかるのはなぜですか？

各参加者のエンゲージメントスコアは、1分ごとに計算されます。 エンゲージメントスコアは1分ごとに更新されるため、エンゲージメントバッジに変更が表示されるまでに最大2分かかる場合があります。

+++

+++ エンゲージメントバッジに「低」と表示された場合、インストラクターは何ができますか？

エンゲージメントレベルが低い場合は、ほとんどの参加者がセッションから切り替わり、積極的に参加していないことを示します。 インストラクターは、投票、クイズ、チャットプロンプト、ディスカッションの質問を使用して、参加を促し、参加者の注意をセッションに戻すことができます。

+++

+++ インストラクターは、エンゲージメントスコアを使用して出席を追跡したり、学習者を評価したりできますか？

エンゲージメントスコアは、セッション中の参加者の注意やアクティビティの一般的な指標となります。 参加者は、積極的に学習に参加したり学習のデモンストレーションを行わなくても、セッションウィンドウをアクティブにしておくことで、高いエンゲージメントレベルを維持できます。 そのため、エンゲージメントスコアは、学習者のパフォーマンスの評価や出席の追跡には適さない場合があります。

+++

+++ 参加者はエンゲージメントスコアを表示できますか？

掲示板で エンゲージメントバッジはインストラクターにのみ表示されます。

+++

+++ インストラクターは個々の参加者のエンゲージメントスコアを表示できますか？

掲示板で エンゲージメントバッジには、メインルームのエンゲージメントスコアのみが表示されます。 個々の参加者のスコアは使用できません。

+++

+++ インストラクターはエンゲージメントトラッキングを無効にできますか？

掲示板で エンゲージメントトラッキングは常に有効になっており、無効にすることはできません。

+++

+++ エンゲージメントスコアはレポートまたはセッション履歴で使用できますか？

掲示板で エンゲージメントバッジには、現在のエンゲージメントスコアのみが表示されます。 エンゲージメントスコアは保存されず、レポートやセッション履歴には含まれません。

+++

+++ 共同インストラクターはエンゲージメントバッジを表示できますか？

はい。 共同インストラクターは、セッション中にエンゲージメントバッジを表示することもできます。

+++

+++ モバイルデバイスでエンゲージメントスコアはどのように計算されますか？

参加者は、モバイルブラウザーを介してライブハブセッションにアクセスできます。 エンゲージメントスコアは、デスクトップブラウザーと同じ条件で計算されます。
