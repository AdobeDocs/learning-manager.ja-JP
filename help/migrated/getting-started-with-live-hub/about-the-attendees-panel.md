# 出席者パネルについて

Live Hubの出席者パネルでは、セッション中の学習者の表示やインタラクションの管理を行うことができます。 すべての出席者を一元的に表示し、インストラクターが参加とエンゲージメントをリアルタイムで監視できるようにします。

このパネルには出席者の名前、役割、インタラクションのステータスが表示されるため、セッションに存在するユーザーとまだ参加していないユーザーを簡単に特定できます。 インストラクターはこのパネルを使用して、参加者のアクセス権を管理し、参加度を監視し、マイクのアクセス、リアクション、挙手など、学習者とのインタラクションを制御できます。

## 主な利点

* **セッションの可視性を向上させる**：すべての出席者を1か所に表示し、誰が参加したかをより簡単に確認できるようにします。

* **参加を簡単に管理する** ：インストラクターがセッション中の学習者のインタラクションを管理するのに役立つ出席者コントロールにすばやくアクセスできます。

* **学習者の対応をサポート**：反応、挙手、プライベートメッセージなどの機能を使用してエンゲージメントを実現します。

* **出席の追跡**：現在在席中の学習者と、セッションに登録されているがまだ参加していない学習者を表示します。

## ロールと権限

出席者パネルは、ライブハブセッションのインストラクターと学習者の両方が使用できます。 実行できるアクションは、ユーザーの役割によって異なります。
