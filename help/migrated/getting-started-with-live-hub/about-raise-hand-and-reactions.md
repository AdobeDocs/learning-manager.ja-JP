# 挙手と反応について

インストラクターと参加者は、挙手機能とリアクション機能を使用して、ライブハブセッション中にやり取りすることができます。 学習者は、話したいという合図に手を上げ、反応を送ることで、口頭ではなく迅速にフィードバックを行います。 インストラクターは、リアクションや挙手をリアルタイムで表示して参加を管理できます。すべてセッションフローを中断することなく実行できます。

## 主な利点

挙手と反応の機能には以下の利点があります。

* **参加を促す** ：学習者は、セッションに割り込まずに、話したい、または質問したいというシグナルを受け取ります。

* **簡単なフィードバックの収集** ：学習者は、親指を立てる、拍手を送る、考えるなどの反応を返すことができます。これにより、インストラクターは教室の雰囲気を即座に把握できます。

* **インタラクションの管理** ：インストラクターが個々の学習者の手を下げたり、上げた手をすべて消去したりして、ディスカッションを整理できるようにします。

* **無停止を維持** :セッションフローを中断せずにリアルタイムで表示される視覚的なキューと反応を通じて、エンゲージメントをサポートします。

## ロールと権限

インストラクターと学習者は、ライブハブセッションで挙手してリアクションを送信できますが、実行できるアクションはユーザーの役割によって異なります。
