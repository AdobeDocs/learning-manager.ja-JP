# スクリーン共有について

スクリーン共有を使用すると、インストラクターはデバイスのコンテンツをリアルタイムで参加者と共有できます。 画面共有を使用して、アプリケーションのプレゼンテーション、プレゼンテーションの提供、ワークフローのデモンストレーション、タスクのガイドを行います。 インストラクターが画面共有を有効にしている場合は、学習者も画面を共有できます。

分割表示では、画面を共有するだけでなく、2つのコンテンツを並べて表示したり、共有コンテンツとホワイトボードを併用したり、画面に直接コメントを付けて主要な情報をハイライト表示したりすることもできます。この際、プレゼンテーションが中断されることはありません。

## 主な利点

* **リアルタイムで表示** :アプリケーション、プレゼンテーション、ワークフローをデバイスから直接共有して、学習者が実際に作業を進められるようにします。

* **一度にさらに表示** ：画面共有やホワイトボードなど、分割表示で最大2つのコンテンツを並べて表示できます。この場合、切り替えや切り替えは行われません。

* **視覚的な説明** ：共有コンテンツに直接注釈を付けて、重要なポイントを強調し、概念を明確にし、学習者の注意を導きます。

* **ツールの組み合わせ**：共有画面と一緒にホワイトボードを実行して、説明やメモを追加します。

* **参加を促す** ：学習者が自分の画面を共有して、自分の作品を発表したり、ディスカッションをサポートしたりできるようにします。インストラクターは、セッションを完全に制御できます。

## ロールと権限

画面共有は、インストラクターと学習者の両方が利用できます。 実行できるアクションは、ユーザーの役割によって異なります。
