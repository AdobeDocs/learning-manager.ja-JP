# ライブハブセッションでの作成者の役割

作成者はAdobe Learning Managerで、ライブハブを使用してインストラクターによるライブトレーニングを実施する、バーチャルクラスルームコースを作成および管理します。 コースの設定、セッションの設定、インストラクターの割り当て、パブリッシュを行って、セッションを実行できるようにします。

この記事では、Live Hubを使用する際の作成者の作業について説明します。

## 作成者が実行できる操作

作成者は、ライブハブコースを作成する際、次のタスクを行う必要があります。

### ライブハブコースの作成

作成者は、コースの作成ワークフローでライブハブコースを作成できます。 次のことができます。

* バーチャルクラスルームモジュールをコースに追加します。
* ライブバーチャルトレーニングツールとして、「ライブハブ」を選択します。
* タイトル、説明、長さなど、セッションの詳細を定義します。

### セッションの詳細を設定する

作成者は、ライブハブセッションの実行方法を定義できます。 次のことができます。

* 日付、時刻、およびタイムゾーンを設定
* セッション期間の設定

### インストラクターファインダーを使用したインストラクターの割り当て

インストラクターファインダーを使用し、コースの種類に基づいてインストラクターを検索して割り当てます。 次のことができます。

* コースの要件、スキル、利用可能性に基づいて、AIを活用したインストラクターの推奨事項を入手してください。
* セッションで有効なインストラクターを1人以上選択します。
* インテリジェントな推奨事項と簡単なインストラクターの割り当てにより、コースのセットアップをスピードアップします。

### Publishとコースの管理

設定が完了すると、作成者はコースの提供を完了して管理できます。 次のことができます。

* 学習者用コースのPublish
* 必要に応じてセッションの詳細を更新します
* コース構造とモジュールの管理

詳細については、[Live Hubセッションの作成](./create-a-live-hub-session.md)を参照してください。
