Live Hubには、管理者、作成者、インストラクター、学習者の役割が含まれ、それぞれがトレーニングワークフローの異なる部分を担当します。 このドキュメントでは、元のLive Hub FAQコンテンツを役割ごとに再編成しているため、各対象者は最も関連性の高い質問をすばやく見つけることができます。

## 管理者

+++Adobe Learning Managerアカウントでライブハブを有効にする方法を教えてください。

管理者としてログインし、学習/ライブハブでAIに移動します。 このアカウントでライブハブを有効にするをオンにすると、バーチャルクラスルームのトレーニングでライブハブを使用できるようになります。 有効にすると、作成者はAdobe Learning Manager内でライブハブセッションを作成できます。

+++

+++ライブハブをデフォルトのバーチャルクラスルームプロバイダーにすることはできますか？

はい。 ライブハブを有効にした後、ライブハブをデフォルトのライブトレーニングツールにします。 バーチャルクラスルームモジュールを作成すると、ライブハブが事前に選択されますが、必要に応じて別のプロバイダーを選択することもできます。

+++

+++管理者がライブハブセッションを有効にできるのは、どのAIアシスタントですか？

管理者はライブハブでAIを有効にし、作成者やインストラクターが使用できるAIアシスタントを選択できます。 利用可能なアシスタントは次のとおりです。

* 投票アシスタント： AIを使用して投票を生成します。
* Q&amp;Aアシスタント：学習者の質問と回答の下書きのフィルタリングに役立ちます。
* ブレークアウト監視アシスタント：ブレークアウトルームのディスカッションを監視します。
* トピック録画の生成：録画から構造化されたトピックとメモを作成します。
* インストラクターファインダーアシスタント： AIを使用したセッションに適したインストラクターを推奨します。

+++

## 作成者

+++自分のアカウントでLive Hubを使用できますか？

ライブハブ（ベータ版）は2026年8月から利用可能になります。 管理者は、Adobe Learning ManagerアカウントのLive Hubを有効または無効にできます。 ライブハブが有効になっている場合、作成者は、バーチャル教室モジュールの作成時にライブトレーニングプロバイダーとして選択できます。 Live Hubオプションが使用できない場合は、管理者に連絡してアカウントの機能を有効にしてください。

+++

+++ライブハブコースを作成するにはどうすればよいですか？

Adobe Learning Managerにログインし、「コースを作成」を選択します。 コースカタログページで、「追加」を選択し、コースの名前と説明を入力し、コースカタログにモジュールを追加します。 モジュールをバーチャルクラスルームとして設定し、配信ツールとしてライブハブを選択します。 利用可能なライブトレーニングプロバイダーとして表示されるには、Adobe Learning Managerアカウントでライブハブを有効にする必要があります。 利用可能なオプションのリストにLive Hubが表示されない場合は、管理者に連絡してください。

+++

+++どうすればコースをライブハブセッションとして設定できますか？

作成者はコースを作成し、バーチャルクラスルームモジュールを追加することができます。 モジュールの設定で、ライブトレーニングプロバイダーとしてLive Hubを選択し、タイトル、説明、スケジュール、タイムゾーンなど、必要なセッションの詳細を入力します。 モジュールを保存して、ライブハブでセッションをスケジュールします。

>[!NOTE]
>
>ライブハブが利用可能なライブトレーニングプロバイダーとして表示されるには、事前にAdobe Learning Managerアカウントの管理者がライブハブを有効にする必要があります。

+++

+++コースの作成時にインストラクターを追加できますか？

はい。 Live Hubを選択した後、セッションに1人以上のインストラクターを追加し、追加/保存を選択します。

+++

+++Live Hubコースを公開するにはどうすればよいですか？

コースの設定を完了したら、保存/Publishを選択します。 公開されると、コースは学習者の登録とセッションのスケジュール設定に使用できるようになります。

+++

## 学習プログラム / 資格認定を

### セッションに参加

+++インストラクターとしてLive Hubセッションに参加するにはどうすればよいですか？

Adobe Learning Managerにログインし、「今後のセッション」でセッションを見つけます。 セッションURLを選択して参加前画面を開き、「参加」を選択してセッションに入ります。

+++

+++参加者が到着する前にセッションに参加できますか？

はい。 インストラクターは、予定されている開始時刻より前にセッションに参加して、会議室の準備、AI回答参照用のコンテンツのアップロード、設定の構成を行うことができます。また、参加者が参加する前に、すべての準備が整っていることを確認できます。

+++

+++セッションの開始前に何を設定できますか？

セッション開始前に、インストラクターはバーチャルルームを準備できます。具体的には、学習者の権限の設定、投票とクイズの作成、ブレイクアウトルームの設定、共同作業のためのMiroの接続、セッション中のAIを活用したQ&amp;Aをサポートするための参考資料のアップロードなどです。

+++

### 学習者の権限とクローズドキャプション

+++参加者が画面を共有し、ホワイトボードを使用できるようにするには、どうすればよいですか？

セッションルームで、コントロールバーから「設定」を選択し、参加者の権限を選択します。 共有画面を有効にしてホワイトボードを使用し、「完了」を選択して変更を適用します。

+++

+++参加者の権限はどのような場合に設定すればよいですか？

会議室の準備の一環としてセッションを開始する前に学習者の権限を設定します。 これにより、参加者が参加する際に、適切な共同作業と参加の機能を持つことができます。

+++

+++クローズドキャプションをオンにするにはどうすればよいですか？

コントロールバーから「その他のオプション」を選択し、「キャプション」を選択して、「キャプションを表示」を有効にします。

+++

+++なぜクローズドキャプションを使用する必要があるのですか？

クローズドキャプションは、セッション中に音声コンテンツをテキストとして表示することで、アクセシビリティを向上させます。 参加者がより簡単にディスカッションを進められるように支援し、様々な学習環境やリスニング環境で参加者をサポートします。

+++

### 投票

+++AIを活用したIcebreakerポーリングを生成するには、どのような情報が必要ですか？

AIを活用したIcebreakerポーリングを生成するには、モジュール名とモジュールの説明を入力します。 Live Hubでは、この情報を使用して、セッション開始時に学習者の関心を引くために役立つ初歩的な質問を作成します。

+++

+++AIを活用したナレッジチェック投票を生成するには、何が必要ですか？

AIを活用したナレッジチェックの投票が、セッションのトランスクリプトから生成されます。 文字起こしが利用可能であり、ナレッジチェックポーリングを生成する前に十分なセッションコンテンツがキャプチャされていることを確認します。 生成される質問は、セッション中に議論されたトピックに基づきます。

+++

+++投票を作成するにはどうすればよいですか？

投票とクイズパネルを開き、「投票」タブを選択します。 投票を手動で作成するか、AIを使用して投票を生成し、「保存」を選択します。 投票がセッションに追加され、必要に応じて起動できるようになります。

+++

+++AIを使用して投票を生成できますか？

はい。 Live Hubでは、AIを活用した投票を生成し、セッション中の学習者の参加率を高めることができます。

* 「Icebreaker」を選択して、AIを活用した導入調査を生成します。
* 「ナレッジチェック」を選択して、話し合うトピックに対する参加者の理解を評価するためのアンケートを生成します。

+++

+++独自のアンケート質問を作成できますか？

はい。 独自の質問と回答オプションを使用してカスタム投票を作成するには、「独自に構築」を選択します。

+++

+++セッション中に投票を開始するにはどうすればよいですか？

[投票とクイズ]パネルで、 [投票]タブを選択し、新しい投票を作成するか、以前に保存した投票を選択します。 「起動」を選択して、参加者が投票できるようにします。 参加者はリアルタイムで回答を送信でき、回答が受信されると結果が自動的に収集されます。

+++

+++参加者に投票の結果を見せることはできますか？

はい。 投票を開始する場合は、「すべての学習者に結果を表示」を有効にして、セッション中に参加者と結果を共有します。

+++

+++投票はいつ使用すればよいですか？

投票を使用して、セッションへの参加を促したり、フィードバックを収集したり、ディスカッションを開始したり、セッション全体の学習者の理解度を評価したりします。 ナレッジチェック調査は、次のセクションに進む前に主要なトピックの理解を測定するのに特に便利です。

+++

### クイズ

+++クイズを作成するにはどうすればよいですか？

投票とクイズパネルを開き、「クイズ」タブを選択します。 「クイズを新規作成」を選択し、質問の種類を選択します。次に、質問と解答のオプションを追加し、正解を特定して「完了」を選択します。

+++

+++サポートされている質問タイプを教えてください。

ライブハブでは、次のクイズ質問タイプをサポートしています。

* 多岐選択：参加者は1つの正解を選択します。
* 複数回答：参加者は、該当するすべての回答を選択します。

+++

+++クイズに質問を追加するにはどうすればよいですか？

クイズの作成中に、 +質問を追加を選択して追加の質問を追加します。 質問の追加が終了したら、「完了」を選択します。

+++

+++セッション中にクイズを開始するにはどうすればよいですか？

「投票とクイズ」パネルで、「クイズ」タブを選択し、使用するクイズを見つけて、「起動」を選択します。 参加者は、クイズにリアルタイムで応答できます。

+++

+++クイズの結果を参加者に表示させることはできますか？

はい。 クイズを開始するとき、「すべての学習者に結果を表示」を有効にして、セッション中に参加者と結果を共有します。

+++

+++クイズはどのような場合に使用すればよいですか？

クイズを使用して、学習者の理解度を評価し、重要な概念を強調し、セッション中の知識保持を測定します。 クイズは、追加の説明やディスカッションが必要なトピックを特定するのに役立ちます。

+++

### ホワイトボード

+++ライブハブセッション中にホワイトボードを作成するにはどうすればよいですか？

セッションコントロールバーから「その他のオプション」を選択し、ホワイトボードを共有/新規ホワイトボードを選択します。 ホワイトボードがすぐに開き、セッションのすべての参加者に表示されます。

+++

+++セッション中に以前に共有したホワイトボードを再び開くことはできますか？

はい。 その他のオプション/ホワイトボードを共有を選択し、使用可能なボードのリストからホワイトボードを選択します。 選択したホワイトボードが開き、すべての学習者に表示されます。

+++

+++参加者がホワイトボードで共同作業することを許可できますか？

はい。 ホワイトボードメニューを開き、「参加者に描画を許可」を有効にします。 その後、学習者はホワイトボード上に描画したり、シェイプを追加したり、テキストを挿入したり、使用可能な注釈ツールを使用したりできます。

+++

+++後で参照できるように、ホワイトボードを保存したり書き出したりすることはできますか？

はい。 ホワイトボードメニューを開き、「スナップショットを書き出し」を選択します。 現在のホワイトボードコンテンツがPNG画像として書き出され、デバイスにダウンロードされます。

+++

+++セッション中に複数のホワイトボードを管理できますか？

はい。 ホワイトボードパネルを使用して、セッション中に作成されたすべてのホワイトボードを表示および管理します。 パネルから、ホワイトボードの共有、個別の掲示板の削除、すべてのホワイトボードの削除を行うことができます。

+++

### Miroとの共同作業

+++Miroは何に使用できますか？

Miroは、ライブハブセッション中のブレーンストーミング、アイデア、計画、その他のインタラクティブなアクティビティのための共同ワークスペースを提供します。 参加者は、リアルタイムで共有ボード上で共同作業を行うことができます。

+++

+++Miroをライブハブセッションに接続するにはどうすればよいですか？

セッションルームで「その他のアプリ」を選択し、ミロ/ミロにログインを選択します。 ログインウィンドウが開き、Miroアカウントに接続できます。

+++

+++Miroを使用するにはMiroアカウントが必要ですか？

はい。 Miroをライブハブセッションに接続してMiroボードにアクセスするには、まずMiroアカウントでログインする必要があります。

+++

+++Miroにログインするにはどうすればよいですか？

「 Miroにログイン」を選択した後、使用するアカウントを選択し、ログインプロセスを完了します。 接続すると、セッションから直接Miroにアクセスできます。

+++

### ブレイクアウトルーム

+++ブレイクアウトルームとは何ですか？

ブレイクアウトルームでは、参加者を小さなグループに分けて、ディスカッション、共同作業、問題解決の演習、チームベースの学習を行うことができます。

+++

+++ブレイクアウトルームを作成するにはどうすればよいですか？

ブレークアウトパネルを開き、ブレークアウトセッションの名前を入力し、ルームの数とデュレーションを指定し、参加者を割り当て、指示を追加して、「保存」を選択します。

+++

+++ブレークアウトルームに参加者を割り当てるにはどうすればよいですか？

「自動割り当て」を選択して、参加者を自動的に割り当てるか、参加者を特定の部屋にドラッグして手動で割り当てることができます。

+++

+++各ブレイクアウトルームは異なる指示を持つことができますか？

はい。 各ブレイクアウトルームに固有の指示を表示するには、「ルームに個別に設定」を選択します。

+++

+++セッション中に会議室を開始するにはどうすればよいですか？

設定したブレイクアウトセッションを開き、「ブレイクアウトを開始」を選択します。 参加者は、割り当てられた部屋に移動され、共同作業を開始できます。

+++

+++参加者を支援するブレイクアウトルームに参加できますか？

はい、ブレイクアウトルームのコントロールから「参加」を選択してルームに参加できます。

+++

+++ブレイクアウトルームのディスカッションを参加せずに監視するにはどうすればよいですか？

アクティブなブレークアウトセッション中に「会議室を確認」を選択すると、AIが生成した掲示板の概要がブレークアウトルームに表示されます。 概要は会話が展開されると自動的に更新されるので、学習者のディスカッションを監視し、アクティビティとの整合性を評価し、ルームに参加するかどうかを決定するのに役立ちます。

+++

+++ブレイクアウトセッションの終了後にブレイクアウトサマリーにアクセスできますか？

はい。 ブレイクアウトセッションが終了したら、「レポートを表示」を選択して、ルームごとの概要、参加者の詳細、アクティビティの指示、セッション情報を確認します。 ブレイクアウトインサイトはセッションダッシュボードにもあり、セッション後にサマリーを確認してセッションの結果を分析できます。

+++

+++ブレークアウトルームを終了するにはどうすればよいですか？

ブレイクアウトアクティビティの期間を設定すると、割り当てられた時間が経過したときにブレイクアウトルームが自動的に終了し、すべての参加者がメインセッションルームに戻ります。 また、「ブレークアウトを終了」を選択して、いつでもアクティビティを終了できます。 参加者は5秒間のカウントダウンを受け、メインセッションルームに戻ります。

+++

+++ブレークアウトルームはいつ使用すればよいですか？

ブレイクアウトルームは、参加者が小規模なグループでの共同作業、ディスカッションへの参加、チームアクティビティの完了、または演習を行う必要がある場合に使用してから、より大規模なオーディエンスと成果を共有します。

+++

+++ブレイクアウトセッションをスケジュールされた時間を超えて延長できますか？

はい。 インストラクターは、ブレイクアウトコントロールで「2分延長」を選択することで、アクティブなブレイクアウトセッションを延長できます。 セッションは、ブレイクアウトアクティビティごとに最大2回拡張できます。 更新された期間はすぐに適用され、参加者は中断することなくディスカッションや活動を継続することができます。

+++

### Q&amp;AとAIを活用した返信

+++AIが生成した回答の精度を向上させるにはどうすればよいですか？

セッションを開始する前に、関連する参照資料をアップロードして、AIがより正確でコンテキストに応じた応答を生成できるようにします。 チャットパネルで、「 AI参照をアップロード」を選択し、AIが参照コンテンツとして使用するファイルをアップロードします。

+++

+++参加者からの質問はどこで確認できますか？

「全員」タブの参加者が投稿した質問は、チャットパネルの「質問」タブに自動的に収集され、インストラクターが確認して対応できます。

+++

+++AIを利用した返信を生成するにはどうすればよいですか？

チャットパネルの「質問」タブを開き、質問にポインターを合わせ、AIベースの返信を選択します。 生成された応答を確認し、必要に応じて変更を加え、「送信」を選択します。

+++

+++AIが生成したレスポンスを送信する前に編集できますか？

はい。 AIが生成したレスポンスは編集可能です。 コンテンツを送信する前に内容を確認および変更して、回答が参加者にとって正確かつ適切であることを確認できます。

+++

+++AI参照資料をアップロードする必要があるのはなぜですか？

参考資料には、AIがセッションコンテンツにより関連性の高い応答を生成するのに役立つ追加のコンテキストが提供されるため、FAQに手動で回答する必要性が軽減されます。

+++

+++AIは学習者の質問に自動的に応答しますか？

掲示板で AIは、インストラクターがレビューするための推奨レスポンスを生成します。 インストラクターが、参加者に回答を編集して送信するかどうかを決定します。

+++

+++AIを使用した返信は、プライベートチャットやブレイクアウトルームで質問された場合に機能しますか？

掲示板で AIを使用した返信は、メインセッションルームのEveryoneチャットに投稿された質問やメッセージに対してのみ使用できます。 プライベートチャットやブレイクアウトルームのチャットで質問された質問は、AIを活用した回答の生成には含まれません。

+++

+++AIを活用した質問の分類と回答の生成に使用されるチャットメッセージはどれですか？

AIを活用した質問分類と回答生成は、メインセッションルームのEveryoneチャットに投稿されたメッセージを使用します。 プライベートチャットやブレイクアウトルームのチャットからのメッセージは、これらのAI機能では処理されません。

+++

### チャットとメッセージング

+++どのチャットタブを利用できますか？

チャットパネルには、次のタブがあります。

* 全員：すべてのセッション参加者とメッセージを共有します。
* 非公開：個別の参加者と1対1のメッセージを交換します。
* 質問：セッション中に送信された学習者の質問を表示および管理します。

+++

+++セッション中に学習者と非公開の会話を行うことはできますか？

はい。 チャットパネルの「非公開」タブを開き、参加者を選択してメッセージを入力し、「送信」を選択します。 非公開会話は、チャットに参加した参加者にのみ表示されます。

+++

### セッションの録画

+++セッションを記録するにはどうすればよいですか？

セッション中に、コントロールバーから「詳細オプション」を選択し、「記録」を選択します。 録音が開始されたことを示す確認メッセージが表示されます。

+++

+++セッションは録音・録画されますか？

はい。 録画が開始されると、Live Hubは自動的にセッションの文字起こしを開始します。 録音および録音が開始されたことを示す確認メッセージが表示されます。

+++

+++セッションを記録する理由

セッションを記録すると、参加者やインストラクターは、セッション終了後にコンテンツに再びアクセスできるようになります。 レコーディングは、ディスカッションのレビュー、キーコンセプトの強化、ライブセッションに参加できなかった参加者のサポートに役立ちます。

+++

### コンテンツの共有

+++画面を共有するにはどうすればよいですか？

コントロールバーから「スクリーンを共有」を選択し、ブラウザータブ、アプリケーションウィンドウ、またはスクリーン全体のいずれを共有するかを選択してから、「共有」を選択します。 選択したコンテンツが、すべての参加者に表示されます。

+++

+++セッション中に共有できるものは何ですか？

表示するコンテンツに応じて、ブラウザータブ、特定のアプリケーションウィンドウ、または画面全体を共有できます。

+++

+++共有コンテンツに注釈を付けることはできますか。

はい。 画面を共有しながら、「注釈」を使用して、情報をハイライト表示したり、重要な領域に注目を集めたり、リアルタイムで参加者と共同作業を行ったりします。

+++

+++画面に表示されている内容を保存できますか？

はい。 オプションメニューから「スナップショットの書き出し」を選択して、現在の共有ビューをキャプチャして保存します。

+++

+++参加者に画面の共有を許可できますか？

はい。 インストラクターが「共有画面」権限を有効にしている場合、参加者は画面を共有できます。 プレゼンテーション時に、参加者は注釈ツールを使用したり、スナップショットを書き出したりすることもできます。

+++

+++スクリーン共有はどのような場合に使用すればよいですか？

スクリーン共有を使用すると、スライドの表示、アプリケーションのデモ、Webサイトのウォークスルー、ドキュメントのレビュー、ライブセッション中のタスクやワークフローのガイドを行うことができます。

+++

### 出席者の管理

+++出席者パネルでは何ができますか？

出席者パネルを使用すると、セッションの参加状況を監視し、参加者を管理できます。 出席者のステータスやリアクションの確認、挙手の管理、および参加者とのコミュニケーションが可能です。

+++

+++誰が出席しているか、または誰が欠席しているか、どうすれば確認できますか。

出席者パネルには、登録済みの参加者が表示され、その参加者が出席しているかどうかが示されます。 また、学習者の反応と挙手のステータスも表示されます。

+++

+++すべての学習者のマイクを一度にミュートできますか？

はい。 出席者パネルでは、参加者全員のマイクをミュートして、バックグラウンドノイズを軽減し、セッション中にフォーカスを維持することができます。

+++

+++すべての上げた手を一度に下ろせますか。

はい。 出席者パネルには、すべての挙手を同時に下げるオプションが含まれています。これは、Q&amp;Aセッション後またはディスカッションが終了したときに便利です。

+++

+++出席者パネルから学習者にプライベートメッセージを送信できますか。

はい。 インストラクターがプライベートメッセージングを有効にしている場合は、「参加者」パネルを使用すれば、他の参加者のセッションを中断することなく、個々の学習者とのプライベート会話を開始できます。

+++

+++セッションで出席者パネルを使用する理由

出席者パネルには、学習者の参加状況が一元的に表示されるため、インタラクションの管理、エンゲージメントのシグナルへの応答、セッションのスムーズな進行が容易になります。

+++

### セッションの参加度の監視

+++参加者のエンゲージメントの度合いを確認するにはどうすればよいですか？

セッションルームの上部にある参加度インジケーターを使用して、セッション全体の学習者の参加度を監視します。

+++

+++参加度インジケーターとは何ですか？

エンゲージメントインジケーターは、セッション中の学習者の参加状況をインストラクターが全体的に把握するのに役立ちます。 エンゲージメントは、会話、チャットへの参加、セッションとのやり取りなどの学習者のアクティビティに基づいて計算されます。 個々のエンゲージメントスコアは定期的に更新され、集計されて、全体的なセッションエンゲージメントレベルを提供します。

エンゲージメントインジケーターには、次のいずれかのレベルが表示されます。

* 高（緑）：学習者のエンゲージメントのレベルが高いことを示します。
* 中（黄色）：学習者のエンゲージメントが中レベルであることを示します。
* 低（赤）：学習者のエンゲージメントのレベルが低いことを示します。

エンゲージメントスコアは、学習者ごとに計算され、定期的に更新されます。 セッション全体のエンゲージメントレベルは、セッションのすべての参加者の平均エンゲージメントを表します。 インストラクターは計算から除外されます。 学習者のスコアは、次のようにマッピングされます。

* 0～30：低いエンゲージメント
* 31-60：中規模エンゲージメント
* 61～100：高いエンゲージメント

このインジケーターは、参加全体の概要を簡単に表示し、インストラクターがアクティビティを調整して学習者のエンゲージメントを向上させるのに役立ちます。

+++

+++参加者の参加度インジケーターはどこにありますか？

参加者の参加度インジケーターはセッションルームの上部に表示され、インストラクターはセッションを中断することなく参加度を監視できます。

+++

+++参加者のエンゲージメントを監視する必要があるのはなぜですか？

エンゲージメントの監視は、参加者がセッションにどの程度積極的に参加しているかを理解するのに役立ちます。 エンゲージメントインサイトは、投票、クイズ、ディスカッションなどのアクティビティを導入するタイミングを決定するのに役立ち、参加を促し、参加者を継続的に参加させることができます。

+++

### セッションの終了

+++全員のセッションを終了するにはどうすればよいですか？

「退出」を選択し、確認ダイアログボックスで「すべてのセッションを終了」を選択します。 これにより、すべての参加者のセッションが終了します。

+++

+++セッションを終了するとどうなりますか？

すべての参加者がセッションから削除され、セッション完了画面にリダイレクトされます。 そこから、コースページに戻ることができます。

+++

+++AllにEnd Sessionを使用する必要があるのは、どのような場合ですか。

トレーニングセッションが終了し、すべての参加者の会議室を同時に閉じる場合は、「すべての参加者のセッションを終了」を使用します。

+++

### セッション録画と分析

+++セッション後の録画と分析はどこで確認できますか？

セッションが終了すると、セッションの概要ページからセッションの記録、トランスクリプト、分析にアクセスできます。

+++

+++セッション録画を表示するにはどうすればよいですか？

過去のセッションに移動し、確認するセッションを選択してから、「セッションの記録」セクションの「表示」を選択します。 記録を変更するには、「編集」を選択します。

+++

+++セッション分析を開くにはどうすればよいですか？

過去のセッションに移動し、必要なセッションを選択してから、セッション分析URLを選択して分析ダッシュボードを開きます。

+++

+++セッション分析にはどのような情報が含まれますか？

セッション分析では、次のようなセッションのアクティビティと学習者のエンゲージメントに関するインサイトが提供されます。

* セッションの概要：セッションの詳細と記録情報を表示します。
* インタラクション：投票、クイズ、ブレイクアウトルーム、Q&amp;A、リアクションアクティビティをレビューします。
* 参加者のアクティビティ：セッション全体にわたる学習者の参加とエンゲージメントを監視します。
* レポート：セッションレポートとインタラクションデータをダウンロードして、さらに分析します。

+++

+++セッションのトランスクリプトは、セッションの終了後に確認できますか？

はい。 録音と同時にセッションのトランスクリプトも利用できるため、ディスカッションの確認や特定のトピックの再検討が容易になります。

+++

+++セッション分析をレビューする理由

セッション分析は、参加者がコンテンツとどのように対話したかを理解し、参加の傾向を特定し、エンゲージメントレベルを測定し、トレーニングセッションの有効性を評価するのに役立ちます。

+++

## 学習者

### コースの登録

+++コースに自分自身を登録できますか？

はい。 コースがセルフ登録用に設定されている場合は、「カタログ」ページから直接登録できます。 登録後、コースは「学習状況」で利用できるようになります。

+++

+++登録されたことを確認する方法はありますか？

登録すると、Adobe Learning Managerの学習プランにコースが追加されます。 また、アプリ内通知も届きます。 組織の通知設定によっては、招待メールが届きます。

+++

+++登録後のコースはどこで確認できますか？

登録済みコースには、Adobe Learning Managerの「学習状況」からアクセスできます。

+++

### セッションに参加

+++学習者がライブハブセッションに参加するにはどうすればよいですか？

Adobe Learning Managerにログインし、「学習状況」に移動します。 登録済みのコースを開き、スタート/セッションへ移動を選択し、「参加」を選択します。

+++

### クローズドキャプション

+++クローズドキャプションをオンにするにはどうすればよいですか？

コントロールバーから「 CC 」を選択して、クローズドキャプションをオンにします。 「 CC 」をもう一度選択して、オフにします。

+++

+++なぜクローズドキャプションを使用する必要があるのですか？

クローズドキャプションは、セッション中に音声コンテンツをテキストとして表示することで、アクセシビリティを向上させます。 これにより、ディスカッションをより簡単にフォローし、様々な学習およびリスニング環境への参加をサポートできます。

+++

### セッション中に参加する

+++クイズや投票を行うにはどうすればよいですか？

セッション中にインストラクターがクイズや投票を公開すると、学習者の画面にそのクイズや投票が自動的に表示されます。 画面の指示に従い、表示された質問の種類に基づいて回答を送信します。

+++

+++投票結果を見ることはできますか？

はい。インストラクターが投票の開始時に「すべての学習者に結果を表示」を有効にしている場合は、セッション中に参加者と共有された結果を表示できます。

+++

+++クイズの結果を表示できますか？

はい。インストラクターがクイズの開始時に「すべての学習者に結果を表示」を有効にしている場合は、セッション中に参加者と共有した結果を表示できます。

+++

+++セッション中にチャットを使用する必要があるのはなぜですか？

チャットを使用すると、プレゼンターの作業を中断することなく、ディスカッションへの参加、質問、フィードバックの共有を行うことができます。 マイクへのアクセスが制限されている場合や、プレゼンテーションの進行中にマイクを使用して発言したい場合に、この機能は特に便利です。

+++

+++セッション中に質問するにはどうすればよいですか？

チャットパネルの「全員」タブを使用して、質問をしたり、コメントを共有したり、ディスカッションに参加したりできます。 メッセージを入力し、「送信」を選択します。 このタブに投稿されたメッセージは、すべてのセッション参加者に表示されます。

+++

+++セッション中にプライベート会話をすることはできますか？

はい。 チャットパネルの「非公開」タブを開き、参加者を選択してメッセージを入力し、「送信」を選択します。 非公開会話は、チャットに参加した参加者にのみ表示されます。

+++

+++セッション中にインストラクターに質問するにはどうすればよいですか？

質問は、次のいずれかの方法で行うことができます。

* 質問を「全員」タブに投稿して、すべてのセッション参加者に表示されるようにします。
* 質問をインストラクターのみに表示する場合は、インストラクターにプライベートメッセージを送信します。

+++

+++プライベートチャットはどのような場合に使用すればよいですか？

非公開チャットは、個々のフォローアップの質問、説明、またはオーディエンス全体とは関係のない会話に使用します。

+++

+++画面を共有できますか？

はい。 画面を共有するには、インストラクターが「画面を共有」権限を有効にします。 プレゼンテーション時には、注釈ツールを使用したり、スナップショットを書き出すこともできます。

+++

### ブレイクアウトルーム

+++ブレイクアウトルームでのディスカッションの概要を表示できますか？

はい。 ブレイクアウトセッションが終了すると、表示していた部屋について、AIが生成したレポートを表示できます。 このレポートには、検出されたアクティビティタイプと、グループで話し合った重要なポイントの書き込み概要が含まれます。 画面の右下にある「ブレイクアウト（グリッド） 」アイコンを選択し、ブレイクアウトセッションを選択して、「概要」を選択します。

+++

+++以前に入っていた他のブレイクアウトルームまたはルームからのレポートを表示できますか？

掲示板で 最後に表示したルームのレポートのみを表示できます。 同じブレイクアウトセッション中にインストラクターが別のルームに移動した場合、最新のルームの概要のみが表示され、他の参加者のルームからのレポートは表示されません。

+++

### セッションの終了後

+++セッション後に録画にアクセスできますか？

はい。 セッションが終了すると、セッションで設定されている権限と記録設定に従って、コースから記録にアクセスできます。 トピックに直接移動して、記録の対応するセグメントを表示し、そのトピックに焦点を当てたAIが生成した概要を確認できます。これにより、記録全体を見ることなく、特定のディスカッションや重要なポイントに簡単に戻ることができます。

+++

+++録画されたセッションの後、どのような追加コンテンツを利用できますか？

録画に加えて、Live Hubにはセッションのトランスクリプトが用意されており、ディスカッションのレビューや特定の情報の検索が容易になります。 AIが生成したトピックでは、主要なディスカッション領域に記録を整理し、トピック固有の概要を含めます。 トピックは、記録の複数の連続しないセグメントにまたがることができます。これにより、セッション全体を手動で検索することなく、そのトピックに関連するすべての場面を表示できます。

+++

+++セッション終了後にフィードバックを提供することはできますか？

はい。 セッション完了画面で、オーディオとビデオのエクスペリエンスに関するフィードバックを共有できます。
