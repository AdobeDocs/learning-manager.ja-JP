# 必要システム構成

Adobe Learning Managerでライブハブセッションを設定および実行するには、以下の必要システム構成を使用します。 ライブハブは、実行するバーチャルクラスルーム環境と同じブラウザー、オペレーティングシステム、ハードウェア要件を使用します。

Live Hubはバーチャルクラスルームセッション内で利用でき、個別のクライアントインストールは必要ありません。

| カテゴリ | 要件 |
|---|---|
| **デスクトップブラウザー** | 最新バージョンのGoogle Chrome、Mozilla Firefox、Microsoft EdgeおよびSafari |
| **モバイルブラウザー** | Chromeモバイル版、Safariモバイル版、およびSamsungインターネット版 |
| **オペレーティングシステム** | Windows 10以降、macOS 15以降 |
| **画面解像度** | 1920 × 1080、1366 × 768、768 × 1024（タブレット）、および375 × 667（モバイル） |
| **Windowsハードウェア** | 8 GB以上のRAM、8コアプロセッサー、Intel® Core™ i5以上 |
| **Macハードウェア** | 16 GB以上のRAM、4コアプロセッサー、3.2 GHz以上 |
| **ネットワーク** | ライブオーディオ、ビデオ、およびAIを活用したライブハブ機能には、少なくとも5 Mbpsの安定したブロードバンド接続を推奨 |

>[!NOTE]
>
>Linuxブラウザー、Chromebookデバイス、Firefoxモバイル版、Opera（デスクトップ版およびモバイル版）、Internet Explorer 11および以前のバージョンのブラウザーはサポートされていません。
