# ホワイトボードを学習者として使用する

ホワイトボードは、ライブハブセッション中に共有ビジュアルワークスペースを提供します。 インストラクターがホワイトボードへのアクセスを許可すると、共有カンバス上で描画、シェイプやテキストの追加、コンテンツの消去を行うことができます。 ホワイトボードを使用して、アイデアを説明し、問題を解決し、リアルタイムの共同作業に参加します。

この記事では、Live Hubで学習者としてホワイトボードを使用する方法について説明します。

## ホワイトボードの使用

インストラクターが学習者にホワイトボードの編集を許可している場合、ライブセッション中にホワイトボードを操作できます。 セッションでは、次の操作を実行できます。

* マーカーツールを使用して、ホワイトボードに描画します。

* シェイプとテキストを追加して、コンテンツを作成または投稿します。

* ホワイトボードから描画、図形、またはオブジェクトを消去します。

![学習者ホワイトボードツール](assets/learner-whiteboard-tools.png)
*学習者は、共有ホワイトボード上で描画、図形やテキストの追加、コンテンツの消去を行うことができます。*

詳細については、[ホワイトボードツールを使用する](../getting-started-with-live-hub/share-a-whiteboard.md#use-whiteboard-tools)を参照してください。
