# 学習者としてモバイルでライブハブ（ベータ版）を使用する

Adobe Learning Managerモバイルアプリを使用すると、iOSまたはAndroidデバイスからライブハブセッションに参加および参加できます。 セッション中、インストラクターや参加者との対話、投票やクイズへの応答、ブレイクアウトルームでの共同作業、モバイルデバイスからの共有コンテンツへの直接アクセスを行うことができます。

>[!NOTE]
>
> モバイルアプリは、Live Hubのコア参加機能をサポートしています。 デスクトップエクスペリエンスで使用できる一部の機能が、モバイルデバイスでは使用できません。 デスクトップでサポートされている機能の一覧については、[Live Hubの概要](./getting-started-live-hub.md)を参照してください。

## モバイルでの学習者エクスペリエンス

次の表は、モバイルアプリの学習者が利用できるライブハブ機能をまとめたものです。

| **機能** | **モバイルエクスペリエンス** |
|----|----|
| セッションに参加 | Adobe Learning Managerモバイルアプリからライブハブセッションに参加します。 |
| オーディオとビデオ | マイクとカメラの電源をオンまたはオフにし、使用可能なオーディオデバイスを選択します。 |
| チャットと質問 | セッション中は、チャットに参加して質問を送信できます。 |
| リアクションと手の挙げ | リアクションを送信し、手を上げてインストラクターと協働します。 |
| 投票 | セッション中に公開されたポーリングに応答します。 |
| クイズ | インストラクターが起動したクイズを試行します。 |
| ブレイクアウトルーム | 割り当てられたブレイクアウトルームへの参加、他の参加者との共同作業、インストラクターのサポートのリクエスト、ブレイクアウトの概要の表示を行うことができます。 |
| ホワイトボードと共有コンテンツ | セッション中に共有されたコンテンツを表示して操作できます。 |
| ミラーボード | インストラクターが共有するミロの掲示板を表示します。 |
| クローズドキャプション | セッション中にクローズドキャプションのオンとオフを切り替えます。 |
| 画面共有 | インストラクターまたは参加者が共有したコンテンツを表示します。 |
| セッション録画 | セッション終了後に利用可能になった場合、録画にアクセスできます。 |

## ライブハブセッションに参加

Adobe Learning Managerモバイルアプリから、スケジュールされたライブハブセッションに参加します。

参加する前に、カメラ、マイク、オーディオデバイスの設定を確認して、正しく設定されていることを確認できます。

![モバイルの参加前画面](assets/mobile-pre-join-screen.png)
*カメラ、マイク、オーディオデバイスの設定を確認してから、モバイルのLive Hubセッションに参加してください。*

>[!NOTE]
>
> 仮想の背景と背景のぼかし効果は、モバイルアプリではサポートされていません。

## セッションインターフェイスの操作

セッションに参加すると、メインセッションビューに参加者のビデオタイルまたは共有コンテンツが、コミュニケーションと参加のコントロールとともに表示されます。

セッションコントロールを使用して、次の操作を行います。

* マイクの電源をオンまたはオフにします。

* カメラの電源をオンまたはオフにします。

* 手を挙げなさい。

* リアクションを送信します。

* チャットや質問にアクセスできます。

* 投票とクイズに参加します。

* ブレイクアウトルームのアクティビティに参加しましょう。

* セッションを終了します。

## クローズドキャプションの使用

クローズドキャプションは、セッション中に音声コンテンツをフォローするのに役立ちます。

Live Hubセッションに参加している間は、いつでもキャプションのオンとオフを切り替えることができます。

>[!NOTE]
>
> フォントサイズや表示スタイルなどのキャプションの書式設定オプションは、モバイルアプリでは使用できません。

## チャットでの質問

チャットパネルを使用して、インストラクターや他の参加者とコミュニケーションを取ります。

次のことができます。

* メッセージをセッションチャットに投稿します。

* インストラクターと参加者からのメッセージを表示します。

* セッション中に質問を送信します。

* インストラクターから提供された回答を確認します。

## 世論調査に対応する

インストラクターが投票を開始すると、セッションに自動的に表示されます。

![投票に返信するモバイル](assets/mobile-respond-to-poll.png)
*Adobe Learning Managerモバイルアプリから投票に直接返信する。*

応答はモバイルアプリから直接送信できます。 ポーリングの構成によっては、応答後にポーリング結果を表示することもできます。

## 試行クイズ

インストラクターがクイズを起動した場合、セッションを終了せずにモバイルデバイスからクイズを完了できます。

クイズ結果と解答の表示は、インストラクターが設定した設定によって異なります。

## ブレイクアウトルームに参加

セッション中にブレイクアウトルームが使用された場合、インストラクターがルームを割り当てます。

![モバイルブレイクアウトルームビュー](assets/mobile-breakout-room-view.png)
*モバイルで利用できる共同作業オプションを表示するブレイクアウトルームのビュー。*

ブレイクアウトルームでは、次の操作を行うことができます。

* 他の参加者との共同作業。

* ブレークアウトアクティビティに参加します。

* インストラクターにサポートを依頼します。

* ブレイクアウトの概要が利用可能な場合はそれを確認します。

ブレイクアウトルームの割り当てとタイミングはインストラクターが管理します。

## 共有コンテンツを表示

セッション中、インストラクターはプレゼンテーション、ホワイトボード、ミロボード、その他のコンテンツを共有することができます。 共有コンテンツをモバイルアプリで直接表示し、ディスカッションやアクティビティに従うことができます。

![モバイルビューの共有コンテンツ](assets/mobile-view-shared-content.png)
*インストラクターが共有したコンテンツをモバイルアプリで直接表示できます。*

## セッションから退出

セッションを終了する準備ができたら、[**退出**]を選択します。

![モバイル離脱セッション](assets/mobile-leave-session.png)
*退出を選択して、モバイルアプリからセッションを終了します。*

退出後、セッションエクスペリエンスに関するフィードバックを提供するように求められます。
