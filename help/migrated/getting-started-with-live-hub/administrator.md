# ライブハブセッションでの管理者の役割

Adobe Learning Manager(ALM)の管理者は、ライブハブのトレーニングの提供に必要な主要コンポーネントを設定および管理できます。 これらの機能は、インストラクターの割り当て、コースの設定、ブランディング、レポート作成を合理化するのに役立ちます。

この記事では、ライブハブセッションに関連する管理者アクションの概要を説明します。 設定手順とワークフローについて詳しくは、各セクションのリンク先の記事を参照してください。

## ライブハブの管理者機能

管理者は、以下の機能を使用して、ライブハブのトレーニングを設定および実行できます。 手順について詳しくは、リンク先の記事を選択してください。

| **機能** | **実行できる操作** | **詳細情報** |
|----|----|----|
| **Live Hubを有効にする** | Adobe Learning Managerアカウントでライブハブを有効にします。 また、ライブハブセッション中に以下のような作成者やインストラクターをサポートする、AIを使用したアシスタントを有効にすることもできます。 <ul><li>投票アシスタント</li><li>Q&amp;A アシスタント</li><li>ブレイクアウトモニタリングアシスタント</li><li>トピックの記録ジェネレータ</li><li>講師検索アシスタント</li></ul> | [Live Hub機能を有効にする](../administrators/feature-summary/enable-live-hub.md) |
| **インストラクタープロファイルの管理** | <ul><li>インストラクターの役割と責任の定義</li><li>スキルと専門知識の割り当て</li><li>作業状況と授業の環境設定</li><li>インストラクターファインダーを通じてよりスマートな推奨事項を有効化</li></ul> | [インストラクターの追加と管理](./instructor-management.md) |
| **一括スキルの追加** | <ul><li>スキルを一括で追加</li><li>スキルセットの整理と更新</li><li>スキルをコースの要件に合わせる</li></ul> | [スキルとレベルの作成および変更](../administrators/feature-summary/skills-levels.md#add-skills-in-bulk) |
| **休日の管理** | <ul><li>1つの祝日を追加するか、CSVファイルをアップロードして一度に複数の祝日を読み込みます</li><li>各休日に日付、名前、説明（任意）を設定する</li><li>「すべて」、「今後の予定」、「過去」の各タブで休日を確認、検索、フィルタリング</li><li>アカウント全体で一貫した祝日カレンダーを1つ管理する</li></ul> | [休日の管理](./manage-holidays.md) |
| **ブランディングとカラーテーマの設定** | <ul><li>カラーテーマの適用</li><li>セッション間で一貫した視覚的IDを維持</li><li>ブランド環境で学習者のエクスペリエンスを向上</li></ul> | [カラーテーマ](../administrators/feature-summary/themes.md#color-themes) |

>[!NOTE]
>
>Live Hubに関するよくある質問への回答については、[Live Hubに関するよくある質問](./frequently-asked-questions-for-live-hub.md#administrator)をご覧ください。
