# ホワイトボードについて

ホワイトボードは、ライブハブセッション内の共有デジタルカンバスです。インストラクターと学習者は、リアルタイムで共同作業できます。 教室のホワイトボードのように機能しますが、オンラインで行うことができます。フリーハンドでの描画、シェイプとテキストの追加、アイデアに注釈を付ける、複数のボード間でコンテンツを整理する、これらすべてがセッションの全員に表示されるようにすることができます。

ホワイトボードは以下を支援します。

* 視覚補助を使用して複雑なトピックを説明します。

* ライブセッション中に、学習者とインタラクティブに共同作業を行うことができます。

* 複数の掲示板やページにわたってコンテンツを整理します。

インストラクターは、ライブハブでホワイトボードを共有して、コンセプトの視覚的な説明、アイデアへの注釈の追加、学習者とのリアルタイムの共同作業を行うことができます。 ホワイトボードは、描画ツール、シェイプ、テキスト、ズームコントロール、共同作業機能を備えた共有カンバスを提供します。 インストラクターが編集権限を有効にしている場合は、学習者もコンテンツの描画、シェイプの追加、消去を行うことができます。
