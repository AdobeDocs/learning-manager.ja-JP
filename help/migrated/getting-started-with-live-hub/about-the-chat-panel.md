# チャットパネルについて

ライブハブのチャットパネルでは、ライブセッション中にインストラクターと学習者の間でリアルタイムのコミュニケーションが可能です。 パブリックディスカッション、プライベートな会話、構造化された問題処理をサポートし、学習者のエンゲージメントを維持しながら、インストラクターがインタラクションを効率的に管理できるようにします。

## 主な利点

* **改善されたインタラクション** ：インストラクターと学習者の間でリアルタイムのコミュニケーションが可能になりました。

* **構造化されたディスカッション**: [全員]、[プライベート]、および[質問]用の個別のタブにより、会話を整理できます。

* **質問の効率的な処理** : AIを活用したサポートにより、インストラクターは質問を特定し、迅速に対応することができます。

* **モデレート制御**:インストラクターは、生産的なディスカッション環境を管理および維持できます。

* **コンテキストコミュニケーション** ：返信およびメンション機能により、会話を明確にします。

## チャットパネルタブ

チャットパネルには、ライブハブセッション中の様々な種類の会話を管理するのに役立つ複数のタブが含まれています。

* **全員**：このタブを使用して、すべての参加者に表示されるメッセージを送信および表示します。 また、このタブに投稿されたメッセージから、AIによって学習者の質問が検出されます。

* **プライベート**：このタブを使用して、セッション中に特定の参加者と1対1の会話を行います。

* **質問**：このタブには、パブリックチャットからAIによって識別された質問が表示されます。 インストラクターは、質問を効率的にレビュー、グループ化、回答できます。

>[!NOTE]
>
> 「**質問**」タブは、インストラクターのみが使用できます。

## ロールと権限

チャットパネルは、インストラクターと学習者の両方が使用できます。 パネルで使用できるアクションやコントロールは、バーチャルクラスルーム内のユーザーの役割によって異なります。
