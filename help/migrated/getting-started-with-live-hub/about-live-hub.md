# ライブハブについて

Live Hubは、バーチャルクラスルームをネイティブにAdobe Learning Managerに取り込むため、学習管理システム(LMS)と会議ツールを切り替える必要がありません。 すべてのセッションは自動的に追跡され、豊富なセッションダッシュボードにより、出席だけでなく、学習者のエンゲージメント状況がインストラクターに示されます。

ライブトレーニング用に意図的に構築された、ライブハブのAI担当者は、インストラクターと一緒に作業します。 受講者は世論調査を提案し、参加者の質問を検出して回答を提案し、ブレイクアウトルームをライブで監視し、セッションの概要を作成するので、インストラクターはトレーニングの実施に集中できます。 また、学習者の場合、録画は自動的にナビゲート可能なトピックにセグメント化され、ライブに参加するのと同様に、構造化された便利なリプレイを作成します。

Live Hubは、インストラクターが魅力的なバーチャルトレーニングを提供し、組織が大規模なインタラクティブなライブトレーニングを実行するのに役立ちます。 ライブハブ（ベータ版）は、今後の8月リリースのAdobe Learning Managerで間もなくローンチされます。
