# ライブハブについて

Live Hubは、バーチャルクラスルームをネイティブにAdobe Learning Managerに取り込むため、学習管理システム(LMS)と会議ツールを切り替える必要がありません。 すべてのセッションは自動的に追跡され、豊富なセッションダッシュボードにより、出席だけでなく、学習者のエンゲージメント状況がインストラクターに示されます。

ライブトレーニング用に意図的に構築された、ライブハブのAI担当者は、インストラクターと一緒に作業します。 受講者は投票を提案し、参加者の質問を検出して回答を提案し、ブレイクアウトルームをリアルタイムで監視し、セッションの概要を作成するので、インストラクターはトレーニングセッションの実施に集中できます。 学習者の場合、録画は自動的にナビゲート可能なトピックにセグメント化され、再生が構造化されてライブに参加するのと同じように便利になります。

Live Hubは、インストラクターが魅力的なバーチャルトレーニングを提供し、組織が大規模なインタラクティブなライブトレーニングを実行するのに役立ちます。

>[!NOTE]
>
>ライブハブは、今後のAdobe Learning Managerの&#x200B;**8月リリース**&#x200B;で利用できるようになります。 Live Hubのドキュメントは、機能がリリースされると利用可能になります。
