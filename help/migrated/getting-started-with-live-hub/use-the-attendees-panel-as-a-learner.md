# 出席者パネルの学習者としての使用

学習者は、出席者パネルを使用して、ライブハブセッションの他の参加者を表示し、インストラクターが有効にした権限に基づいて参加者と対話できます。 他の参加者の表示、参加者の詳細の確認、他の参加者からのメッセージが利用可能な場合はそれを送信することができます。 このガイドでは、出席者パネルを開き、学習者として他の出席者と対話する方法について説明します。

## 出席者パネルへのアクセス

出席者パネルを使用すると、セッションの他の出席者を表示し、インストラクターが有効にした権限に基づいて操作できます。

パネルを開くには、コントロールバーから![open-attendees-panel](./assets/open-attendees.svg)を選択します。 このパネルにはセッションの全員が一覧表示されるので、誰が出席しているかを確認できます。

## 他の参加者との交流

**出席者**&#x200B;パネルから、インストラクターが有効にした権限に基づいて参加者と対話できます。

これらのアクションにアクセスするには、パネルの参加者の名前の横にある&#x200B;**その他のオプション(⋯)**&#x200B;アイコンを選択します。

![出席者オプションメニューの表示](assets/view-attendee-options-menu.png)
*詳細オプションメニューを選択して、学習者の詳細を表示し、学習者に個人的にメッセージを送信します。*

学習者は、次のアクションを実行できます。

| **操作** | **説明** |
|----|----|
| **プライベートメッセージを送信する** | 参加者とのプライベートチャットを開きます。 |
| **プロファイルの表示** | 学習者のプロファイル情報を表示します。 |
