# マネージャーとして外部の学習要求をレビューする

チームの学習者がAdobe Learning Managerで外部学習リクエストを送信すると、プラットフォーム内通知が届きます。 提出内容の詳細を確認したり、リクエストを承認または却下したり、学習者にコメントを追加したりできます。

## マネージャーレビューワークフローの仕組み

学習者が社外学習リクエストを送信すると、以下が行われます。

1. 送信内容を確認するよう求める&#x200B;**アプリ内通知**&#x200B;が届きます。 送信された内容は、マネージャーダッシュボードの「**外部学習**」タブに表示されます。
2. 送信を開き、すべてのフィールドとアップロードされた文書を証明として確認し、「**承認**」または「**却下**」を選択します。
3. 学習者が通知を受け取ったときに表示される&#x200B;**レビューコメント**&#x200B;を追加できます。
4. 学習者は、お客様の決定事項を含む&#x200B;**プラットフォーム内通知**&#x200B;を受け取ります。

提出を承認すると、社外学習アクティビティが&#x200B;**管理者学習者トランスクリプト**&#x200B;に追加され、学習者のトランスクリプトレコードに表示されます。

## 提出物の確認と承認または却下

1. Adobe Learning Managerにマネージャーとしてログインします。

2. 左側のナビゲーションウィンドウで&#x200B;**外部学習**&#x200B;を選択します。

3. 送信リストで、確認するリクエストを選択します。 提出物は、提出日で並べ替えられ、最新のものが最上位に表示されます。

4. 提出物全体を確認します。

   - タイトル、説明、日付、期間、スコア

   - 管理者が設定したカスタムフィールド

   - 添付の校正書類（提供されている場合）。 表示またはダウンロードする添付ファイルを選択

5. **[承認]**&#x200B;または&#x200B;**[拒否]**&#x200B;を選択します。

6. 「**校閲コメント**」フィールドに、学習者へのメモを入力します。 これはオプションですが、リクエストを拒否する場合にはお勧めします。そうすることで、学習者は修正する内容を理解できます。

7. 「**送信**」を選択します。

学習者は、決定したことを通知するアプリ内通知を受け取ります。 提出が承認されると、学習者トランスクリプトに表示されます。

## 送信キューの管理

外部学習キューには、直属の部下からの保留中の提出物と過去の提出物がすべて表示されます。

**ステータスでフィルター**

**ステータス**&#x200B;フィルターを使用して、リストを絞り込みます。

- **すべて** – ステータスに関係なく、すべての送信内容を表示します

- **レビュー待ち –**&#x200B;には、レビュー待ちの提出物のみが表示されます

- **承認済み –**&#x200B;には、既に承認されている提出物が表示されます

- **却下 –**&#x200B;は、却下した提出物を表示します

**検索と並べ替え**

- **検索**&#x200B;フィールドを使用して、学習者名で提出物を検索します。

- 提出物は、デフォルトで提出日で並べ替えられ、最新のものが最上位に表示されます。

### 承認ルーティングルール

デフォルトでは、社外学習の提出物は学習者の直接マネージャーにルーティングされます。 学習者に直接マネージャーが割り当てられていない場合、次のルールが適用されます。

| **学習者にマネージャーが存在します** | **学習者がマネージャーである** | **送信は**&#x200B;にルーティングされます |
|---------------------------|-------------------------------------|---------------------------------------------------------------------------------------------------------------------|
| ○ | × | 直接管理者（デフォルトのケース） |
| ○ | ○ | 直接管理者（デフォルトのケース） |
| × | × | ルートアカウントユーザー（ルートアカウントユーザーにマネージャーの役割がある場合）。それ以外の場合、送信は自動承認されます。 |
| × | ○ | ルートアカウントユーザー（ルートアカウントユーザーにマネージャーの役割がある場合）。それ以外の場合、送信は学習者にルーティングされます。 |

特定の学習者のマネージャーの割り当てについて質問がある場合は、アカウント管理者に連絡してください。

## 社外学習のレポートとトランスクリプトの変更

Adobe Learning Managerで学習者の社外学習の提出物が承認されると、そのアクティビティがレポートシステムに追加され、管理者学習者トランスクリプトと学習者トランスクリプトの両方に表示されます。

### 学習者のトランスクリプトに外部学習がどのように表示されるか

**注意：**&#x200B;外部学習を有効にすると、管理者学習者のトランスクリプトに次の新しい列が追加されます： **外部学習名**、**完了コメント**、および各カスタムフィールドの動的列。 カスタムフィールド列は、書き出しの最後に常に表示されます。 学習者のトランスクリプトデータが自動レポートやBIツールにフィードされる場合は、追加の列を処理するために、パイプラインが更新されていることを確認してください。

トランスクリプトに表示される外部学習提出物は、**承認済み**&#x200B;のみです。 **承認待ち**&#x200B;または&#x200B;**却下**&#x200B;ステータスの提出物は、トランスクリプトの書き出しに含まれません。

管理者学習者のトランスクリプトと学習者のトランスクリプトでは、外部学習タイトルの処理が異なります。

- **管理者学習者のトランスクリプト**&#x200B;では、外部学習のタイトルが既存の&#x200B;**LP/資格認定/コース**&#x200B;列に配置され、列の構造が他の学習アクティビティタイプと一貫した状態が保たれます。

- **学習者のトランスクリプト** （学習者が生成）で、**モジュール**&#x200B;列の直後に&#x200B;**外部学習名**&#x200B;という新しい列が追加されます。

送信が承認されると、管理者が設定したカスタムフィールドが、両方のトランスクリプトの書き出しの最後に動的列として表示されます。

社外学習行に対する管理者学習者トランスクリプトの日付ベースのフィルタリングは、承認日に対応する&#x200B;**完了日**&#x200B;に基づいています。
