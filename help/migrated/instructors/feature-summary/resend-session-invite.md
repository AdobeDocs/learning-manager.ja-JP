# セッションの招待を再送信

## 概要

>[!NOTE]
>
>再トリガーは、バーチャルクラスルーム(VC)セッションでのみ使用できます。 教室モジュールやセルフペース（eラーニング）モジュールなど、その他のモジュールタイプはサポートされていません。

学習者が招待を逃す理由はいくつかあります。 **再送信**&#x200B;オプションを使用すると、コースを編集する権限を持つ管理者が、「インスタンス」ページでVCセッションを開き、学習者を検索してセッションの招待電子メールを送信することができます。 Learning Managerは、登録イベントフローの外部でオンデマンドで電子メールを送信します。 学習者はセッションの詳細とカレンダーの招待状を受け取りますが、登録状態は変わりません。

## ユースケース

セッションへの招待を再送信する場合には、次の操作を行います。

* **失われた招待を回復する。** メールボックスがいっぱいになった学習者、電子メールがスパムになった学習者、または元の電子メールが配信されなかった学習者に招待を再送信します。
* **ノーショーを減らす。** セッションの直前またはセッションの当日に、セッションの詳細とカレンダーの招待状を再送信します。
* **登録の回避策を避けてください。** 学習者の登録を解除および再登録せずに招待を再送信することで、登録状態とセッション登録を維持できます。
* **サポートチケットを減らす。** 管理者は、サポートチームの介入なしに、「招待が見つからない」というリクエストを自分で解決します。

## 前提条件

* セッションがVCセッションである。
* 学習者がターゲットセッションに登録されている。 Learning Managerは、セッションに登録されている学習者にのみ招待を送信します。
* セッションは既に存在します。 この機能では、セッションを作成または変更することはできません。
* 既存のセッション招待電子メールテンプレートが使用されます。 この機能では、新しい電子メールテンプレートは導入されません。

## サポートされる構成

| アイテム | サポート |
|--------------------|-----------------------------------------------------------------------------------------------------------|
| 役割 | コースを編集する権限を持つ管理者 割り当てられているセッションのインストラクター。 |
| カタログ項目の種類 | コースと学習パス |
| モジュールタイプ | バーチャルクラスルーム(VC)セッション |
| セッション | 現在および今後のセッション。 過去のセッションはサポートされていません。 |
| VCプロバイダー | Zoom、Teams、Adobe Connectなど、セッションに設定されているすべてのプロバイダー |
| 電子メールテンプレート | 学習目標に設定されたテンプレート：セッションの詳細を示す電子メールとカレンダーの招待状 |
| 受信者 | セッションに登録されている個々の学習者。 ユーザーグループはサポートされていません。 |
| トリガー | 「セッションの招待を再送信」アクションからの手動 |

マネージャーの役割には、このリリースのこの機能へのアクセス権がありません。 このオプションは、学習者やマネージャーには表示されません。

## セッション招待の再送信アクションへのアクセス

アクションの場所は、役割によって異なります。

| 役割 | アクションの場所 |
|---------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 管理者 | カタログでコースまたは学習パスを開き、「インスタンス」に移動してインスタンスを開きます。 「セッション」セクションで、VCセッションを見つけ、「セッションの招待状を再送信」を選択します。 コースを編集するには権限が必要です。 |

## ダイアログを再送信

セッションの招待を再送信ダイアログには次の要素が含まれます。

| エレメント | 概要 |
|-----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 学習者の選択 | 検索フィールド。 学習者の名前またはメールアドレスを入力して学習者を検索し、学習者を選択します。 複数の学習者を選択できます。 選択した各学習者に、学習目標に設定されたテンプレートに基づく2通の電子メール（セッションの詳細電子メールとカレンダーの招待状）が送信されることが通知で説明されます。 |
| キャンセル | 電子メールを送信せずにダイアログを閉じます。 |
| 再送信 | 選択した学習者に電子メールを送信します。 このボタンは、学習者を1人以上選択するまで無効です。 |

>[!NOTE]
>
>検索は個々の学習者にのみ一致します。 ユーザーグループを検索または選択することはできません。

## セッションへの招待を再送信

管理者として次の手順を実行します。

1. コースを編集する権限を持つ管理者としてログインします。
2. **学習**/**コース**&#x200B;に移動します。

   ![](assets/resend-session-invite1.png)

3. アクセスするインスタンスを含むコースを開きます。

   ![](assets/resend-session-invite2.png)

4. セッションにアクセスするインスタンスに移動します。
5. 以下の&#x200B;**セッションの詳細**&#x200B;セクションで、**セッションの招待を再送信**&#x200B;を選択します。

   ![](assets/resend-session-invite3.png)

6. **セッションの招待を再送信**&#x200B;のポップアップが開きます。

   ![](assets/resend-session-invite4.png)

7. 招待を再送信する学習者を検索します。

   ![](assets/resend-session-invite5.png)

   ![](assets/resend-session-invite6.png)

8. 「**再送信**」を選択します。 「x人の学習者にセッションの招待状が送信されました」というメッセージが表示されます。

   ![](assets/resend-session-invite7.png)

9. 選択した学習者の1人が別のセッションの学習者である場合は、「選択したX人はこのセッションに登録されていないためスキップされました」というメッセージが表示されます。

   ![](assets/resend-session-invite8.png)

10. 数分後、セッションに参加するためのリンクが含まれるセッションの詳細が記載されたメールが学習者に送信されます。

![](assets/resend-session-invite9.png)

Learning Managerは、選択した各学習者がターゲットセッションに登録されていることを検証してから、既存のセッションの招待状を対象の学習者に送信します。

Learning Managerがリクエストを承認すると、ダイアログが閉じて「セッションの学習者に招待電子メールが送信されています。 完了までに時間がかかる場合があります。」 メールは通常数分以内に届きます。

## 電子メールコンテンツ

選択した各学習者に、セッションの詳細を示す電子メールとセッションの招待状が送信されます。 コンテンツには、VCセッション参加リンク、日付と時刻、セッションの詳細が含まれています。 Learning Managerでは同じテンプレートが使用されるため、電子メールは元のセッションの招待状と同じです。

## 複数登録の動作

再送信はインスタンスに固有です。 学習者が複数のインスタンスに登録されている場合、1つのインスタンスから再送信すると、そのインスタンスの招待のみが送信されます。 学習者の他のインスタンスに対する招待は再トリガーされません。

| 学習者の登録 | アクション | 結果 |
|------------------------------------------------|------------------------------------------------|----------------------------------------------------------------------------------|
| インスタンスAとインスタンスB | インスタンスAから再送信 | インスタンスAの招待のみが再送信されます。 |
| インスタンスAのみ | インスタンスAから再送信 | インスタンスAの招待が再送信されました。 |
| 選択したセッションとは異なるインスタンス | 学習者はコースレベルの検索に表示されます | 選択したセッションの学習者がスキップされ、警告が表示されます。 |

## 特定のシナリオでの動作

| シナリオ | 動作 |
|--------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| インスタンスにVCセッションがありません | セッションの招待状の再送信アクションは使用できません。 |
| セッションは既に発生しています | このアクションは使用できません。 Learning Managerは、現在および将来のセッションのみをサポートします。 |
| セッションに登録されていない学習者を選択した場合 | 学習者の検索はコース全体を対象としているため、他のインスタンスから学習者を検索できます。 Learning Managerは、選択したセッションに登録していない学習者をスキップし、他のユーザーに招待を送信して、警告を表示します。 |
| 学習者が複数のインスタンスに登録されている | Learning Managerは、送信元のインスタンスに対してのみ招待を送信します。 他のインスタンスの招待は送信されません。 |
| 学習パスインスタンスが選択されています | このアクションは、コースインスタンスの場合と同様に動作します。 |

## エラー処理

エラーが発生してLearning Managerが電子メールを送信できない場合、ダイアログに次のいずれかのメッセージが表示されます。

| 条件 | メッセージ |
|---------------------------------------|------------------------------------------------------------------------|
| 招待電子メールテンプレートが無効になっています | 電子メールを送信できません。招待用の電子メールテンプレートは現在無効です。 |
| その他のエラー | メールの送信中にエラーが発生しました。 後で再試行してください。 |

セッションに登録されていない学習者を選択すると、Learning Managerではそれらの学習者の招待がスキップされたことを通知する警告が表示されます。 登録されている学習者に招待が送信されます。

>[!NOTE]
>
>電子メールサービスは、ダイアログが閉じられた後に、配信ステータスをLearning Managerに非同期でレポートします。

## 制限

* 現在および今後のセッションの招待のみを再送信できます。
* 学習目標に設定されているテンプレートのみが使用されます。 別のテンプレートを選択することはできません。
* 招待は、一度に1つのセッションに再送信できます。 複数のインスタンスに同時に再送信することはサポートされていません。
* ユーザーグループを選択することはできません。 個々の学習者のみを選択できます。
* Learning Managerは、選択したセッションに登録されている学習者にのみ招待を送信します。
* このダイアログには、電子メールの配信ステータスは表示されず、個々の学習者に対して再試行は提供されません。
* このダイアログでは、新しいセッションをスケジュールしたり、既存のセッションの詳細を編集したりすることはできません。

## トラブルシューティング

| 現象 | 考えられる原因 | アクション |
|---------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------|
| セッションの招待を再送信アクションは表示されません | モジュールがVCセッションではない、セッションが既に発生している、またはコースを編集する権限がない。 | セッションが現在または将来のVCセッションであることを確認します。 管理者にコースの権限の確認を依頼してください。 |
| メールを送信すると警告が表示されます | 選択した1人以上の学習者が、選択したセッションに登録されていません。 | セッションに登録されている学習者を確認し、正しいセッションまたはインスタンスから招待を再送信します。 |
| 招待状が間違ったインスタンスに送信されました | 学習者が複数のインスタンスに登録されており、別のインスタンスから招待を再送信した場合。 | 学習者が必要とするインスタンスを開き、そこから招待を再送信します。 |
| 「招待電子メールテンプレートは現在無効です」というエラーが表示されます | 学習目標に対して、招待電子メールテンプレートが無効になっています。 | 管理者にテンプレートを有効にしてもらい、招待を再送信します。 |
| 現在の電子メールは、元の招待メールと同じに見えます | これは予期される動作です。 Learning Managerは既存のセッション招待テンプレートを再利用します。 | 対応は不要です。 |
| 招待を一度に複数のインスタンスに再送信する必要があります | これはサポートされていません。 | 各インスタンスからの招待を個別に再送信します。 |
| 教室またはeラーニングモジュールへの招待を再送信する必要があります | これはサポートされていません。 再トリガーは、VCセッションでのみ使用できます。 | これらのモジュールタイプで使用できるアクションはありません。 |
| 学習者からメールが届かなかったと通知される | 電子メールがまだ処理中か、学習者のメールボックスがいっぱいか、電子メールがスパムとしてフィルタリングされている。 | 数分待ってから、スパムフォルダーを確認してメールボックスの空き容量を増やすように学習者に依頼し、招待を再送信します。 |
