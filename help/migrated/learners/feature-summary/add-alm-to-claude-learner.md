# Adobe Learning Managerを学習者としてクラウドに追加

## 概要

これらの手順は、組織がコネクターを追加していない場合にのみ使用してください。 Adobe Learning ManagerのコネクターがClaudeに表示される場合は、代わりに「**Connect**」を選択します。

## クロードにコネクターを追加する

1. クロードで、**カスタマイズ** > **コネクター**&#x200B;に移動します。
2. **[追加]** (**+**)を選択し、**[カスタムコネクターの追加]**&#x200B;を選択します。
3. Adobe Learning Managerなどの&#x200B;**名前**&#x200B;を入力してください。
4. **リモートMCPサーバーURL**&#x200B;にMCPエンドポイントURLを入力します。
5. 「**続行**」を選択します。
6. **認証**&#x200B;で、**今すぐサインイン**&#x200B;を続けてください。
7. **OAuthクライアント**&#x200B;で、**独自のOAuthクライアントを使用**&#x200B;を選択します。
8. **クライアントID**&#x200B;にクライアントIDを入力します。
9. **クライアントシークレット**&#x200B;に秘密キーを入力してください。
10. 「**追加**」を選択します。
11. ログインページが開いたら、Adobe Learning Managerにログインします。

ログインすると、コネクターは接続済みとして表示されます。 学習について質問します。 アイデアについては、[学習者へのサンプルプロンプト](/help/migrated/learners/feature-summary/sample-prompts-for-learners.md)をご覧ください。

>[!IMPORTANT]
>
>Claudeは「クライアントシークレット」フィールドにオプションとラベルを付けますが、Adobe Learning Managerでは必須です。 空のままにするか、間違った値を入力すると、**認証に失敗しました**&#x200B;メッセージが表示されてサインインに失敗します。

>[!NOTE]
>
>リクエストは、独自の権限で実行されます。 クロードは、Adobe Learning Managerに表示されているもののみを表示できます。

## 別のAdobe Learning Managerアカウントを使用

ブラウザーに既にアクティブなAdobe Learning Managerセッションがある場合、Claudeは資格情報を要求せずにそのアカウントに接続します。 別のユーザーとして接続するには、まずAdobe Learning Managerからログアウトするか、プライベートブラウザーウィンドウを使用します。

## その他のAIクライアント

ChatGPTまたは別のクライアントの場合、手順は異なります。 カスタムコネクターの追加については、AIクライアントのドキュメントを参照してください。また、管理者が提供する同じ3つの値を使用してください。

## トラブルシューティング

**サインインすると、登録されていないリダイレクトメッセージが表示されます。**
管理者は、サーバーの**リダイレクトドメイン**&#x200B;にクラウドドメインを追加する必要があります。 管理者に<https://claude.ai>の追加を依頼して、もう一度やり直してください。

**クロードが認証に失敗したと言っています。**
秘密鍵に余分なスペースや間違った値がないか確認します。 管理者からもう一度コピーし、コネクターを削除してから、もう一度追加します。

**接続されたユーザーが正しくありません。**
コネクターーを取り外し、Adobe Learning Managerからログアウトして、プライベートブラウザーウィンドウで再度接続します。

**クロードは、もう一度サインインするように求めます。**
セッションが終了したか、アクセスが取り消されました。 「**Connect**」を選択して、もう一度ログインします。
