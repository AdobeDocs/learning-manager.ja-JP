# 学習者向け成績表

## 成績表を使用してコースを開始

Adobe Learning Managerでコースの成績表が有効になっていて表示されている場合は、コースの概要ページに「**成績表**」タブが表示されます。 これを使用して、各モジュールの加重スコア、現在の集計スコア、およびコースを修了したか、または修了する必要があるかを確認します。

![](assets/image_0008.png)

## 成績表が使用可能な場合

作成者または管理者がコースの成績表を表示するように設定した場合、**成績表**&#x200B;タブは、コースプレーヤーで&#x200B;**モジュール**、**メモ**、および&#x200B;**ディスカッション**&#x200B;と一緒に表示されます。 タブが表示されない場合は、このコースに対して成績表が有効になっていないか、管理者が学習者の表示を無効にしています。 スコアが記録され、管理者に表示される場合もあります。

登録中はいつでも「**Gradebook**」タブを開くことができます。

![](assets/image_0009.png)

* **開始前：**&#x200B;登録後、採点可能なモジュールの一覧と、その加重比率、各モジュールの最大マーク、作成者が設定した合格条件が表示されます。 これにより、開始前にコースが採点される方法が正確に示されます。
* **処理中：**&#x200B;モジュールを完了し、スコアが記録されると、成績表が更新され、未試行のモジュールや採点待ちのモジュールと一緒に今までのスコアが表示されます。
* **完了後：**&#x200B;成績表には、最終モジュールのすべてのスコア、計算されたコースのスコア、および&#x200B;**合格**&#x200B;の結果がヘッダーに表示されます。

## 成績表を表示する

* **学習状況**&#x200B;から、コースを選択します。
* コースページから「**成績表**」タブを選択します。

  成績表のヘッダーには次が表示されます。

  ![](assets/image_0010a.png)

* **合格条件：**&#x200B;必要な集計スコアとモジュール数の最小値
* 合計のうち完了した必須モジュールの数
* 現在の&#x200B;**集計スコア**&#x200B;の割合
* 現在のコースのステータス： **未開始**、**完了待ち**、**合格**、または&#x200B;**不合格**

ヘッダーの下のモジュール表には、各モジュールの次の列が表示されます。

| **列** | **表示される内容** |
|------------|-------------------|
| **モジュール** | モジュール名とタイプ |
| **ステータス** | このモジュールの完了またはスコアのステータス（以下のステータスのリファレンスを参照） |
| **加重値** | このモジュールが集計スコアに与える割合 |
| **スコア** | このモジュールのスコア（40/100など） |
| **貢献度** | これまでの集計スコアに、このモジュールが追加した実際のパーセンテージポイント |

## 「モジュール」タブからのモジュールの加重値の表示

成績表を開かずに、**モジュール**&#x200B;タブから各モジュールの加重値を確認することもできます。

コースページから、「**モジュール**」タブを選択します。

![](assets/image_0011.png)

「**モジュール**」タブには、各モジュールの加重比率と、コースを完了するために必要なモジュールの数が表示されます。

## 複数回の試行でのモジュールのスコア

モジュールで複数回の試行が許可されている場合、成績表に表示されるスコアは、コースの作成者が設定した方法によって異なります。

* **最高：**&#x200B;試行した最高点が表示されます。 後で試行してスコアを下げても、記録されたスコアは減少しません。
* **最新：**&#x200B;最新の試行のスコアが常に表示されます。 後で試みた場合のスコアが低いと、前のスコアが置き換えられる。

## モジュールのステータスの理解

成績表の各モジュールには、次のいずれかのステータスが表示されます。

![](assets/image_0012.png)

| **ステータス** | **意味** |
|------------|-------------------|
| **完了** | モジュールが終了し、スコアが記録されました |
| **処理中** | モジュールは開始しましたが、まだ完了していません |
| **未開始** | モジュールはまだ開いていません |
| **失敗** | モジュールが得点し、スコアがモジュールの合格しきい値を満たしていませんでした |
| **保留中のレビュー** | モジュールは完了しましたが、インストラクターまたは管理者からのスコアを待っています |
| **加重値なし** | モジュールタイプはスコアリング（PDF、ビデオなど）をサポートしておらず、集約には関与しない |

## 集計スコアの計算方法

集計スコアは、各スコア付きモジュールの加重貢献度の合計です。

（最高点÷達成したスコア） ×加重値% =モジュールの貢献度

成績表の&#x200B;**貢献度**&#x200B;列は、現在の集計に対する各モジュールの貢献度を示します。 **加重値なし**&#x200B;とマークされたモジュールは、この計算から除外されます。

スコア尺度は、すべてのモジュールで同じである必要はありません。 100点満点のモジュールと10点満点のモジュールの両方が正しく機能します。 式は、加重値を適用する前に各値を正規化します。

## 成績表のスコアの表示とレポート

Adobe Learning Managerの管理者は、コースに登録されているすべての学習者の加重成績表スコアを表示したり、モジュールごとに個々の学習者のパフォーマンスをドリルダウンしたり、フィルタリングされた学習者トランスクリプトをダウンロードしたり、コンテンツ監査追跡レポートで成績表の設定の変更を追跡したりできます。

## コースの成績表の表示

コースで成績表が有効になっている場合、コースを開くと、**レポート**&#x200B;の下の左側のナビゲーションに新しい&#x200B;**L2フィードバック – 成績表**&#x200B;セクションが表示されます。

* Adobe Learning Managerに管理者としてログインします。
* 左側のナビゲーションで「**コース**」を選択し、レビューするコースを開きます。
* コースナビゲーションの[**レポート**]で、[**L2フィードバック – Gradebook**]を選択します。 **アクティブなフィードバック成績表**&#x200B;ページが開きます。

![](assets/image_0013.png)

次のように表示されます。

1. コースの合格条件（必要な最小モジュールと最小集計スコア）
2. 成績別に学習者を表示するためのフィルター行： **合格**、**不合格**、または&#x200B;**完了待ち**
3. 集計スコアの式：集計スコア= Σ（最大スコア÷達成したスコア）×加重値（モジュールごと）
4. 各学習者の&#x200B;**集計スコア**&#x200B;と、採点可能な各モジュールのスコアを表示する学習者リスト
5. コースに複数のインスタンスが含まれている場合に、コースインスタンスを切り替えるためのインスタンスドロップダウン

まだスコア付きモジュールを試行していない学習者は、スコア列にダッシュが表示されます。 スコアリング、PDF、ビデオ、オーディオなどをサポートしていないモジュールは、スコア列として表示されません。

## 個々の学習者のスコアの表示

**アクティブなフィードバック成績表**&#x200B;で、学習者の名前を選択します。

![](assets/image_0014.png)

個々の学習者ビューには以下が表示されます。

1. 学習者の名前、電子メール、およびステータス（**完了保留中**、**合格**、または&#x200B;**不合格**）
2. 学習者が完了した総スコアと必要なモジュール数
3. モジュール名、タイプ、必須かどうか、ステータス、加重値、達成スコア、および集計への貢献度を示すモジュール表

モジュールテーブルには、採点可能なモジュールと採点不可能なモジュールがすべて含まれます。 採点可能なモジュールは、スコアと貢献度を表示します。 採点不可能なモジュールは、「スコア」列と「貢献度」列にダッシュで表示されます。

## スコアモジュール

管理者とインストラクターのスコアリング動作は、現在のワークフローから変更されていません。

* **基礎となるコンテンツがスコアを報告すると、SCORM、AICC、xAPI、ネイティブクイズモジュール**&#x200B;が自動的にスコア付けされます。
* **教室セッション、バーチャル教室セッション、およびアクティビティモジュール**&#x200B;は、インストラクターまたは管理者が&#x200B;**出席とスコア付け**&#x200B;ページからスコア付けします。

## コースの学習者のトランスクリプトのダウンロード

このコースにフィルターされた学習者のトランスクリプトは、次の2つの方法のいずれかで成績表ページから直接ダウンロードできます。

* **アクティブフィードバック成績表**&#x200B;で、ページの右上隅にある&#x200B;**学習者のトランスクリプトをダウンロード**&#x200B;を選択します。
* 管理者ホームページで、**レポート**&#x200B;を選択し、**カスタムレポート**&#x200B;を選択します。 使用可能なレポートのリストから&#x200B;**学習者のトランスクリプト**&#x200B;を選択します。

詳しくは、リリースの変更点のレポートを参照してください。

## コンテンツ監査追跡イベント

コンテンツ監査証跡は、成果書固有の2つの構成イベントをキャプチャします。

| **イベント** | **表示されるタイミング** |
|-----------|---------------------|
| **成績表を更新しました** | 作成者がコースの成績表を有効または無効にした場合 |
| **モジュールの重みが更新されました** | 作成者がモジュールの加重比率を変更した場合 |

詳しくは、リリースの変更点のレポートを参照してください。

これらのエントリを使用して、誰がいつ成績表の設定を変更したかを追跡できます。特に、複数の作成者が同じコースで共同作業を行う環境で使用できます。

## トラブルシューティング

**L2フィードバック – 成績表セクションがコースナビゲーションに表示されません**

成績表は、コースの作成時にコース作成者が有効にする必要があります。 作成者がコースの作成で成績表を有効にしたことを確認します。 成績表が使用可能になる前に作成されたコースの場合、さかのぼって追加することはできません。 新しいコースバージョンが必要です。

**完了したモジュールがあるにもかかわらず、学習者の合計スコアは0です**

重み値が割り当てられた採点可能なモジュールがコースに1つ以上あることを確認します。 学習者が完了したすべてのモジュール（PDF、ビデオ、オーディオ）がスコア付けできない場合、集計スコアは計算されません。 また、得点したモジュールが&#x200B;**レビュー待ち**&#x200B;の状態にないことを確認してください。 採点されていないモジュールは、インストラクターがスコアを入力するまで、集計から除外されます。

**ダウンロードされた学習者トランスクリプトに「加重値」列がありません**

この列は、成績表が有効で、少なくとも1つのモジュールに加重値が保存されている場合にのみ表示されます。 著者が成績表を有効にし、加重値を合計100 %保存したことを確認します。

**学習者は必要なモジュールをすべて完了しましたが、完了が保留中です**

1つ以上のモジュールがインストラクターまたは管理者のスコアを待っている可能性があります（**レビューの保留中**&#x200B;ステータス）。 すべての必須モジュールに完了とスコアの両方が記録されるまで、コースを完了することはできません。 **出席とスコア付け**&#x200B;から未処理のスコアを入力して、保留状態をクリアします。
