# 学習者向け成績表

## 成績表を使用してコースを開始

Adobe Learning Managerでコースの成績表が有効になっていて表示されている場合は、コースの概要ページに「**成績表**」タブが表示されます。 これを使用して、各モジュールの加重スコア、現在の集計スコア、およびコースを修了したか、または修了する必要があるかを確認します。

![](assets/image_0008.png)

## 成績表が使用可能な場合

作成者または管理者がコースの成績表を表示するように設定した場合、**成績表**&#x200B;タブは、コースプレーヤーで&#x200B;**モジュール**、**メモ**、および&#x200B;**ディスカッション**&#x200B;と一緒に表示されます。 タブが表示されない場合は、このコースに対して成績表が有効になっていないか、管理者が学習者の表示を無効にしています。 スコアが記録され、管理者に表示される場合もあります。

登録中はいつでも「**Gradebook**」タブを開くことができます。

![](assets/image_0009.png)

* **開始前：**&#x200B;登録後、採点可能なモジュールの一覧と、その加重比率、各モジュールの最大マーク、作成者が設定した合格条件が表示されます。 これにより、開始前にコースが採点される方法が正確に示されます。
* **処理中：**&#x200B;モジュールを完了し、スコアが記録されると、成績表が更新され、未試行のモジュールや採点待ちのモジュールと一緒に今までのスコアが表示されます。
* **完了後：**&#x200B;成績表には、最終モジュールのすべてのスコア、計算された集計コースのスコア、および&#x200B;**最終成績**&#x200B;の結果がヘッダーに表示されます。

## 成績表を表示する

* **学習状況**&#x200B;から、コースを選択します。
* コースページから「**成績表**」タブを選択します。

  成績表のヘッダーには次が表示されます。

  ![](assets/image_0010a.png)

* **合格条件：**&#x200B;必要な集計スコアとモジュール数の最小値
* 合計のうち完了した必須モジュールの数
* 現在の&#x200B;**集計スコア**&#x200B;の割合
* 現在のコースのステータス： **未開始**、**完了待ち**、**合格**、または&#x200B;**不合格**

ヘッダーの下のモジュール表には、各モジュールの次の列が表示されます。

| **列** | **表示される内容** |
|------------|-------------------|
| **モジュール** | モジュール名とタイプ |
| **ステータス** | このモジュールの完了またはスコアのステータス（以下のステータスのリファレンスを参照） |
| **加重値** | このモジュールが集計スコアに与える割合 |
| **スコア** | このモジュールのスコア（40/100など） |
| **貢献度** | これまでの集計スコアに、このモジュールが追加した実際のパーセンテージポイント |

## 「モジュール」タブからのモジュールの加重値の表示

成績表を開かずに、**モジュール**&#x200B;タブから各モジュールの加重値を確認することもできます。

コースページから、「**モジュール**」タブを選択します。

![](assets/image_0011.png)

「**モジュール**」タブには、各モジュールの加重比率と、コースを完了するために必要なモジュールの数が表示されます。

## 複数回の試行でのモジュールのスコア

モジュールで複数回の試行が許可されている場合、成績表に表示されるスコアは、コースの作成者が設定した方法によって異なります。

* **最高：**&#x200B;試行した最高点が表示されます。 後で試行してスコアを下げても、記録されたスコアは減少しません。
* **最新：**&#x200B;最新の試行のスコアが常に表示されます。 後で試みた場合のスコアが低いと、前のスコアが置き換えられる。

## モジュールのステータスの理解

成績表の各モジュールには、次のいずれかのステータスが表示されます。

![](assets/image_0012.png)

| **ステータス** | **意味** |
| ------------ | ------------------- |
| **合格** | モジュールが終了し、スコアが記録されました |
| **処理中** | モジュールは開始しましたが、まだ完了していません |
| **未開始** | モジュールはまだ開いていません |
| **失敗** | モジュールが得点し、スコアがモジュールの合格しきい値を満たしていませんでした |

## 集計スコアの計算方法

集計スコアは、各スコア付きモジュールの加重貢献度の合計です。

（最高点÷達成したスコア） ×加重値% =モジュールの貢献度

成績表の&#x200B;**貢献度**&#x200B;列は、現在の集計に対する各モジュールの貢献度を示します。 **加重値なし**&#x200B;とマークされたモジュールは、この計算から除外されます。

スコア尺度は、すべてのモジュールで同じである必要はありません。 100点満点のモジュールと10点満点のモジュールの両方が正しく機能します。 式は、加重値を適用する前に各値を正規化します。
