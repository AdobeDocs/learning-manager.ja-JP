# 学習者コンプライアンスウィジェットに複数登録されたコース

Adobe Learning Managerでは、学習者は同じコースの複数のインスタンスに登録できます。 学習者のコンプライアンスウィジェットでは、期日を迎えている登録済みインスタンスがすべて一覧表示されるようになりました。これにより、学習者はプライマリインスタンスのみではなく、各期日を確認することができます。

## 複数登録コースの変更点

この変更が行われる前、コンプライアンスウィジェットには、複数登録されたコースのプライマリインスタンスのみが表示されていました。 複数のインスタンスに登録されている学習者が、ウィジェットの他のインスタンスの期日を確認できませんでした。

これで、コンプライアンスウィジェットは、次のすべての条件を満たすすべてのインスタンスを表示します。

* 学習者がインスタンスに登録されている。
* インスタンスに期限があります。
* 学習者がインスタンスを完了していません。

各項目にはインスタンス名が表示されるため、学習者は同じコースのインスタンスを区別できます。 学習者が項目を選択すると、Adobe Learning Managerはそのインスタンスを直接開きます。

例えば、学習者が最初のトレーニングコースを完了したとします。 管理者は、9月、10月および11月の各コースに、それぞれ期限を指定して学習者を登録します。 準拠ウィジェットには、3つのエディションがすべて表示されます。

ウィジェットは、各準拠カテゴリでインスタンスを個別にカウントします： **期限切れ**、**今後の期限まで（30日以内）**、**オントラック**。

## 準拠ウィジェットに表示されるインスタンス

次の表に、ウィジェットが各登録状況をどのように処理するかを示します。

| 登録状況 | ウィジェットに表示 | メモ |
|--------------------------------------------------|-----------------------------------|---------------------------------------|
| 登録済み、インスタンスは締め切り日を持ち、完了していません | 可 | インスタンス名とともに表示 |
| 登録済み、インスタンスに期限がありません | 不可 | 期限のあるインスタンスのみが表示されます |
| インスタンス完了 | 不可 | 完了したインスタンスが表示されません |
| すべての登録済みインスタンスで完了 | 不可 | コースが表示されなくなります |
| 期限が指定されたインスタンス1つと、指定されていないインスタンス1つ | 期限のあるインスタンスのみ |                                       |
| 登録済みインスタンスは1つのみ | 可 | ウィジェットは、そのインスタンスを表示します |

API情報については、[学習者アプリの複数登録インスタンスのAPIサポート](/help/migrated/api-changes-dec-2026.md#multi-enrolled-compliance-widget)を参照してください。
