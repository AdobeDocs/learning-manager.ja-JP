# Adobe Learning Manager学習者向けのサンプルプロンプト

まず、AIクライアントを接続する必要があります。 [AIクライアントを接続](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md)を表示します。 各プロンプトは、[学習者ツールのリファレンス](/help/migrated/learners/feature-summary/learner-tools-reference.md)のツールにマッピングされます。

## 登録

| **プロンプト** | **ツール** |
|------------------------------------------|----------------|
| どのようなコースに登録できますか？ | 登録を取得 |
| 期限切れになるコースはどれですか？ | 登録を取得 |

## 検索

| **プロンプト** | **ツール** |
|-----------------------------------------|----------|
| どのようなリーダーシップコースが利用できますか？ | 検索 |
| 利用可能なセキュリティトレーニングを表示します。 | 検索 |

## 知識

| **プロンプト** | **ツール** |
|---------------------------------------------------------|--------------|
| FedRAMPにおけるサプライチェーンのリスク管理とは何ですか？ | Answer agent |
| コンプライアンスコースの要件を説明します。 | Answer agent |

## 学習パス

| **プロンプト** | **ツール** |
|----|----|
| プロジェクト管理のスキルアップに役立つ一連のコースを見つけましょう。 | 学習パスの生成 |
| この学習パスを保存します。 | 学習パスを保存 |
