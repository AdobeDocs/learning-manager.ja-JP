# Model Context Protocolサーバーの学習者ツール

すべての機能は、学習者が接続すると、ログインした学習者として実行されます。 リクエストは、学習者がAdobe Learning Managerでアクセスできる内容のみを返します。 詳しくは、[AIクライアントを接続](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md)を参照してください。

## 学習者の機能

| **機能** | **学習者が実行できる操作** | **リクエストの例** |
|----|----|----|
| 学習コンテンツを検索 | コース、資格認定および学習パスの検索 | どのようなリーダーシップコースが利用できますか？ |
| 登録の表示 | 登録と学習期限の確認 | 期限切れになるコースはどれですか？ |
| 学習に関する質問 | 学習コンテンツから回答を得る | FedRAMPにおけるサプライチェーンのリスク管理とは何ですか？ |
| 学習パスの生成 | パーソナライズされた学習パスの作成 | プロジェクト管理のスキルアップに役立つコースを見つけるにはどうすればよいですか？ |
| 学習パスの保存 | 生成された学習パスの保存 | この学習パスを保存します。 |

## サポートされているMCPツール

Learner Assistant MCPサーバーには、次の学習者向けツールが表示されます。

| **MCPツール** | **目的** | **機能をサポート** |
|----|----|----|
| 検索 | 利用可能な学習コンテンツを検索 | 学習コンテンツを検索 |
| 登録を取得 | 学習者の登録情報の取得 | 登録の表示 |
| Answer Agent | 学習コンテンツを使用した質問への回答 | 学習に関する質問 |
| ユーザーを取得 | リクエストごとにログインしている学習者を特定します。 | すべての機能 |
| 学習目標を取得 | 説明や期間など、学習目標の詳細を取得する | 学習コンテンツの検索、登録の表示 |
| ラーニングパスを生成 | 推奨される学習パスの作成 | 学習パスの生成 |
| 学習パスを保存 | 生成された学習パスの保存 | 学習パスの保存 |

>[!IMPORTANT]
>
>ツール名は参照用に表示されますが、クライアントの実装によって異なる場合があります。
