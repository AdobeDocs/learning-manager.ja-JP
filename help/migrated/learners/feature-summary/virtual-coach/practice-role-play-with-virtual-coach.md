# バーチャルコーチでロールプレイを練習する

Adobe Learning ManagerでAIを活用したロールプレイセッションを実施し、パフォーマンスレポートを確認して、実際のコミュニケーションスキルを身につけましょう。

バーチャルコーチのロールプレイは、コースモジュールまたはスタンドアロンジョブエイドとして利用できます。 この記事では、セッションの検索と起動からAIペルソナの操作まで、あらゆることを説明します。

## ロールプレイを検索して開く

### 方法1

1. 学習者としてAdobe Learning Managerにログインします。 **ホーム**&#x200B;ページが表示されます。
2. このページの冒頭に、「バーチャルコーチについて」というセクションが表示されます。 リストから適切なロールプレイを選択します。

   ![](/help/migrated/learners/feature-summary/assets/virtual-coach21.png)

3. 「**開始**」を選択してモジュールを起動します。

### 方法2

この方法を使用して、**学習状況**&#x200B;ページまたは&#x200B;**カタログ**&#x200B;ページからロールプレイを検索できます。 方法は同じです。

1. 学習者としてAdobe Learning Managerにログインします。
2. 左側のナビゲーションパネルで、**学習状況**&#x200B;ページまたは&#x200B;**カタログ**&#x200B;ページに移動します。
3. セクション「**タイプ**」から、「**仮想コーチ作業計画書**」を選択します。 バーチャルコーチを使用して作成されたロールプレイのリストが表示されます。

   ![](/help/migrated/learners/feature-summary/assets/virtual-coach20.png)

4. 適切なロールプレイモジュールを選択するか、右側の&#x200B;**探索**&#x200B;を選択して開きます。
5. 「**開始**」を選択してモジュールを起動します。

## ハードウェアの準備

セッションが開始する前に、Virtual Coachがカメラとマイクをチェックします。

1. デバイス設定画面で、**カメラソース**&#x200B;をドロップダウンメニューから選択して確定します。
2. **マイク**&#x200B;を選択し、「こんにちは」などの短いフレーズを話して、オーディオレベルインジケーターをテストします。
3. 両方のデバイスが確認されたら、**[カメラで参加]**&#x200B;を選択します。

## シミュレーションに参加する

AIトレーナーが開き、誰と話し、目的を説明する短いコンテキストステートメントが表示されます。 AIペルソナが開始する前に、よく読んでください。

- AIペルソナの最初の言葉を聞きます。
- **口頭で対応する。** 実際の会話の場合と同様に、自然かつ直接的に話します。 AIは、ユーザーの発言に基づいてリアルタイムで応答します。
- **必要なトピックをカバーしてください。** このシナリオには、作成者が設定した特定のトピックがあります。 会話中に対応し、ナレッジコンポーネントのスコアを適切に評価します。
- **複数のペルソナによるロールプレイ**&#x200B;では、各ペルソナがそれぞれの遠近法から質問や懸念事項を提起することを想定します。たとえば、コストに重点を置いたCFOと、セキュリティに重点を置いたIT Directorが同じテーマでディスカッションします。 グループに対して一般的な回答を1回行うのではなく、各個人の問題に対処します。
- 目標を達成した場合、または完了する準備ができている場合は、[**シミュレーションの終了**]を選択します。

>[!TIP]
>
>君は急ぐ必要はない。 実際の会話の場合と同じように、返答する前にしばらく考えてください。

シミュレーションを終了すると、セッションは自動的に採点されます。 レポートに表示される内容と改善方法については、[仮想コーチパフォーマンスレポートについて](/help/migrated/learners/feature-summary/virtual-coach/understand-virtual-coach-performance-report.md)を参照してください。

ロールプレイは何度でも再試行できます。各試行は独自のレポートを持つ新しい独立したセッションであるため、最初の試行のフィードバックを使用して次の試行の準備を行います。 ロールプレイがスコア0で終了した理由がわからない場合は、そのシナリオに自分が対応していない&#x200B;**MakeまたはBreak**&#x200B;トピックがあるかどうかを確認します。これらのトピックの1つが見つからない場合、他でのパフォーマンスに関係なく、自動的に最終スコアがゼロになります。
