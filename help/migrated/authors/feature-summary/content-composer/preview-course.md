# コースのプレビュー

![](../assets/19_preview_mode_timeline_block_updated.png)

- 上部のツールバーで&#x200B;**プレビュー**&#x200B;を選択します。 学習者が見るのと同じ方法でコースが表示され、適用されたテーマ、インタラクティブコンポーネント、クイズが解答モードで表示されます。

- 「**次へ**」と「**前へ**」を使用して移動するか、左側のレッスンパネルで任意のトピックを選択します。 右上隅の&#x200B;**プレビューを終了**&#x200B;を選択して、編集に戻ります。
