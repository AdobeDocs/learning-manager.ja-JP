# Content ComposerからALMへのパブリッシュに関するベストプラクティス

- アウトラインを生成する前に、特定の学習目標を記述します。 目標は、ソースファイルでAIが優先する対象、アウトライン構造、クイズがテストする対象を制御します。

- コースを生成する前に、概要を確認してください。 アウトラインの段階でチャットを使用してレッスン名を変更するには数秒かかります。生成後に変更するには、アウトラインの会話に戻る必要があります。

- 組織の特定の手順を正確に行う必要がある場合は、**ファイル内のコンテンツへの出力を制限**&#x200B;してください。 例えば、コンプライアンスやポリシーのトレーニングなどです。

- 公開する前に、生成されたすべてのコンテンツ、評価、学習目標を確認してください。 AIの出力は確率的であり、世代間で異なる場合があります。

- 固定レッスン/トピック階層がコンテンツに対して十分な粒度ではない場合は、**アコーディオン**&#x200B;と&#x200B;**Tab**&#x200B;の各コンポーネントを使用して、トピック内に深度を追加できます。
