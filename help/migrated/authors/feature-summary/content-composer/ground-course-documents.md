# 自分のドキュメントでコースを固定する

ほとんどのAIコースツールは、一般的な知識からコンテンツを生成します。これは、トレーニングの内容が、もっともらしく聞こえる近似ではなく、組織の実際のポリシー、手順、または規制に関する言語に一致する必要がある場合の問題です。

コンテンツコンポーザーを使用すると、AIの描画元を正確に制御できます。 ソースファイルをアップロードし、**「ファイル内のコンテンツへの出力を制限」**&#x200B;を選択すると、コンテンツコンポーザーは、指定したコンテンツからのみコースの全部分（アウトライン、レッスン、クイズ）を生成します。 AIは、不足していると識別されるギャップを埋めるために、外部情報を導入することもありません。

これは、次の場合に最も重要です。

- **コンプライアンスと規制に関するトレーニング**:コースの内容が実際のポリシー言語と一致している必要があります。

- **手順とSOPトレーニング** : AIが生成した「十分に近い」手順が間違っている可能性があります。

- **製品またはシステムトレーニング**:コースは、ツールの一般的なバージョンではなく、特定の構成を反映する必要があります。

より広範なトピックや機密性の低いトピックで役立つ独自の一般知識をAIにマテリアルを補足させたい場合は、制限を選択しないでおきます。 ソースマテリアルがまったくない場合は、**ソースファイルを使用せずにコースを生成**&#x200B;を選択します。
