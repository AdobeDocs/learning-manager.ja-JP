# クイズの確認と編集

![](../assets/12_quiz_block_question_view_updated.png)

採点済みのクイズがコースの最後に表示されます。 各質問には、テストするトピックでタグが付けられています。

>[!NOTE]
>
>レッスン内に埋め込まれたナレッジチェックは採点されません。 レッスン終了のクイズのみが採点されます。


質問を編集するには、次の手順に従います。

1. 質問テキストを選択して編集し、テキスト編集オプションを使用してスタイルを調整します。
   ![](../assets/13_quiz_question_text_edit_toolbar_updated.png)

2. 正しいとマークするオプションの横にあるラジオボタンを選択します。

3. 正解にスコアを割り当てることもできます。
   ![](../assets/14_quiz_question_options_scoring_panel_updated.png)

4. 質問を削除するには、**オプションの削除**&#x200B;を選択します。

5. 質問を再生成するには、アシスタントに「レッスン1のクイズを再生成する」と質問します。
