# コメントの管理と返信

作成者は、プロジェクトの&#x200B;**コメント**&#x200B;パネルを使用して、コメントを表示し、返信できます。

1. 上部のツールバーから&#x200B;**コメント**&#x200B;を選択します。 **コメント**&#x200B;パネルが開き、すべてのレビュー担当者のコメントが表示されます。

   ![](../assets/63_owner_in_app_comments_panel_mention_comment.png)

2. 任意のコメントを選択して、カンバス上のコンテキストで表示します。

   ![](../assets/64_comment_in_context_on_canvas.png)

3. チェックマークアイコンを選択してコメントを解決済みとしてマークするか、**その他のオプション**&#x200B;アイコンを選択して編集または削除します。

   ![](../assets/65_comment_resolve_checkmark_delete_menu.png)

4. 更新したコースを保存します。

5. レビュー担当者が最新バージョンを表示できるように、**共有**&#x200B;を選択してレビューリンクを更新します。
