# ヘッダーとフッターの追加

ヘッダーとフッターを追加して、ロゴなどの要素を追加します。

1. ツールバーから&#x200B;**テーマ**&#x200B;を選択し、適用されたテーマにカーソルを合わせて、**編集**&#x200B;を選択します。

2. 「**ヘッダーを追加**」トグルをオンにして、コースにヘッダーを追加します。
   ![テーマの編集パネルでヘッダーの追加とフッターの追加を切り替えます](../assets/39_edit_theme_header_footer_toggles_updated.png)

3. 「**ロゴ**」で「**追加**」を選択して、ヘッダーのロゴをアップロードします。

4. **「フッターを追加」**&#x200B;トグルをオンにして、コースにフッターを追加します。

>[!NOTE]
>
>コンテンツコンポーザーは、変更を加えると、自動的にカンバス内でプレビューします。
