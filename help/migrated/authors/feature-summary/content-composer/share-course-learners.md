# 学習者とのコースの共有

学習者と共有すると、LMSに接続したりログインしたりしなくても、コースに直接アクセスできます。 これは、学習者がコースをすばやくプレビューまたは完了する場合に便利です。例えば、パイロット試験や非公式のトレーニングセッション中や、正式な登録とトラッキングのためにコースをAdobe Learning Managerにパブリッシュする前などです。

1. 上部のツールバーで&#x200B;**共有**&#x200B;を選択します。

2. **学習者の場合**&#x200B;タブを選択します。

3. 「**リンクを生成**」を選択して、学習者アクセスリンクを作成します。

   ![](../assets/59_share_for_learners_generate_link_generated_links.png)

4. 学習者とリンクを共有します。

>[!IMPORTANT]
>
>学習者リンクはバージョンに固有です。 コースを更新するたびに、新しいリンクを生成して共有し、学習者が最新バージョンにアクセスできるようにします。 前のリンクには、引き続き以前のバージョンが表示されます。
>
>学習者アクセスにはコメントパネルは含まれません。 学習者はコメントを追加したり、レビューワークフローを操作したりすることはできません。
