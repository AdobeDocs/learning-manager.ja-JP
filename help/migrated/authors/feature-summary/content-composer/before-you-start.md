# 始める前に

Adobe Learning Manager Content Composerを起動する前に、以下を確認してください。

>[!IMPORTANT]
>
>有効なAdobe Creative Cloudアカウントでログインする必要があります。 アカウントをお持ちでない場合は、Adobe Expressで無料アカウントを作成できます。 詳しくは、[無料のAdobe Expressアカウントを作成する](https://helpx.adobe.com/express/web/adobe-express-subscription/free.html)をご覧ください。 Adobe認証情報を作成したら、Content Composerを起動し、ログインしてコースの作成を開始します。 組織内で既にCreative Cloudサブスクリプションを使用している場合は、Content Composerにログインする前に、管理者に連絡して、Creative Cloudアカウントをプロビジョニングしてもらってください。

コンテンツコンポーザーを快適にご利用いただくために、**Google Chromeブラウザーをおすすめします**。 FirefoxとSafariで機能や動作に違いが見られる場合があります。

## コンテンツコンポーザーのアカウントメニューと環境設定

Content Composerアカウントメニューから、Adobeアカウント設定へのアクセス、表示設定の指定、最近使用したプロジェクトの表示を行います。

[コンテンツコンポーザ]ツールバーには、[ユニバーサルナビゲーションアカウント] Adobeが含まれています。 これを使用して、表示テーマと言語を調整し、最近作業したプロジェクトをすばやく再度開くことができます。

### アカウントメニューを開く

Content Composerツールバーの右上隅にあるプロファイルアイコンを選択して、アカウントメニューを開きます。

1. 環境設定の指定
2. プロファイルアイコンを選択して、アカウントメニューを開きます。
3. [!UICONTROL 環境設定]を選択します。 [!UICONTROL 環境設定]ダイアログが開きます。
4. [!UICONTROL テーマ]で、[!UICONTROL 明]または[!UICONTROL 暗]を選択して、コンテンツコンポーザーインターフェイスの表示モードを設定します。
5. 「[!UICONTROL 言語]」で、お好みの表示言語を選択します。
6. 「[!UICONTROL 保存]」を選択して変更を適用します。

>[!NOTE]
>
>テーマと言語の環境設定は、コンテンツコンポーザーのインターフェイスにのみ適用されます。 コースの視覚的なテーマやコースコンテンツの言語には影響しません。

## 最近使用したプロジェクトを開く

アカウントメニューには、最近開いたコンテンツコンポーザープロジェクトを示す[!UICONTROL 最近使用したファイル]のリストがあります。

[!UICONTROL 最近使用したプロジェクト]リストで任意のプロジェクトを選択して、直接開きます。

## オプションの要件

* 取り上げる被写体の領域に関する一般的なアイデアがある。 始める前に完全な明瞭度は必要ありません。

* AIは、会話を通じて、コースタイトル、対象者、学習目標を定義する手順を案内します。

* ソース文書はオプションです。 ファイルをアップロードせずに続行できます。入力に基づいてAIがコンテンツを生成します。

* 既存のマテリアルを使用してコースを作成する場合は、Briefステージでコースをアップロードできます。 サポートされているファイル形式は、PDF、マークダウン(.md)、PowerPoint(.pptx)などで、それぞれ最大100 MBです。
