# テーマの書き出し

テーマをJSON ファイルとして書き出して、コンテンツコンポーザー以外でカスタマイズしたり、他の作成者と共有したりすることができます。

1. ツールバーから&#x200B;**テーマ**&#x200B;を選択し、**コーステーマ**&#x200B;パネルを開きます。

2. 書き出すテーマにカーソルを合わせ、**書き出し**&#x200B;アイコンを選択します。
   ![](../assets/47_export_theme_save_as_json_dialog_updated.png)

3. 表示されるダイアログで、場所を選択し、**ファイル名**&#x200B;を入力します。
