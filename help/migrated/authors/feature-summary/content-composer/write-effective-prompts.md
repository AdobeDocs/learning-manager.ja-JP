# 効果的なプロンプトを書く

コンテンツコンポーザーで、正確なコース概要、改善されたアウトライン、AI生成コンテンツの強化を実現するプロンプトを記述します。

このプロンプトは、コンテンツコンポーザーに最初に入力するテキストで、最も重要なテキストです。 明確で具体的なプロンプトとは、AIが概要をより正確に事前入力し、目的に合ったアウトラインを生成して、編集の必要が少ないコースコンテンツを生成することを意味します。

## なぜ迅速な対応が必要なのか

コンテンツコンポーザーはプロンプトを読み取り、それを使用してコースタイトル、学習者プロファイル、学習目標という3つの短いフィールドに事前入力します。 プロンプトがこれらの3つの次元を反映するほど、ブリーフで必要な修正は少なくなり、ブリーフの精度が上がるほど、より適切なアウトラインが生成されます。

「セキュリティに関するコースを作成する」というプロンプトでは、AIはほとんど操作できません。 視聴者に名前を付け、トピックを指定し、スコープに信号を送るプロンプトは、最小限の変更で受け入れることができる短い資料を生成するのに十分なAIを提供します。

短いフィールドは、プロンプトに含まれる内容も増幅します。 プロンプトが曖昧な場合、AIは曖昧なメッセージを生成します。 あいまいな概要は、一般的なアウトラインを生成します。

## 強力なプロンプトを構成する

強いプロンプトは、1つまたは2つの文で3つの質問に答えます。

- 学習者は&#x200B;**誰**&#x200B;ですか？ 役割と経験レベルに名前を付けます。

- **コースの対象**&#x200B;を指定してください。 幅広いテーマではなく、2～3の具体的なトピック名を挙げてください。

- **どのような範囲または結果を指定しますか**? 信号の長さ、深度、または学習者が実行できる操作。

## 効果的なプロンプトの解剖

**[対象ユーザー+エクスペリエンスレベル]** + **[2 ～ 3の特定のトピック]** + **[範囲または結果に関するシグナル]**

**例**:

新しい営業担当者向けに、エンタープライズ価格レベル、割引承認ワークフロー、3つの最も一般的な顧客オブジェクションへの対処方法について説明するコースを作成したいと考えています。

これの内訳：

- **対象ユーザー：**&#x200B;新しい営業担当者

- **トピック：**&#x200B;のエンタープライズ価格レベル、割引承認ワークフロー、3つの一般的なオブジェクション

**開始**&#x200B;を選択すると、コンテンツコンポーザーは&#x200B;**概要**&#x200B;ステージを開きます。 事前入力されたフィールド、タイトル、学習者プロファイル、プロンプトから生成されたAIの目的を確認し、アウトラインを生成する前に目的と一致しないものを調整してください。

## 効果的なプロンプトの是非

| **含める** | **回避** |
|--------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------|
| 特定の対象ユーザーの役割（「新しい営業担当者」、「フロントラインマネージャー」） | 曖昧なオーディエンス（「すべてのスタッフ」、「全員」、「ユーザー」） |
| 2-3具体的なトピックエリア | 1つのプロンプトに6つ以上のトピックが表示されます。これらのトピックでは、アウトラインが過負荷になります。代わりに、別々のコースに分割されます |
| 範囲信号 – 期間、深度、または学習者の成果 | 一般的な目標（「Xに関するあらゆることを教える」「あらゆる側面をカバーする」） |
| トーンや深度を形成するコンテキスト（「コンプライアンス用」、「技術者以外の対象者向け」、「シナリオベース」） | AIに関する質問 このプロンプトは簡潔であり、会話ではありません |
| コース終了後に学習者が実行できる操作 | コースに含まれるもの（構造はアウトラインステージに残す） |

## プロンプトが曖昧すぎる場合はどうなりますか？

プロンプトの範囲が広い場合、AIによって幅広い概要が生成され、一般的なアウトラインが生成されます。 アウトラインは主題となる正しい領域をカバーしますが、コースに必要な特定の構造が不足しています。 より適切なプロンプトを作成するよりも、会話的にアウトラインを編集する方が時間がかかります。

プロンプトがあまりにも曖昧であることが最も一般的な徴候です。

- この概要の学習者プロファイルは、特定の役割ではなく、一般的な（つまり、「Xについて学習したい従業員」）プロファイルになります

- 概要には、トピックに関するあらゆるコースに適用できるレッスンタイトルが表示されます（「概要」、「キーコンセプト」、「概要」）

- この目標は、測定可能な動作を示すものではありません。 代わりに、コーストピックについて説明します

## ベストプラクティス

- コンテンツコンポーザーを開く前に、メッセージを入力します。 あらかじめ起草された文は、入力フィールドの圧力の下で入力された文よりも明確になる傾向があります。

- オーディエンスの名前をサイズではなくロールで指定します。 「大規模な従業員チーム」よりも「新しい営業担当者」の方が便利です。

- プロンプトを2～3個のトピックに制限します。 その他のトピックでアウトラインが過負荷になります。 3つ以上のレッスンが必要な科目の場合は、コースを別々に作成します。

- プロンプトを開始点として扱います。 簡単なフィールドは編集可能です。 AIの提案が近いが正しくない場合は、プロンプトを最初から書き換えるのではなく、フィールドを直接絞り込みます。
