# コースの概要を編集する

![](../assets/10_outline_tab_generated_lessons_topics_updated.png)

Adobe Learning Manager Content Composerでは、briefファイルとsourceファイルからレッスンとトピック構造を生成します。 すべてのレッスンとそのトピックを示すアウトラインがキャンバスに表示されます。

**注意：**&#x200B;アウトライン編集は現在、ベータ版リリースで対話的に行われています。 カンバス上のレッスンやトピックを選択して、名前を変更したり、並べ替えたりすることはできません。 チャットパネルで、変更を平易な言葉の要求として入力します。

その助手は会話的に働いている。 リクエストを自分の言葉で表現できます。 次に、実行できる操作の例をいくつか示します。

| **操作** | **リクエストの例** |
|--------------------------|---------------------------------------------------------------------------|
| レッスンまたはトピックの名前の変更 | 「レッスン1の名前を「フィッシング詐欺の仕組み」に変更する」 |
| レッスンまたはトピックを追加する | 「QRコード・フィッシングに関するトピックをレッスン2に追加」 |
| レッスンまたはトピックを削除する | トピック1.3を削除 |
| レッスンを分割する | 「第3課を二つに分けなさい。 スパムフィルター用に1つ、パッチ管理用に1つ」 |
| レッスンを結合 | 「レッスン3と4を1つのレッスンに統合」 |
| アウトラインの再生成 | 「パスワードの衛生管理に重点を置いて再生成」 |

チャットパネルで平文言語のリクエストを使用して、レッスン、トピック、または完全なアウトライン構造を変更します。

アウトラインの階層は、レッスン/トピックで固定されています。 サブトピックまたは3レベルの構造は作成できません。

アウトラインが正しく表示されたら、上部のツールバーで「**コースを生成**」を選択します。
