# プロンプトを書く

![コンテンツコンポーザーのホーム画面でメッセージを書き込む](../assets/1_coco_home_landing_screen_updated.png)

コンテンツコンポーザーのホーム画面で、作成するコースの説明を入力します。 テーマ、対象者、目標の名前を1つまたは2つの文に分けて、分かりやすく書きます。

**プロンプトの例：**

- フィッシングシミュレーション、パスワードの衛生管理、その他の保護方法など、ITセキュリティ意識に関するコースを作成したいと思います。

- チケットのログ、問題のエスカレーション、ヘルプデスクシステムでケースをクローズする方法について説明する、新しいカスタマーサポート担当者用のオンボーディングモジュールを作成します。

- 正しいリフティング技術、機材の使用時期、ニアミスの報告方法など、手作業での取り扱いに関する倉庫スタッフ向けのリフレッシュコースを作成したいと考えています。

「**使用を開始**」を選択します。 コンテンツコンポーザーは、**概要**&#x200B;のステージを開き、プロンプトを読み取ってコースの詳細の入力を開始します。

**ヒント**:プロンプトは完全である必要はありません。 アシスタントは各ステップでフォローアップの質問を行い、タイトル、学習者のプロファイル、および目標を微調整した後、何も生成します。

## 効果的なプロンプトを書く

コンテンツコンポーザーで、正確なコース概要、改善されたアウトライン、AI生成コンテンツの強化を実現するプロンプトを記述します。

このプロンプトは、コンテンツコンポーザーに最初に入力するテキストで、最も重要なテキストです。 明確で具体的なプロンプトとは、AIが概要をより正確に事前入力し、目的に合ったアウトラインを生成して、編集の必要が少ないコースコンテンツを生成することを意味します。

### なぜ迅速な対応が必要なのか

コンテンツコンポーザーはプロンプトを読み取り、それを使用してコースタイトル、学習者プロファイル、学習目標という3つの短いフィールドに事前入力します。 プロンプトがこれらの3つの次元を反映するほど、ブリーフで必要な修正は少なくなり、ブリーフの精度が上がるほど、より適切なアウトラインが生成されます。

「セキュリティに関するコースを作成する」というプロンプトでは、AIはほとんど操作できません。 視聴者に名前を付け、トピックを指定し、スコープに信号を送るプロンプトは、最小限の変更で受け入れることができる短い資料を生成するのに十分なAIを提供します。

短いフィールドは、プロンプトに含まれる内容も増幅します。 プロンプトが曖昧な場合、AIは曖昧なメッセージを生成します。 あいまいな概要は、一般的なアウトラインを生成します。

詳細については、[効果的なプロンプトを書く](write-effective-prompts.md)を参照してください。
