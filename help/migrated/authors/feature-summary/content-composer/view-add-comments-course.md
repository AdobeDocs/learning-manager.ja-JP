# コースの表示とコメントの追加

コースの作成者の場合は、プロジェクトの&#x200B;**コメント**&#x200B;パネルを選択して、コメントを表示し、返信します。

1. **コメントパネルを開く**:ツールバーから&#x200B;**コメント**&#x200B;を選択します。 コメントパネルには、レビュー担当者が入力したコメントが表示されます。

2. コメントを解決済みとしてマークしたり、コメントを編集または削除したりできます。

3. 必要な変更を行い、プロジェクトを&#x200B;**保存**&#x200B;します。

4. ツールバーから&#x200B;**共有**&#x200B;を選択して、最新のリンクを更新します。
