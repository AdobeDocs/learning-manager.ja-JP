# フォントを変更

見出しと本文のフォントを更新して、コンテンツやブランドにより適したフォントにします。

1. ツールバーから&#x200B;**テーマ**&#x200B;を選択し、適用されたテーマにカーソルを合わせて、**編集**&#x200B;を選択します。 **テーマを編集**&#x200B;パネルが開き、テーマのカラーパレットとフォントが表示されます。

   ![](../assets/35_course_themes_list_edit_icon_updated.png)

2. **フォント**&#x200B;で、**見出し**&#x200B;ドロップダウンを選択し、コースのすべての見出しのフォントを選択します。 例えば、**Outfit**&#x200B;を選択します。

   ![](../assets/36_edit_theme_headings_font_dropdown_updated.png)

3. **本文**&#x200B;ドロップダウンを選択し、コースの本文テキストのフォントを選択します。 たとえば、**DM Sans**&#x200B;を選択します。

   ![](../assets//37_edit_theme_body_font_dropdown_updated.png)

4. 「**保存**」を選択して既存のテーマを変更で上書きするか、「**保存** **新規保存**」を選択して、元のテーマを変更せずに新しいカスタムテーマを作成します。

   ![](../assets/38_edit_theme_full_panel_header_logo_updated.png)

>[!NOTE]
>
>デフォルトのテーマは直接編集できません。 デフォルトのテーマをカスタマイズするには、テーマを編集してから「新規保存」を選択し、元のテーマに基づいてカスタムテーマを作成します。
