# コンテンツコンポーザーの仕組み

コンテンツコンポーザーはオーサリングを処理します。 Adobe Learning Managerは、配信、登録、トラッキング、レポートを処理します。 この分割について理解することで、ALMへのパブリッシングで、サードパーティのLMSへの書き出し方法を手動でSCORMに再アップロードする必要がない理由が説明されます。

| **コンテンツコンポーザーのコントロール** | **Adobe Learning Managerコントロール** |
|-------------------------------------------------------------------------|----------------------------------------------------------|
| レッスンとトピックの構造 | 学習者の登録とアクセス |
| コースコンテンツ – テキスト、画像、ビデオ、コンポーネント、ナレッジチェック | モジュールメタデータ – 期間、タグ、一意のID、有効期限 |
| 質問のタイプと回答を含む、レッスンの終わりのクイズ | コースの組み立てとバージョン管理 |
| ビジュアルテーマ、完了条件、成功条件 | 学習者のトラッキング、レポート作成、トランスクリプト |

Adobe Learning Manager Content Composerでは、次の4つの段階を順に進めます。

- **ホーム画面：**&#x200B;コースを普通の言語で説明するプロンプトを記述します。 AIがプロンプトを読み取り、コースの概要を事前入力します。

- **概要：**&#x200B;次のフィールドを確認します：

  - コースタイトル

  - 学習プロファイル

  - 学習目標

この段階で、AIが描画するファイルをアップロードし、生成されたコンテンツをそれらのファイルのみに制限するかどうかを選択できます。 これらの入力は、AIが下流で生成するものすべてを形成します。

- **概要：** AIは、目標構造を持つレッスンとトピックを提案します。 チャットパネルで確認して、変更をリクエストできます。

アウトラインが正しい場合は、コース全体を生成します。

- **コース：** AIは、3つの階層で構成された完全なコースを生成します。

  - **レッスン:**&#x200B;コースの主要なセクションで、それぞれ主題の特定の部分をカバーしています

  - **トピック:**&#x200B;各レッスン内の個々のユニット。それぞれが1つの概念またはスキルに焦点を当てています

  - **ブロック：**&#x200B;各トピックを構成するコンテンツ要素：テキスト、画像、ビデオ、フリップカード、アコーディオン、タイムラインなどのインタラクティブコンポーネント、およびインラインナレッジチェック

各レッスンの最後に、採点されたクイズが追加されます。

**注意**:レッスンとトピックの構造は、前のステージで承認したアウトラインから取得されます。

共有または公開する前に、すべてのコンテンツ、クイズ、視覚テーマをレビュー、編集、調整します。

**お試しください。**

[**コンテンツコンポーザー**](https://contentcomposer.adobe.io/)を試して、作成するコースを説明してください。

会話アシスタントは、4つのステージすべてで実行されます。 要望に応じて変更を加え、代替案を提案し、可能な操作と不可能な操作を説明します。
