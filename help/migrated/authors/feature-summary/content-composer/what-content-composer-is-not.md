# What Adobe Learning Manager Content Composer以外

始める前に正確な予想を設定するには、次の手順を実行します。

- コンテンツコンポーザーは、分岐またはアダプティブ学習パスをサポートしていません。 コースは、線形のレッスン/トピック構造に従います。

- レッスン終了のクイズでは、現在のベータ版で多肢選択問題と正誤問題のみをサポートしています。 追加の質問タイプについては、ロードマップを参照してください。

## 次のステップ

開始する準備が整ったら、[コンテンツコンポーザーを使用してコースを作成](#create-course)して、詳細な手順に従ったワークフローを参照してください。

**アプリを試す**。 [**コンテンツコンポーザー**](https://contentcomposer.adobe.io/)を開き、手順ガイドに従います。

問題が発生した場合は、[Adobe Learning Managerコミュニティ](https://community.adobe.com/adobe-learning-manager-466)でサポートにお問い合わせいただくか、質問を投稿してください。
