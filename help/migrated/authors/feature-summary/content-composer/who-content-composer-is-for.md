# Adobe Learning Manager Content Composerの対象

Adobe Learning Manager Content Composerは、ゼロから始めることなく、構造化されたコースを作成する必要があるユーザー向けに設計されています。

| **ロール** | **コンテンツコンポーザーの使い方** |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **作成者** | 構造化された効果的なコースを作成します。 自分の知識をコースに変換する、既存のドキュメントやソース資料から作業する、特定の学習目標を満たすためにAIが生成したコンテンツを調整するなど。 |
| **L&amp;D管理者** | アクセスのプロビジョニング、組織のテーマの設定、完了したコースのAdobe Learning Managerへの公開を行います。 |
| **L&amp;Dマネージャー** | コースを学習者に配布する前に、レビューおよび承認します。 |
