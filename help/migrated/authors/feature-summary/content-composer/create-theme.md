# テーマの作成

ユーザー設定のテーマを作成する2つの方法があります。どちらも、**ユーザー設定**&#x200B;のテーマリストに結果を追加します。

- ツールバーの&#x200B;**作成**&#x200B;オプションを使用して&#x200B;**ゼロから構築** – カラーパレット、フォント、およびその他のプロパティを構成し、**新規として保存**。

- **カスタマイズされたJSONファイルのインポート** – 既存のテーマをJSONとしてエクスポートし、テキストエディターまたはコードエディターで編集してから、再度インポートします。

**さらに制御が必要ですか？**

要素ごとのタイポグラフィ（レッスン名、トピック名、ブロック見出し、キャプション）、カラートークンレベルのカスタマイズ、および完全なJSONスキーマアクセス – 一般的にプラットフォームやブランドチームが必要とする制御の種類については、[高度なテーマのカスタマイズ](advanced-theme-customization.md)を参照してください。

## ゼロからテーマを作成

1. ツールバーから&#x200B;**作成**&#x200B;を選択し、**コーステーマ**&#x200B;パネルを開きます。
   ![](../assets/44_course_themes_create_button_updated.png)

2. テーマのカラーパレット、フォント、およびその他のプロパティを必要に応じて設定します。
   ![](../assets/45_create_theme_panel_name_palette_fonts_updated.png)

3. **新規として保存**&#x200B;を選択して、テーマを&#x200B;**カスタム**&#x200B;のテーマリストに追加します。
   ![](../assets/46_custom_themes_list_new_theme_added_updated.png)

## JSONを読み込んでテーマを作成

1. ツールバーから&#x200B;**テーマ**&#x200B;を選択し、**コーステーマ**&#x200B;パネルを開きます。

2. ベースとして使用するテーマにカーソルを合わせ、**書き出し**&#x200B;を選択して、JSONファイルとしてダウンロードします。

3. JSONファイルをテキストエディターまたはコードエディターで開き、半径、間隔、カラーパレット、フォントなどのプロパティを更新します。

4. JSONファイルを保存します。

5. コンテンツコンポーザーで、**コーステーマ**&#x200B;パネルから&#x200B;**読み込み**&#x200B;を選択します。

6. コンピューターから更新されたJSONファイルを選択します。

7. **新規として保存**&#x200B;を選択して、テーマを&#x200B;**カスタム**&#x200B;のテーマリストに追加します。
