# Adobe Learning Managerのモジュールバージョン管理

ソース・マテリアルの変更：ポリシーの改訂、SOPの新バージョンの取得、ピッチ・デックの更新など。 コンテンツコンポーザーとALMは、更新をインプレイス編集ではなくバージョンの変更として処理するため、基になるモジュールを更新している間、以前に公開したコースは機能し続けます。

再公開するときに、Adobe Learning Managerは既存のモジュールをコンテンツライブラリの新しいバージョンとしてアップロードし、モジュールのバージョン番号を1つずつ増加させます。

1. コンテンツコンポーザーで、ソースファイルを更新し、影響を受けるレッスンを再生成した後（「ソースマテリアルの変更時にコースを更新する」を参照）、再パブリッシュします。

2. アップデートを公開しても、既存のモジュールは上書きされません。ALMコンテンツライブラリで、そのアップデートと一緒に新しいバージョンが追加されます。

3. ALM作成者は、モジュールを使用して新しいバージョンを指定する各ALMコースを明示的に更新する必要があります。既存のコースは、ALM作成者が変更するまで、ビルドで使用したバージョンを参照し続けます。

4. 前のバージョンでコースを既に完了している学習者は、既存の完了レコードを維持します。 新しいバージョンは、ALMコースの更新後に登録された学習者に適用されます。

再パブリッシュする前に、コンテンツコンポーザーで再生成されたレッスンを確認してください。 再生成により、影響を受けるレッスンで以前に編集したテキスト、画像またはクイズの質問を調整できます。
