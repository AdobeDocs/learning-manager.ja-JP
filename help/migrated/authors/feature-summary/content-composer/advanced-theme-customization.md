# コンテンツコンポーザーでの高度なテーマのカスタマイズ

## アプリでのテーマの詳細プロパティのカスタマイズ

高度なテーマプロパティを使用すると、レッスン名、トピック名、ブロック見出し、小見出し、キャプション、段落など、個々の要素をより詳細に制御できます。

1. **テーマ**&#x200B;を選択し、適用されたテーマにカーソルを合わせ、**編集**&#x200B;を選択してから、**詳細**を選択します。
   ![テーマの編集パネルの[詳細設定]ボタン](../assets/41_edit_theme_advanced_button_updated.png)

2. フォントプロパティパネルで、コースの&#x200B;**フォントペアリング**&#x200B;を設定します。

   - **見出し**&#x200B;ドロップダウンを選択し、すべての見出しのフォントを選択します。

   - **本文**ドロップダウンを選択し、本文のフォントを選択します。
     ![フォントのペアリングオプションが表示された、詳細テーマのプロパティの[フォントのプロパティ]タブ](../assets/42_advanced_theme_properties_font_pairing_updated.png)

3. 要素のリストを設定： **レッスン名**、**トピック名**、**ブロック見出し**、**小見出し**、**キャプション**&#x200B;および&#x200B;**段落；**&#x200B;カスタマイズする要素を選択します。

4. [!UICONTROL ビジュアルプロパティ]パネルで、コース全体のレイアウトと間隔を調整できます。

   - 「コンテンツの密度」オプションを使用して、エレメント間の間隔を設定します。

   - **カード/画像の角丸の半径**&#x200B;を設定するには、スライダーをドラッグするか、値を入力して、カードや画像の丸みを設定します。 たとえば、半径を17 pxに設定します。

   - **レッスン**&#x200B;を選択して、レッスンの背景色または画像を変更します。

   - **トピック**&#x200B;を選択して、トピックの背景色または枠線を設定します。

   - ヘッダーとプロパティを設定するには、**ヘッダー/フッター**&#x200B;を選択します。

   コンテンツコンポーザーは、変更を加えると、自動的にカンバス内でプレビューします。

5. 選択した要素について、必要に応じてプロパティをカスタマイズします。

   - 大文字にするなど、**フォントスタイル**&#x200B;を選択します。

   - **+**&#x200B;および&#x200B;**-**&#x200B;コントロールを使用して&#x200B;**フォントサイズ**&#x200B;を設定します。

   - **フォントの色**&#x200B;を選択してください。

   - **太字**、*斜体*、<u>下線</u>、~~打ち消し線~~&#x200B;などの書式を適用します。

   - **テキストの配置**&#x200B;を設定します。

6. 右側のカンバスで変更をプレビューします。 **現在のレッスン**&#x200B;と&#x200B;**テストレッスン**のタブを使用して、異なるレッスンで変更がどのように表示されるかを確認します。
   ![詳細なテーマプロパティのテストレッスンのプレビュー](../assets/43_advanced_theme_test_lesson_preview_updated.png)

7. **[新規として保存]**&#x200B;または&#x200B;**[保存]**&#x200B;を選択します。
