# Adobe Learning Manager Content Composerとは

Adobe Learning Manager Content Composerは、コース作成のすべての段階を、AIガイド付きの1つのワークフローにまとめます。 ユーザーは学習内容を記述し、ユーザーからの入力に基づいて、構造化されたアウトラインと、画像、知識チェック、採点されたクイズを含む完全なコースコンテンツを生成します。

コンテンツコンポーザーは、学習のあらゆる段階を単一のワークフローにまとめ、教育用デザインを理解したAIによる共同制作をサポートします。これにより、制作のスピードが向上するだけでなく、デザインに基づいてより効果的な学習を実現できます。

コースの準備が整ったら、次の操作を実行できます。

- PublishコースをAdobe Learning Managerに直接結び付け、包括的な学習者分析を通じて学習効果に関する実用的なインサイトを得ることができます。
- 互換性のあるLMSで使用するには、SCORMパッケージとしてダウンロードしてください。
