# 生成されたコースを確認します

![](../assets/11_course_view_generated_topic_content_updated.png)

Adobe Learning Manager Content Composerは、テキスト、画像、ナレッジチェック、クイズを含むフルコースを1回のパスで作成します。 生成が完了すると、**コース**&#x200B;エディターが自動的に開きます。

左パネルには、レッスンとトピックのナビゲーションが表示されます。 キャンバスには、選択したトピックのコンテンツが表示されます。 チャットパネルは開いたままであるため、会話形式で編集できます。

>[!CAUTION]
>
>共有または公開する前に、生成されたすべてのコンテンツを確認してください。 AI出力は世代によって異なり、不正確な値が含まれる可能性があります。 配布の前に作成者のレビューが必要です。
