# バーチャルコーチテンプレートを使用したロールプレイの作成

ロールプレイを最初から作成するのではなく、テンプレートから開始することで、事前定義済みのバーチャルコーチシナリオを数分でPublishします。

Virtual Coachの&#x200B;**おすすめ**&#x200B;および&#x200B;**利用可能なテンプレート**&#x200B;のセクションには、販売、リーダーシップ、スキル評価の状況を網羅する事前定義済みのロールプレイシナリオのライブラリが含まれています。 テンプレートを使用する方法が最も簡単で、ロールプレイを作成できます。ペルソナ、会話を開く、トピック、スコア付けは既に設定されており、すぐに公開することも、公開する前に詳細をカスタマイズすることもできます。

テンプレートは、ドメイン、シミュレーションの種類、および言語ごとに整理されています。 フィルターを使用して、**音声会話**&#x200B;や&#x200B;**Webカメラの練習**&#x200B;などの操作の種類でリストを絞り込むか、キーワードで検索して、ユースケースに最も近いシナリオを見つけます。

>[!TIP]
>
>テンプレートを選択しても、デフォルト設定にロックされるわけではありません。 テンプレートを選択すると、ペルソナの背景、トピック、スコアの重み、会話の開始など、すべてのフィールドを編集できます。 テンプレートは、最終的なデザインではなく、出発点として扱います。 設定可能な各フィールドの詳細な説明については、[仮想コーチロールプレイの作成と公開](/help/migrated/authors/feature-summary/virtual-coach/create-publish-virtual-coach-role-play.md)を参照してください。


1. 作成者としてAdobe Learning Managerにログインします。
2. 左側のナビゲーションパネルで「**仮想コーチ**」を選択します。
3. **今すぐ作成**&#x200B;を選択します。
4. **使用可能なテンプレート**&#x200B;セクションを参照するか、**検索**&#x200B;バーと、ドメイン、シミュレーションの種類、および言語フィルターを使用して、シナリオに一致するテンプレートを見つけます。

   ![](/help/migrated/authors/feature-summary/assets/virtual-coach25.png)
5. テンプレートタイルを選択して開きます。 ペルソナ、トピックおよびスコアリング構成をレビューします。

   ![](/help/migrated/authors/feature-summary/assets/virtual_coach17.png)
   *テンプレートをカスタマイズするかどうかを決定する前に、あらかじめ入力された会話のコンテキストと個人の背景を確認してください。*

6. テンプレートをそのまま使用するには、**Publish**&#x200B;を選択します。 最初にセクションをカスタマイズするには、公開する前に任意のセクションを選択し、関連するフィールドを編集します。

公開されると、ロールプレイが&#x200B;**コンテンツライブラリ**&#x200B;に追加され、作業計画書に追加してコースに割り当てることができます。 これらの手順については、[コースに仮想コーチロールプレイを追加する](/help/migrated/authors/feature-summary/virtual-coach/add-virtual-coach-role-play-to-course.md)を参照してください。学習者のエクスペリエンスを確認するには、[仮想コーチロールプレイを練習する](/help/migrated/learners/feature-summary/virtual-coach/practice-role-play-with-virtual-coach.md)を参照してください。
