# アダプティブコースの複数登録

## 概要

複数登録：学習者は、同じコースの複数のインスタンスに同時に登録できます。 Adobe Learning Managerで、アダプティブコースの複数登録を有効にできるようになりました。

## アダプティブコースでの複数登録について

適応コースでは、ユーザーグループに一致するモジュールのみが各学習者に表示されます。 複数登録を有効にすると、学習者は、異なる月のセッションなど、コースのいくつかのインスタンスを受講できます。

アダプティブコースでは、キャンセル待ちリストがインスタンスレベルではなく、モジュールレベルで追跡されます。 学習者は、一部のモジュールで処理中でも、他のモジュールで同時にキャンセル待ちになることができます。 例えば、1つのコースに2つのインスタンスがあり、各インスタンスの人数制限が1であるとします。 最初の学習者は両方のインスタンスに登録し、両方の席を取ります。 両方のインスタンスに登録している2人目の学習者は、両方に登録がキャンセル待ちとなります。

## アダプティブコースの複数登録を有効にする

1. 作成者としてAdobe Learning Managerにログインします。
2. 左側のナビゲーションで「**コース**」を選択します。 アダプティブコースを開くか作成します。
3. モジュールを追加します。 各コンテンツモジュールについて、**ルールの追加**&#x200B;を選択して、そのモジュールを表示できるユーザーグループと、そのモジュールが必須であるユーザーグループを設定します。
4. 「**保存**」を選択します。 複数登録オプションが使用可能になります。
5. **複数登録**&#x200B;の切り替えをオンにします。
6. 必要なインスタンスを作成します。 教室およびバーチャルクラスルームセッションの場合は、人数制限を設定します。
7. **Publish**&#x200B;を選択します。

学習者は、コースの複数のインスタンスに登録できるようになりました。

## 人数制限とキャンセル待ちの動作

アダプティブコースでは、各教室またはバーチャルクラスルームセッションに人数制限が適用されます。 学習者はすぐに登録され、満席のセッションでのみキャンセル待ちになります。 学習者は、他のすべてのモジュールをすぐに開始できます。

| 条件 | 結果 |
|------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| 表示されているすべてのセッションに使用可能な席があります | 学習者は、すべてのモジュールへのフルアクセスで登録されています。 |
| 1つ以上の表示可能なセッションがいっぱいです | 学習者が登録され、キャンセル待ちになるのはセッション全体のみです。 |
| 登録済み学習者を含むコースに、席のない必須セッションを追加する場合 | 学習者は新しいセッションでキャンセル待ちになります。 既存の進捗状況やアクセス権に影響はありません。 |
| ユーザーグループを変更すると、学習者に表示されているモジュールからセッションが削除されます | Adobe Learning Managerはすぐに席を外す。 |
| 学習者が別のインスタンスに切り替える場合 | 完了したモジュールは完了したままになります。 シートは、学習者が完了していない可視のモジュールにのみ使用されます。 |

## アダプティブ学習パスの登録と完了のルール

作成者は、Adobe Learning Managerでアダプティブ学習パスにアダプティブコースを追加できるようになりました。 登録、キャンセル待ち、完了は、セクションの設定と作成者が設定したコースの設定を組み合わせたルールに従います。

### 適応学習パスで学習者を評価する方法

Adobe Learning Managerでは、セクションレベルとコースレベルで可視性が評価されます。 セクションルールは、学習者がセクションとその中の適応コースを表示するかどうかを決定します。 各適応コース内のモジュールルールは、学習者がコースに登録しているかどうかを決定します。

アダプティブLP内のアダプティブコースに関してUGに変更がある場合、学習者は自動的に登録されます。 同様に、学習者は自動登録通知と電子メールを受け取ります。

### 登録評価ルール

Adobe Learning Managerでは、アダプティブ学習パスに学習者を登録すると、次の順番でパスがチェックされます。

| 順序 | Check | 結果 |
|-----------|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | セクションの表示 | Adobe Learning Managerでは、学習者に対してコースのセクションが表示されている場合にのみ、コースの登録をチェックします。 |
| 2 | コースの利用資格 | 学習者が受講する必須モジュールがコースに含まれていない場合、その学習者はコースに登録されません。 このコースは学習パスの完了時にはカウントされません。 |
| 3 | 対象となるコースがないセクション | アダプティブコースだけが含まれているセクションの学習者が、コースを選択できない場合、Adobe Learning Managerはそのセクションをスキップします。 |
| 4 | 学習パスの登録 | 必須セクションのいずれにも学習者が適用されていない場合、その学習者は学習パスに登録されていません。 |

学習パスインスタンスに属するコースのインスタンスに学習者が既に登録されている場合、Adobe Learning Managerはその登録を使用します。

登録後は、次のルールが適用されます。

* 可視性/必須ルールが後で変更されるため、アダプティブコースが表示されている場合、可視性のために最初にコースをスキップした学習者は自動登録することができます。
* ユーザーグループの変更やコースの変更を行うと、学習者の登録をアダプティブコースから解除できます。 パスに必須コンテンツが残っていない場合、学習者はそのパスの登録を解除されます。
* セクションが変更された場合、学習者は自動登録の通知や電子メールを受け取りません。 ページをリロードするだけで、学習者は変更内容を確認できます。

### アダプティブ学習パスでのキャンセル待ちの動作

キャンセル待ちは、インスタンスレベルではなく、セッションレベルで機能します。 これは、学習パスの適応コースにも適用されます。

| シナリオ | 動作 |
|----------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| パス内に教室またはバーチャルクラスルームモジュールを含むアダプティブコースがない | キャンセル待ちは適用されません。 |
| アダプティブコースに教室またはバーチャルクラスルームモジュールがあり、インスタンスが選択されていない場合 | コースのデフォルトは&#x200B;**インスタンスなし**&#x200B;です。 学習者は任意のインスタンスに登録でき、満席のセッションでのみキャンセル待ちになります。 |
| 登録前にインスタンスが選択されています | 学習者はそのインスタンスに登録されており、満席のセッションでのみキャンセル待ちになります。 |

キャンセル待ち学習者を管理するには、適応コースを開き、**学習者**/**キャンセル待ち**&#x200B;タブを選択します。 Flex学習パスと適応学習パスの適応コースで、キャンセル待ち学習者がコースの&#x200B;**キャンセル待ち**&#x200B;タブにのみ表示され、学習パスには表示されません。

### 更新の完了とロールバック動作

ユーザーグループやルールが変更されても、Adobe Learning Managerによって入力内容が自動的に取り消されることはありません。 完了した学習者は、完了を更新するまで完了したままになります。

* 学習パスで&#x200B;**完了の更新**&#x200B;を実行します。 このパスを使用して学習する学習者に対して、アダプティブコースを自分で更新することはできません。

* アダプティブコースでは、学習者の現在の必須モジュールに基づいて、最初に各コースが再計算されます。 その後、学習パスは、現在の必須セクションと更新されたコースの状態に基づいて再計算されます。

* コースまたはパスが完了しなくなった場合、学習者のステータスは「進行中」に変わります。 元の完了は、履歴レコードとして学習者トランスクリプトに残ります。

* 完了ロールバックは、ユーザーグループの変更または再パブリッシュによってモジュールが変更された適応コースを検索します。 これらのコースと学習パスが再計算されます。 ロールバックが完了すると、ジョブの状態は&#x200B;**成功**&#x200B;と表示されます。

キャンセル待ちは、モジュールレベルで追跡されます。 学習者は、複数のインスタンスでフルセッションのキャンセル待ちになることができます。 例えば、座席の上限がそれぞれ1つのコースに2つのインスタンスがあるとします。 最初の学習者は両方のインスタンスに登録し、両方の席を取ります。 両方のインスタンスに登録する2人目の学習者が、各インスタンスの&#x200B;**キャンセル待ち**&#x200B;タブに表示されます。

### キャンセル待ちの学習者への席の割り当て

学習者が登録を解除したり、作成者が人数制限を増やしたり、学習者がインスタンスを切り替えたりすると、Adobe Learning Managerは登録日の順にキャンセル待ちリストをクリアします。 手動で席を割り当てることもできます。

1. アダプティブコースを開きます。
2. **学習者**/**キャンセル待ち**&#x200B;タブを選択します。
3. 席を割り当てる各学習者の横にあるチェックボックスをオンにします。
4. **シートの割り当て**&#x200B;を選択します。

Adobe Learning Managerは、表示中のセッションだけでなく、キャンセル待ちのすべてのセッションで、選択した各学習者を一度にキャンセル待ちします。 学習者の座席が配置済みであることを前提としています。
