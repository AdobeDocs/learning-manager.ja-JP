# Adobe Learning Managerドキュメント

スケーラブルな学習者エクスペリエンス、コンプライアンストレーニング、およびスキルベースの開発のためのエンタープライズLMS。 役割を選択して、ガイドに直接移動します。 キュレートされたAdobe Learning Manager Academyコースとガイド付き学習パスを使用して、実践的な製品技能を身につけましょう。
