# Adobe Learning Managerのアダプティブコース

Adobe Learning Managerのアダプティブコースでは、各学習者に表示するモジュールと必要なモジュールを、その学習者が属するユーザーグループに基づいて制御することで、1つのコースを複数のオーディエンスに提供できます。

役割、地域、またはコンプライアンスプロファイルごとに個別のコースを構築するのではなく、1つのアダプティブコースで、適切なコンテンツが適切な学習者に動的に提示されます。

## アダプティブコースで解決する問題

大規模で多様な従業員をトレーニングする組織は、データプライバシー、職場の倫理、および安全といった共通の課題に直面しています。これらには、さまざまな役割、場所、またはコンプライアンス義務を持つ学習者にリーチする必要があります。

これにより重複が発生します。作成者は、複数のほぼ同一のコースを保持し、レポートを細分化し、重要なコンテンツが変更されたときに、すべてのコピーを更新する必要があります。

アダプティブコースでは、作成者がユーザーグループに関連付けられたモジュールレベルで表示と完了のルールを設定できるようにすることで、この問題を解決します。 1つのコースですべての聴衆に同時にサービスを提供します。

### 一般的なシナリオ

- コンプライアンスコースには、全従業員を対象としたコアモジュールと、管轄区域固有の付録モジュールがあります。 各学習者には、自分の場所に適用される付録のみが表示されます。
- 新規採用コースでは、従業員、マネージャー、契約業者に対して様々なモジュールが表示されます。 各役割は、自分に関連するものだけを認識します。
- 安全コースでは、新しい必須モジュールが年半ばに追加されます。 管理者は更新完了をトリガーします。これにより、以前に完了したすべての学習者は、準拠を維持するために新しいモジュールを実行する必要があります。

### 実際の例

組織は、全従業員に対して必須のコンプライアンスコースを実施します。 このコースには7つのモジュールがあります。

- 2つのモジュールはすべての従業員に適用されます。
- 2つのモジュールは、人物マネージャーにのみ適用されます。
- 2つのモジュールは、テクニカルロールの個々のコントリビューターにのみ適用されます。
- 1つのモジュールはシニア・ダイレクタ以上にのみ適用されます。

## モジュールの表示と完了の仕組み

アダプティブコースの各コンテンツモジュールには、次の2つの設定があります。

**モジュールを表示できるユーザーグループ**&#x200B;に対して表示されます。 これらのグループの学習者は、コース内のモジュールを表示してアクセスできますが、**必須**&#x200B;でない限り、完了にはカウントされません。

**モジュールがコースを完了する必要があるユーザーグループ**&#x200B;に必須。 「**必須(**)」に一覧表示されているモジュールは、これらのグループに自動的に表示されます。同じグループを両方の設定に追加する必要はありません。

モジュールは、任意の時点で、特定の学習者に対して次の3つの状態のいずれかになります。

| ステート | 決定方法 | 完了にカウントしますか？ |
|---|---|---|
| 必須 | 学習者が、****&#x200B;に必須として一覧表示されているユーザーグループに属している | はい – 完了する必要があります |
| オプション | 学習者は、**表示対象**&#x200B;のグループに属していますが、**必須**&#x200B;のグループではありません | なし – 表示およびアクセス可能ですが、必須ではありません。 |
| 非表示 | 学習者がどちらの設定のグループにも属していない | 学習者には表示されません |

## 適応コースの特性

適応型コースの特徴は、登録時だけでなく、学習者のプロファイルを継続的に評価できることです。

学習者のユーザーグループが登録中に変更された場合：

- 新しいユーザーグループに表示されなくなったモジュールはすぐに消えます。
- 新しく表示されるモジュールが新しいユーザーグループに必須の場合、そのモジュールは完了要件に追加されます。
- 以前に必須であったモジュールが必須ではなくなった場合、そのモジュールは完了要件から削除されます。
- 以前に完了したモジュールは完了したままになります。 プロファイルの変更を行っても、既に行った作業はリセットされません。

### 自動登録解除

ユーザーグループを変更することで、学習者の必須モジュールがすべて削除された場合、その学習者はコースから自動的に登録解除されます。

### オートコンプリート

ユーザーグループを変更することで、進行中の学習者から残りの未完了の必須モジュールがすべて削除されると、その学習者のコースは自動的に完了します。

プロファイルが変更された結果、学習者が完了していない必須モジュールが新たに追加された場合、管理者は更新完了をトリガーして既存の完了をロールバックし、学習者に新しいモジュールの完了を要求することができます。

## 何が適応し、何が変わらないか

適応ルールは、**コンテンツモジュール**&#x200B;にのみ適用されます。 以下は、ユーザーグループに関係なくすべての登録済み学習者に適用されます。

- **事前作業モジュール：**&#x200B;コアコンテンツの開始前にすべての学習者に表示されます。
- **テストアウトモジュール:**&#x200B;すべての学習者が使用できます。テストアウトを完了すると、コンテンツモジュールのステータスに関係なく、コースが完了します。
- **作業計画書とリソース:**&#x200B;登録されているすべての学習者に常に表示されます。

## 機能の可用性

アダプティブコース機能は、2層のアカウントレベルのフラグによって制御されます。 この機能をアカウントで有効にするには、Adobeアカウントチームにお問い合わせください。

アカウントフラグを有効にすると、次のようになります。

- コースの作成時または編集時には、**「完了と表示ルール」**&#x200B;の切り替えが使用できるようになります。
- 切り替えスイッチを有効にすると、アダプティブ設定パネルがアクティブになります。

**注意：**&#x200B;適応機能フラグを有効にすると、**元に戻せません**。 アカウントレベルで有効にすると、無効にすることはできません。

## カタログの共有

アダプティブコースは、アカウント内のカタログに追加できます。 カタログがピアアカウントの外部で共有されると、アダプティブコースが共有コンテンツから自動的に除外されます。

>[!NOTE]
>
>アダプティブコースを含む学習パスまたは資格認定が外部で共有されると、受信側のアカウントではカタログ内に学習パスまたは資格認定が表示されますが、カタログ内にアダプティブコースが表示されません。 学習目標は完全には除外されません。アダプティブコースコンポーネントのみが共有バージョンから削除されます。 受信側アカウントの作成者は、共有学習オブジェクトのモジュール数がソースバージョンのモジュール数よりも少ない場合があることに注意する必要があります。

## サポートされる構成

| 構成 | サポート |
|---|---|
| 通常の学習パスでのアダプティブコース | 〇（以下の注を参照） |
| フレックス学習パスでの適応コース | 可 |
| アダプティブ学習パスでのアダプティブコース | 不可 |
| 資格認定の適応コース | 〇（繰り返し行われる資格認定には推奨されません） |
| 複数登録 | 不可 |
| インスタンスの切り替え | 可 |
| カタログ共有（クロスアカウント） | 不可 |
| 事前作業モジュールまたはテストアウトモジュールの表示ルール | 不可 |
| コアコンテンツモジュールの表示ルール | 可 |

>[!NOTE]
>
>適応型コースが&#x200B;**順序付き**&#x200B;学習パスに含まれている場合、適応型コースに表示されるモジュールがない学習者は、ユーザーグループがどのモジュールの表示ルールとも一致しないため、そのコースを完了できません。 順序付けされた学習パスでは、これ以降のすべてのアイテムがアクセスできなくなります。 これを避けるには、学習パスに登録されているすべての学習者が、パス内の適応コースの少なくとも1つのモジュールを参照可能な、少なくとも1つのユーザーグループに属していることを確認してください。

また、アダプティブコースを含む学習パスは、上位（ネストされた）学習パスの中に埋め込まないでください。 この設定では、学習者がアダプティブコースに表示されるモジュールや必須モジュールを持っていない場合、埋め込みプレーヤーが応答しなくなり、残りのコンテンツを移動できなくなる場合があります。 この動作は、今後のリリースで対応中です。

>[!NOTE]
>
>学習者が&#x200B;**通常**&#x200B;の学習パス内の適応コースから自動登録解除された場合、ユーザーグループの変更により表示されているすべてのモジュールが削除されたため、親学習パスが登録状態のままとなります。 学習パスの登録は自動解除されません。 学習パス内のアダプティブコースにアクセスできなくなっても、学習者にはトランスクリプトに登録された学習パスが表示されます。 ユースケースにより、アダプティブコースの登録時に親の学習パスも登録解除する必要がある場合は、アダプティブコースを含む通常の学習パスの代わりに&#x200B;**アダプティブ学習パス**&#x200B;を使用することを検討してください。

## アカウントでアダプティブコースを有効にする

適応学習をオンにすると、作成者は、ユーザーグループのメンバーシップに基づいて、様々な学習者に様々なモジュールを表示するコースを作成できます。

## 有効にする前に

- **永続的：**&#x200B;一度有効にすると、アカウントでアダプティブ学習をオフにできません。
- **コースと学習パスの両方に同時に影響します：**&#x200B;適応コースを有効にするフラグと同じフラグで、適応型学習パスも有効になります。
- **既存のコースは変更されていません：**&#x200B;新しく作成されたコースのみをアダプティブにすることができます。 既存の通常のコースは自動的に変換されません。
- **作成者には、このオプションがすぐに表示されます。**&#x200B;保存するとすぐに、アダプティブコースの種類がオーサリングワークフローに表示されます。
- **2層のプロビジョニング：**&#x200B;アカウントが適応学習用にプロビジョニングされている場合、オプションが有効になっており、ロックされています。 UIからは変更できません。 アカウントがプロビジョニングされていない場合、設定は表示されません。 プロビジョニングを依頼するには、Adobeにお問い合わせください。

## アダプティブコースを有効にする

1. Adobe Learning Managerに管理者としてログインします。
2. 左側のナビゲーションウィンドウで&#x200B;**設定**&#x200B;を選択します。
3. **一般**&#x200B;を選択します。
4. セクション&#x200B;**表示と完了の規則**&#x200B;に移動します。 組織でアダプティブ学習が有効になっている場合、次に示すように、オプションがロックされた状態で表示されます。

![](assets/image_0001.png)

アカウントでアダプティブ学習がアクティブになりました。 作成者は、アダプティブコースとアダプティブ学習パスをすぐに作成できます。

## 有効化後の変更点

アダプティブ学習を有効にした後：

- 作成者には、コースの作成時に、既存の通常のコースの種類に加えて、**コンテンツの表示と完了ルール**&#x200B;のオプションが表示されます。
- アダプティブコースの各コンテンツモジュールは、ユーザーグループに対して&#x200B;**オプション**&#x200B;と&#x200B;**必須**&#x200B;のルールを設定できます。
- 適応コースに登録されている学習者には、ユーザーグループによって表示されるモジュールのみが表示されます。
- 既存のすべての通常コースは変更されません。

## トラブルシューティング

- **設定：**&#x200B;の[表示と完了の規則]セクションが表示されません。切り替えが表示される前に、バックエンドでこの機能を準備する必要があります。 アクセスをリクエストするには、Adobeアカウント担当者またはAdobeサポートにお問い合わせください。
- **切り替えスイッチは既に有効で、ロックされているようです。**&#x200B;アカウントがプロビジョニングされたときに、アダプティブ学習が有効になりました。 必要な操作はありません。 作成者は、既にアダプティブコースを作成できます。
