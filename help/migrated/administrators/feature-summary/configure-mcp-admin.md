# モデルコンテキストプロトコルサーバーの構成

## 概要

各MCPサーバーは、AIクライアントが学習者の代理で行動することを許可するOAuth 2.0クライアントアプリケーションを登録します。 管理者は、サーバーを作成してその資格情報をコピーし、その資格情報をAIクライアント管理者に渡します。AIクライアント管理者は、接続を完了します。 いつでもサーバーに再アクセスして、編集、ツール説明の調整、資格情報のコピー、削除を行うことができます。

>[!NOTE]
>
>サーバーでは、学習者の役割を持つユーザーに対してのみ読み取りアクセス権が提供されます。

## MCPサーバーの作成

1. Adobe Learning Managerに管理者としてログインします。
2. **Learning**&#x200B;のAI > **MCPサーバー**&#x200B;に移動します。
3. **新しいMCPサーバー**&#x200B;を選択します。
4. 説明を含むサーバーの詳細を入力します。

   * **サーバー名：**&#x200B;最大50文字までの名前を入力してください。
   * **説明：**&#x200B;最大150文字の簡単な説明を入力してください。
   * **URL:**&#x200B;会社またはアプリケーションのURLを入力してください。
   * **リダイレクトドメイン：**&#x200B;接続する各AIクライアントのドメインを入力してください（[http://\*.chatgpt.com](https://encoded-592c9deb-987b-4562-aa3c-9fa3d37d83e9.uri/http%3a%2f%2f*.chatgpt.com)または[http://\*.claude.ai](https://encoded-592c9deb-987b-4562-aa3c-9fa3d37d83e9.uri/http%3a%2f%2f*.claude.ai)など）。 このフィールドは必須です。

   ![](assets/2_Administrator--Configure-MCP-image1.png)

5. 「**次へ**」を選択します。
6. **使用可能なツール**&#x200B;ページで、サーバーが表示する学習者ツールを確認します。 MCPツールに関する詳細で状況に応じた、目的に応じた説明を提供します。各ツールについて、状況に応じた詳細な説明を提供します。 正確な説明は、MCPと互換性のあるクライアントが適切なツールを選択して呼び出すのに役立ちます。 ツールの目的、サポートされているタスク、予想される入力、および一般的なユースケースを含めます。

   ![](assets/2_Administrator--Configure-MCP-image2.png)

   各ツールの&#x200B;**表示**&#x200B;を選択すると、ツールが選択されているタイミングとツールの応答方法を確認するための手順が表示されます。

   ![](assets/2_Administrator--Configure-MCP-image3.png)

7. 左側のナビゲーションウィンドウで&#x200B;**クライアント資格情報**&#x200B;を選択します。
8. **MCPエンドポイントURL**、**クライアントID**&#x200B;および&#x200B;**秘密鍵**&#x200B;をコピーします。 各値の横にある「**コピー**」を選択します。

   ![](assets/2_Administrator--Configure-MCP-image4.png)

9. 「**閉じる**」を選択します。

>[!NOTE]
>
>サーバーでは、学習者の役割を持つユーザーに対してのみ読み取りアクセス権が提供されます。

エンドポイントURL、クライアントID、秘密鍵をAIクライアント管理者に伝えます。

## ツールの説明の編集

ツールの説明には、ツールを選択するタイミングとツールの応答方法がAIクライアントに通知されます。 プロンプトの例を追加することもできます。 適切に記述されたツールの説明は、MCPと互換性のあるクライアントが適切なツールをより正確に検出して呼び出すのに役立ちます。 ツールの目的、サポートされているタスク、予想される入力、および一般的なユースケースを含めます。

1. **使用可能なツール**&#x200B;ページで、ツールの&#x200B;**アクション**&#x200B;メニューを選択します。
2. **MCPツール構成** \> **編集**&#x200B;を選択します。

   ![](assets/2_Administrator--Configure-MCP-image5.png)

3. **ツールの編集**&#x200B;ダイアログで、**説明/説明**&#x200B;を更新します。

   ![](assets/2_Administrator--Configure-MCP-image6.png)

4. [**プロンプトの例**]で、プロンプトを編集します。 プロンプトを追加するには、**別の例を追加**&#x200B;を選択します。
5. 「**保存**」を選択します。

ツールを元の表現に戻すには、ツールの&#x200B;**アクション**&#x200B;メニューを選択し、**MCPツール構成** \> **リセット**&#x200B;を選択します。

## MCPサーバーの編集

1. **学習のAI** > **MCPサーバー**&#x200B;を選択します。
2. サーバー名を選択します。
3. 「**編集**」を選択します。
4. **アプリケーションの詳細**&#x200B;ページのフィールドを更新し、変更を保存します。

## MCPサーバーの削除

1. **学習のAI** > **MCPサーバー**&#x200B;を選択します。
2. サーバーの行で、**アクション**&#x200B;メニューを選択します。
3. 「**削除**」を選択します。
4. 確認ダイアログで、**削除**&#x200B;を選択します。

>[!WARNING]
>
>サーバーを削除すると、接続されているAIアプリケーションのすべてのツールへのアクセスが削除されます。 ログイン中のデバイスは直ちに動作しなくなり、削除を取り消すことはできません。

## トラブルシューティング

**ツールの変更はすぐに表示されません。**
ツールの説明の編集が有効になるには時間がかかります。 しばらく待ってからもう一度やり直してください。

**サーバーが削除された後、AIクライアントが動作しなくなりました。**
新しいサーバーを作成し、AIクライアント管理者に新しい資格情報を付与します。

**AIクライアントが間違ったツールを使用しています。**
変更したツールの説明を確認します。 **[リセット]**&#x200B;を選択して、元の表現に戻します。

## ベストプラクティス

* 特に変更する理由がない限り、元のツールの説明は残しておいてください。
* ツールを編集する際には、明確な具体的なツールの説明とプロンプト例を記述します。
* 秘密鍵を安全に保存し、AIクライアント管理者とのみ共有できます。
* AIアプリケーションごとに個別のサーバーを作成して、他のアプリケーションに影響を与えずに1つのサーバーを取り消せるようにします。
* サーバーを削除する前に、サーバーに依存しているAIアプリケーションがないことを確認してください。
