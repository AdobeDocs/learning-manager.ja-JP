# バーチャルコーチレポート

管理者は、仮想コーチに関連する2つのレポートを表示できます。 これは、**学習者の使用状況の概要**&#x200B;および&#x200B;**セッションの詳細**&#x200B;です。

![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report1.png)

## 学習者の使用状況の概要

「学習者の使用状況の概要」には、アカウントに登録されているすべての学習者の毎月の使用状況に関する詳細が含まれます。 これらの使用状況の詳細には、使用状況と学習パターンに関するインサイトが含まれています。

### 学習者の使用状況の概要を生成

学習者使用状況要約を生成する手順は、次のとおりです。

1. 管理者としてログインします。
2. **管理**/**レポート**/**AIレポート**&#x200B;に移動します。
3. **仮想コーチ**&#x200B;セクションで、**学習者の使用状況の概要**&#x200B;を選択します。 **仮想コーチ学習者の使用データ**&#x200B;ポップアップが表示されます。
4. **開始日**&#x200B;と&#x200B;**終了日**&#x200B;を選択します。
5. **「続行」**&#x200B;を選択します。 レポートは.csvファイルとして生成されます。 ダウンロードした.csvファイルは、ファイルエクスプローラーーの&#x200B;**Downloads**&#x200B;フォルダーにあります。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report2.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-learn-usage-6.png)

## セッションの詳細

**セッションの詳細**&#x200B;レポートには、過去90日間にアカウント内で登録されたすべての学習者のセッションの詳細が含まれています。 これらの使用状況の詳細には、使用状況と学習パターンに関するインサイトが含まれています。

### セッションの詳細を生成

セッション詳細レポートを生成するには、次の手順に従います。

1. 管理者としてログインします。
1. **管理**/**レポート**/**AIレポート**&#x200B;に移動します。
1. **仮想コーチ**&#x200B;セクションで、**セッションの詳細**&#x200B;を選択します。 **レポート要求の生成**&#x200B;ポップアップが表示されます。
1. 「**OK**」を選択します。 レポートは.csvファイルとして生成されます。 ダウンロードした.csvファイルは、ファイルエクスプローラーーの&#x200B;**Downloads**&#x200B;フォルダーにあります。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report3.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-session-4.png)

>[!NOTE]
>
>Adobe Learning Managerでは、学習者のバーチャルコーチセッションの記録は保持されません。 学習者は複数のセッションを受講できます。 ただし、学習者は以前のバーチャルコーチセッションに戻ることはできません。
