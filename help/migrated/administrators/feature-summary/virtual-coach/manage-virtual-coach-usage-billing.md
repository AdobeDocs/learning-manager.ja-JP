# バーチャルコーチの使用と請求の管理

Adobe Learning Manager管理者として、バーチャルコーチをアクティブ化し、月間アクティブユーザー(MAU)のクレジット使用量をモニターし、学習者のパフォーマンスレポートをダウンロードします。

## アカウントに対してバーチャルコーチを有効にする {#activatevirtualcoach}

バーチャルコーチは、Adobe Learning Managerのアドオンとして使用できます。 購入後、プロビジョニングによりアクティベーションキーが生成され、アカウント管理者に電子メールで送信されます。

1. Adobe Learning Managerに管理者としてログインします。
2. 左側のナビゲーションウィンドウから&#x200B;**請求**&#x200B;ページに移動します。
3. **仮想コーチ**&#x200B;セクションで、電子メールで受け取ったアクティベーションキーを入力します。

   ![](/help/migrated/administrators/feature-summary/assets/virtual_coach12.png)
   *請求ページの「仮想コーチ」セクションにアクティベーションキーを入力して、この機能を有効にします。*

4. 「**適用**」を選択します。 アカウントに対して仮想コーチが有効になっています。

有効化されると、機能が有効であることを確認するアプリ内通知が届きます。 4つのサンプルのロールプレイシナリオが&#x200B;**コンテンツライブラリ**&#x200B;に自動的に追加されるため、作成者は直ちに作業を開始できます。

>[!NOTE]
>
>アクティベーションキーは、プロビジョニング中に自動生成され、電子メールで共有されます。 アクティベーションキーをお持ちでない場合は、Adobe Learning Managerカスタマーサクセスマネージャーにお問い合わせください。

## MAUクレジット残高の表示

月間アクティブユーザー(MAU)クレジットは、各月にバーチャルコーチを使用した一意の学習者の数をカウントします。

1. **請求**&#x200B;ページに移動します。
2. **仮想コーチ**&#x200B;セクションで、**利用状況の詳細を表示**&#x200B;を選択します。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach22.png)

3. **期間の選択**&#x200B;ドロップダウンを使用して、確認する日付範囲を選択します。

   **全体的な使用量**&#x200B;のテーブルは次を示しています：

   - **使用可能** ：購入したMAUクレジットの合計。
   - **使用済み**：現在までに使用済みのクレジットです。
   - **残り**：残りの契約期間で利用可能なクレジット。

   **毎月の使用数**&#x200B;のテーブルには、アクティブな学習者の一意の数が暦月ごとに表示されます。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach23.png)

4. 完全な使用状況データをエクスポートするには、**詳細レポートのダウンロード**&#x200B;を選択します。

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-mau-billing-5.png)

## MAUクレジットの消費方法

MAUクレジットは、学習者が暦月でバーチャルコーチセッションを開始した場合に消費されます。 同じ学習者が同じ月に追加のセッションを行った場合、追加のクレジットは消費されません。 契約期間の終了時に未使用のクレジットは失効し、繰り越されません。

| シナリオ | 消費されたMAU |
|---|---|
| 1人の学習者が1月に5つのセッションを完了 | 1 |
| 同じ学習者が1月と2月の両方でバーチャルコーチを使用 | 2 （1か月あたり1） |
| 1月に1つのセッションを完了する学習者はそれぞれ100人 | 100 |

*MAUクレジットは、各学習者が起動するセッションの数に関係なく、暦月ごとに一意の学習者ごとにカウントされます。*

**例：単一の学習者、複数のセッション。** サラは1月に5つのバーチャルコーチセッションを開始します。 彼女は月の単一のユニークなユーザーとしてカウントされているので、彼女は彼女が練習する回数に関係なく1マウが消費されます。

**例：同じ学習者、複数か月。** Sarahは1月（3セッション）と2月（2セッション）の両方でバーチャルコーチを使用しています。 カレンダーの月は別々にカウントされるため、2つのMAUが消費されます。1つは1月、1つは2月です。

**例：複数の学習者、同じ月。** 1月に1回のバーチャルコーチセッションを開始する営業担当者は100人です。 各学習者は、その月に1つのMAUとしてカウントされるため、100個のMAUが消費されます。

**例：一定期間のチームの練習。** 50人のスタッフで構成されるチームは、年間を通じてバーチャルコーチを使用しています。 50回の練習のうち5回しか行っていない1か月に、その月は5回のMAUが消費されます。また、50回の練習すべてで、その月に戻ってきた学習者に対して既に消費されているMAUを0回超えるMAUが消費されます。これは、各学習者は、カレンダー内で練習した回数に関係なく、カレンダー月に1回しかカウントされないためです。

仮想コーチレポートについては、[仮想コーチレポート](/help/migrated/administrators/feature-summary/virtual-coach/virtual-coach-reports.md)を参照してください。
