# 管理者ブランディング：ホームページのPLPとVCストリップの再配置

## Adobe Learning Managerでのホームページストリップの追加と並べ替え

パーソナライズされた学習パスと仮想コーチストリップを学習者ホームページに追加し、ストリップをドラッグ&amp;ドロップして学習者に表示する順序を設定します。

管理者は、Adobe Learning Managerの学習者ホームページに、パーソナライズされた学習パス(PLP)とバーチャルコーチストリップを追加できます。 **管理者のブランディング**&#x200B;でドラッグ&amp;ドロップのコントロールを使用して、すべてのホームページストリップを並べ替えることもできます。 学習者が最初に表示するストリップを指定できるようになりました。

カスタマイズした学習パスウィジェットをカスタムページに追加することもできます。

### ホームページのストリップについて

ホームページストリップとは、学習者のホームページに表示されるウィジェット（カード）です。 管理者ブランディングでは、表示するストリップとストリップの表示順序を制御します。 2026年12月リリースのALMでは、AIを利用したストリップが2つ提供されています。

* **パーソナライズされた学習パスストリップ:**&#x200B;各学習者のAIが生成した学習パスをハイライト表示します。
* **仮想コーチストリップ:**&#x200B;学習者がホームページからコーチングエクスペリエンスを検索して開くのに役立ちます。

### パーソナライズされた学習パスストリップ

学習者は、このストリップを使用して次の操作を行うことができます。

* AIが生成した学習パスにアクセスする。
* 以前に生成した学習パスを継続する。
* おすすめの学習ジャーニーを見つけましょう。

### 仮想コーチストリップ

学習者は、このストリップを使用して次の操作を行うことができます。

* バーチャルコーチの経験を紹介します。
* コーチング活動を再開します。
* ホームページから会話型AIコーチングを開始します。

### ホームページストリップの並べ替え

ストリップは任意の位置に配置できます。 例えば、最初に仮想コーチストリップを表示し、その後にパーソナライズされた学習パス、**推奨**、**カタログ**&#x200B;ストリップ、次に&#x200B;**最近表示した**&#x200B;を表示できます。

1. 管理者アプリの左側のナビゲーションペインで、**設定**/**ブランディング**&#x200B;を選択します。

   ![](assets/admin-branding5.png)

2. **学習者ホームページ**&#x200B;を選択します。
3. ストリップのリストで、移動するストリップを見つけます。
4. ストリップを新しい位置にドラッグします。

   ![](assets/admin-branding1.png)

5. 変更内容を保存します。

公開すると、新しい順序が学習者ホームページに表示されます。

>[!NOTE]
>
>パーソナライズされた学習パスやバーチャルコーチストリップがリストにない場合は、順序を変更する前に、ホームページ設定に追加されていることを確認します。

## カスタムページへのパーソナライズされた学習パスウィジェットの追加

ホームページの外で、パーソナライズされた学習パスウィジェットを使用できます。 カスタムページに追加すると、学習者はパーソナライズされた学習レコメンデーションを検索するための専用の場所を利用できます。

1. **カスタムページ**&#x200B;を選択します。
2. ページを作成するか、既存のページを編集します。
3. **パーソナライズされた学習パス**&#x200B;ウィジェットを追加します。

   ![](assets/admin-branding2.png)

   ウィジェットを確認します。

   ![](assets/admin-branding3.png)

4. **「続行」**&#x200B;を選択します。
5. ウィジェットのタイトルと説明を追加します。

   ![](assets/admin-branding4.png)

6. 「**ウィジェットを追加**」を選択します。
7. ページを保存します。
8. Publishします。
