# Adobe Learning Managerの2026年8月リリースで機能が利用可能

## 目的

自社のフロントエンド（「ヘッドレス」実装）を介してプラットフォームを構築または拡張するエンタープライズのお客様は、実際に標準のWeb UI以外で、学習者API、Admin API、AEMウィジェット、またはその他の統合サーフェスを介して、新規または変更された機能を使用できるかどうかを定期的に問い合わせます。

この文書では、このリリースに付属する各機能について、簡単にわかりやすく説明します。 各機能について、サポートされるアプリケーションサーフェス、統合の可用性、移行のサポート、および該当する通知動作を示します。

## 機能ごとの可用性

### コンポーネントベースの電子メールビルダー

これは、機能リリース後にサインアップする様々なアカウントに対するフェーズごとの有効化です。これらのアカウントを既存のメールエディターから新しいエディターに移行します。 有効にすると、お客様は古いメールエディターを使用できなくなります。 （機能の有効化については、CSM/サポートにお問い合わせください）。

* **利用可能：**&#x200B;管理者アプリ 管理者と作成者は、ここで電子メールレイアウトとテンプレートを設定します。
* **該当なし：**&#x200B;学習者が使用するUI、ヘッドレスAPI、AEMウィジェット。結果の電子メールは学習者のメールクライアントから受信するだけです。
* **通知：**
  * 電子メール通知は、引き続きサポートされている電子メールクライアント間で学習者に配信されます。
  * この機能によって導入される新しいプラットフォーム内通知動作はありません。

### 外部学習

* **次のサイトで利用できます：**&#x200B;ネイティブWeb、ヘッドレス（学習者） API、ネイティブモバイルWeb、管理者アプリ。
* **まだ次のアプリで利用できません：**&#x200B;ネイティブモバイルアプリ。
* **ジョブAPI:**&#x200B;は適用できません。
* **移行：**&#x200B;はまだサポートされていません。
* **通知：**
  * プラットフォーム内通知は、社外学習承認リクエストが送信されたときや、リクエストが承認または却下されたときに、学習者とマネージャーが利用できます。
  * 現在、このワークフローでは電子メール通知を使用できません。

### 増分ユーザーレポート

* **次のジョブAPIでのみ利用可能：** レポート作成用にユーザーデータの増分（差分）エクスポートを提供します。
* **該当なし：** UI、他のAPIサーフェス、移行ツール。

### レポートビルダー

* **利用可能：**&#x200B;管理者アプリ
* **まだ次のジョブAPIで利用できません：**。 ジョブAPIベースの書き出しは、今後のリリースで予定されています。
* **移行：**&#x200B;は適用できません。
* **通知：**
  * ユーザーは、レポートのダウンロードの準備ができたとき、またはレポートの生成が失敗したときに、プラットフォーム内通知を受け取ります。
  * 電子メール通知は適用されません。

### 階層コンテンツフォルダ

* **利用可能：**&#x200B;管理者アプリと作成者アプリ
* **移行：**&#x200B;はサポートされています。
* **ジョブAPI:**&#x200B;は適用できません。 現在、専用のAPIサーフェスはありません。

>[!NOTE]
>
>カスタムの役割権限は、ルート/親フォルダーレベルでのみ適用され、階層内のすべてのフォルダーには適用されません。

### インサイトエージェント

* **利用可能：**&#x200B;管理者アプリ 現在、完全な管理者のみに制限されています（カスタムの役割は含まれません）。
* **Admin API:**&#x200B;は利用できません。
* **ジョブAPI /移行：**&#x200B;は適用できません。

### 学習パスエージェント

* **利用可能：**&#x200B;ネイティブWebおよびヘッドレス（学習者） API
* **まだ利用できません：**&#x200B;ネイティブモバイルWeb、ネイティブモバイルアプリ、およびAEMウィジェット。
* **ジョブAPI /移行：**&#x200B;は適用できません。

### AIアシスタント（学習者）

* **次のサイトで利用できます：**&#x200B;ネイティブWeb、ヘッドレス（学習者） API、ネイティブモバイルWeb。
* **まだ利用できません：**&#x200B;ネイティブモバイルアプリとAEMウィジェット。
* **ジョブAPI /移行：**&#x200B;は適用できません。

>[!NOTE]
>
>この機能は、学習者に表示する前に、明示的に有効にする必要があります。

### ライブハブ

* **次のサイトで利用できます：**&#x200B;ネイティブWeb、ヘッドレス（学習者） API、ネイティブモバイルWeb、管理者アプリ。
* **ジョブAPI:**&#x200B;は適用できません。
* **移行：**&#x200B;は現在サポートされていません。

### カスタム管理者：他のカスタム役割の読み取り/管理

* **利用可能：**&#x200B;管理者アプリ カスタム管理者に、他のカスタム管理者の役割の表示と管理を許可します。
* **ジョブAPI /移行：**&#x200B;は適用できません。 専用のAPIはまだ用意されていません。

### 成績表

* **利用可能なアプリ：**&#x200B;ネイティブWeb、ヘッドレス（学習者） API、ネイティブモバイルWeb、ネイティブモバイルアプリ、および管理者アプリ。
* **まだ利用できません：** AEMウィジェット。
* **移行：**&#x200B;は現在サポートされていません。
* **通知：**
  * 電子メール通知はありません。
  * プラットフォーム内通知はありません。

### チャネル

* **利用可能：**&#x200B;ネイティブWebおよび管理者アプリ 現在はベータ版。
* **まだ利用できません：**&#x200B;ヘッドレス（学習者） API、モバイルWeb、モバイルアプリ、AEMウィジェット、およびAdmin API
* **ジョブAPI /移行：**&#x200B;は適用できません。
